# 2026-10-29 画板组件库与指针拖动：事实与踩坑

## 组件缩略图

- 内置组件目录用 Excalidraw skeleton 写，运行时 `convertToExcalidrawElements(..., { regenerateIds: true })` 转成图元；`label` 可以直接写在容器 skeleton 上，转换器会生成绑定文字。
- 缩略图用 `exportToSvg({ elements, appState: { exportBackground: false, viewBackgroundColor: "transparent", exportPadding: 8, exportScale: 1 }, files: {} })`，序列化后转成 `data:image/svg+xml;charset=utf-8,...` 给 `<img>`。CSP 的 `img-src` 已包含 `data:`。
- 不要一次给全部分类生成缩略图；按当前标签逐条生成，并用 Map 做进程内缓存。61 个组件里基础 13 个首屏生成没有可感知卡顿，但全量生成会浪费。
- 社区 v1 `.excalidrawlib` 的 `library` 数组元素没有 `name`；面板只能从首个 text 或图形类型推导名称。

## 拖拽

- **macOS WKWebView 下，原生 CGEvent 拖动 `draggable` 的 `<button>` 没有触发 HTML5 `dragstart`**：e2e 里元素数不变，截图也没有落点。不要再用 `dataTransfer` 判断拖拽是否成功。
- 改用 Pointer Events：卡片 `pointerdown` 记录起点，`pointermove` 超过 6px 才进入拖拽；跟随幽灵用 `position: fixed` + clientX/Y；`document.elementFromPoint` 判断是否在 `.board-excalidraw` 上；`pointerup` 时用 `viewportCoordsToSceneCoords` 落点。原生 CGEvent 拖动可以正常驱动这套逻辑。
- 拖拽结束会紧跟一次 click；用 `suppressClickRef` 按条目 key 吞掉一次 click，否则同一个组件会插入两次。
- 落点插入要把组件包围盒中心对到指针，而不是把元素左上角放到指针。

## 数据

- `library_items` 原 DTO 只有组件字段；「我的组件」需要库名分组，所以在 JOIN 里补了 `library.id / name / source_type`，前端按 `librarySourceType === "import"` 过滤，避免把内置预设再列一遍。
- 画板附件删除后，画板只认 `image.fileId`；旧 `boardFileCard` 图元保留为普通矩形，不报错。
