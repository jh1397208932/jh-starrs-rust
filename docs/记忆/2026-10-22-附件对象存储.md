# 2026-10-22 附件对象存储：事实与踩坑

## 决策

- 小文件阈值 **128 KiB**（<128 KiB 进 pack，≥128 KiB 进 big）。理由：4 KiB 簇的 32 倍，减少 inode 数量，同时 pack 重写/随机读成本仍可控。
- pack 索引放 SQLite（`attachment_blob.pack_id/pack_offset/size`），不放 sidecar 索引文件；元数据是唯一真相，索引与 refcount 同事务。
- active pack 上限 1 GiB；死字节 ≥30% 且 ≥4 MiB 才 compaction；测试通过 `StoragePolicy` 注入更小阈值。
- 逻辑附件 `content_hash` **不建外键**：软删除行要保留哈希审计，而 blob 行在 refcount 归零时会删除；建外键会阻塞删除。
- 重命名/移动只改 `attachment` 行；物理对象与哈希不变。UI 暂未暴露，API 已提供。

## 必须守住的事务/文件顺序

1. big：流式写 `storage/tmp/*.part` → fsync → **rename** 到哈希路径 → 插入 blob+attachment → commit。提交失败用 `FileCleanupGuard` 删除刚发布的文件（只可能留下不可见孤儿，不能有索引无文件）。
2. small：`BEGIN IMMEDIATE` → 选/建 active pack → `max_indexed_end` 为追加尾（顺带截断崩溃遗留的未索引尾部）→ append + fsync → 插入 blob/attachment → 更新 pack size → commit。失败时 `PackAppendGuard` 截回原长度；若 pack 是本次新建则删文件。
3. 删除：软删除 + refcount-- + 归零删 blob 在同一事务；**big 文件 unlink 必须在 commit 之后**。提交前 unlink 一旦事务回滚，就会出现“有索引无文件”。
4. compaction：
   - 若旧 pack 是 active：先置 inactive，并在同一事务创建新的 active pack（否则后续上传无 pack 可写）；
   - 复制存活条目到新 pack（**不持有存储锁**，旧 pack 已停止追加）；
   - 更新 blob 的 pack_id 前必须先插入新 pack 行，否则 `attachment_blob.pack_id` 外键 RESTRICT 会报错；
   - 只条件更新仍指向旧位置的 blob；旧 pack 无引用才删行/删文件。
5. 大文件哈希/复制不持主工作区 Mutex；附件写用 `open_existing` 独立连接。物理发布/追加/删除/压缩提交共用 `storage_lock::lock_for(workspace_id)`。

## 路径/安全

- 逻辑目录是虚拟相对路径：`\` 转 `/`，拒绝绝对路径、`.`/`..`、控制字符；文件名拒绝分隔符/控制字符/首尾空白。
- big 路径由哈希纯计算，两级分桶；pack 文件只存原始字节。
- 下载写入同目录临时文件后原子替换；目标已存在必须显式 `overwrite`；**禁止写进 `storage/` 内部**（否则可能覆盖物理对象）。
- 物理删除失败不改变“逻辑已删除”的结果，只记日志；big 文件可能成为孤儿，后续可做差集清理。

## 并发/性能

- 同哈希并发上传由存储锁 + blob 主键收敛：测试 4 线程 1 MiB → 1 个物理对象、ref_count=4。
- 固定 256 KiB 缓冲；上传/下载/校验都不 `read_to_end`。
- Tauri 命令 `#[tauri::command(async)]` + `spawn_blocking`；不要在主线程做大文件 IO。
- 压缩复制不持锁，条件 UPDATE 处理并发删除；并发删除会让新 pack 留下少量死字节，当前只记录“等待后续 compaction”，不要声称零残留。

## 工具/门禁

- 新增 Rust 依赖后，离线许可证门禁可能因平台目标依赖未缓存而失败；先执行一次 `cargo fetch`，再 `npm run build`。
- `blake3` 1.8.7 为 CC0/Apache/LLVM-exception 三选一；`mime_guess` 2.0.5 为 MIT；传递依赖均宽松。
- 浏览器 UI 冒烟用 `window.__TAURI_INTERNALS__.invoke` mock；`plugin:dialog|open/save` 也走同一 invoke。mock 只能证明 UI→IPC，不代表真实 Tauri 对话框/WKWebView。
- 测试截图用 headless Chrome 生成；临时 harness 测试后删除。
