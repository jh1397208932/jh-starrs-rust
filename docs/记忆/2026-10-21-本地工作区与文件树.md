## 关键决策与不变量

1. **工作区切换唯一入口**：`workspace_service::switch_workspace`。新建/打开/手动切换/删除当前后的自动切换必须复用；不要在命令层直接替换 `AppState.workspace`。
2. **全局工作区只存注册表与配置**：名称只在全局库；工作区目录内只有知识库数据。
3. **新建工作区选择目标目录本身**；打开工作区必须已有 `db/workspace.sqlite3`。
4. **删除当前工作区允许**：自动切到最近使用的其他工作区；最后一个删除后清空会话并回引导；目录删除是可选项。
5. **新建工作区自动建「默认知识库」**；打开无库的工作区显示空态。
6. **node.path 使用标题路径**（`设计/原型/首页`）；标题禁止 `/`、`\`；文件夹改名需同步后代 path。
7. **只有文件夹可作为父级**；根级任意类型；移动时禁止自身后代/跨知识库；事务内重排新旧同级组。
8. **记忆保留键**：`current_workspace_id` 只由后端切换写；`appearance.theme`、`appearance.mode` 由前端经 `memory_save` 写；当前知识库按工作区存 `kb.current.<workspaceId>`，切换时写入、启动时优先恢复，失效回退第一个库并回写。
9. **前端 IPC 唯一出口**：`src/api/*` → `api/client.ts`；组件不得直连 `@tauri-apps/api`。

## 本轮踩坑

- **StrictMode + “只请求一次 + 卸载取消”会让主题 hydration 永不完成**：首个 effect 被清理标记 cancelled，第二次 effect 又被 ref 拦截。修复：读取记忆不做一次性拦截/取消（允许 StrictMode 重复读取）。
- **删除最后一个工作区后管理弹窗残留**：Root 切到引导页时需关闭非创建类 dialog。
- **Bun?** 用 npm（当前环境例外），`tauri dev` 的 beforeDevCommand 也是 `npm run dev`。
- **CLI 的 `columns.includes` 是 JS 习惯**：Rust `Vec` 用 `contains`。
- **字段名要对齐需求字面量**：node 建表列 `create_time/update_time`，不是 `created_at/updated_at`；旧 v1 库通过 v2 迁移列重命名。
- **许可证门禁要归一化斜杠 OR**：Cargo/npm 常见的 `MIT/Apache-2.0`、`Unlicense/MIT` 若按单个 token 判定会把 22 个宽松依赖误报为失败；扫描前统一把 `/` 替换为 ` OR `。
- **Excalidraw 随包字体有许可差异**：产物只允许 OFL/MIT 白名单（Assistant 等）；Liberation 1.05 为 Ascender 旧许可、Excalifont 许可未明确，构建守卫会剔除，禁止放进 `dist`。
- **文件树拖拽在浏览器自动化中**：Radix 下拉需要派发 `pointerdown` 才能打开；HTML5 拖拽需依次 dispatch dragstart → dragover（等待 state 更新）→ drop。
