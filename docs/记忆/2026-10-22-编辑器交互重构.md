# 2026-10-22 编辑器交互重构：事实与踩坑

## 数据契约

- Tiptap `editor.getJSON()` 返回根对象 `{"type":"doc","content":[...]}`；Rust 只按 `content` 切顶层块，保存与回显都传完整根 doc。不要误把 `content` 数组当根。
- `editor.setEditable(value)` 默认会 `emit("update")`。加载/切换文档时必须 `setEditable(false,false)` / `setEditable(true,false)`，否则会把旧文档误标脏并在切换后保存错内容。
- 保存器必须在拿到前端单飞锁后再取 `getJSON()`；加载后 `normalized=true` 时自动补一次保存，让旧脏数据修复落库。

## `:null::null:` 根因

Emoji 扩展的 `enableEmoticons` 会执行：
`this.options.emojis.flatMap(item => item.emoticons).filter(Boolean)`。
当前表情集没有 `emoticons`，得到空数组后正则变成 `(?:^|\s)() $`，输入空格会插入 `name` 为 undefined 的 emoji 节点，`renderText` 回退为 `:${name}:`，即 `:null:`。

- 修复：移除 `enableEmoticons`；`Emoji.extend` 的 `renderText/renderHTML` 对空 name 返回空；后端规范化删除非法 emoji（历史数据从 `doc_load` 开始修复）。
- 不要仅靠前端渲染守卫；旧 JSON 可能在别处被消费，Rust 规范化必须同时存在。

## 回车样式

- 只清 `storedMarks` 不够覆盖所有结构；列表必须 `splitListItem`，标题末尾 `splitBlock` 在部分 Tiptap 版本无动作，需显式 `insertContentAt(after, paragraph)`。
- 空列表/引用交还默认命令退出结构；代码块/表格/折叠 summary 不拦截。
- 官方扩展写法：`Extension.create({ addKeyboardShortcuts })`，不要改编辑器源码或全局 `document` 监听。

## 拖拽（2026-10-22 第二轮：自绘方案）

- **官方 `@tiptap/extension-drag-handle(-react)` 已移除，不要重新引入**。它把手柄定位与 HTML5 DnD 绑定：WKWebView 下 `dragstart` 后 `dataTransfer/effectAllowed` 与 Chromium 不一致，表现为“手柄能拖走、松手正文不动”；`mouseleave` 又会在鼠标移向按钮时立刻隐藏。补 payload/effect 只能让 Chromium 绿，不能证明 WKWebView 可用。
- 手柄定位：`useBlockHandle` 按鼠标 Y 扫描顶层块，读 `view.nodeDOM(pos)` 的 rect，绝对定位到 `.doc-editor-body` 左侧 52px 走廊；鼠标在走廊同一块行内保持当前块，跨行则按 Y 重新定位；离开块/滚动/resize/keydown 隐藏，离开有 180ms 缓冲。
- 手柄 DOM 常驻但在隐藏时 `opacity:0; pointer-events:none`；拖动期间不要卸载它，否则会丢失指针捕获。
- 拖拽：`useBlockPointerDrag` 在六点按下后监听 window 的 pointer 事件；4px 阈值后置 `body.starris-block-dragging`、禁用原生 dragstart，计算顶层落点并自绘落点线/类型标签；松手时 `delete` 后按 `insertPos > sourcePos ? insertPos - nodeSize : insertPos` 插入，再聚焦新位置。
- 源块淡化必须用 ProseMirror **Decoration**（`blockDragHighlight.ts`）。直接给节点 `classList.add` 会被视图重绘回滚，还会触发“加类 → 重绘 → 类丢失”的循环；这也意味着不要用 DOM class 表达任何需要跨事务存活的编辑器状态。
- 落点线用自绘 `.editor-block-drop-indicator`（fixed），不能用官方 Dropcursor：Dropcursor 只在原生 DnD 的 drag 事件里工作，pointer 拖拽不会触发。官方 Dropcursor 仅保留给图片/文件拖放。
- 拖动是否生效以顶层顺序/`getJSON()` 变化为准；无位移释放与 Escape 必须保持 JSON 不变并清理所有浮层。拖动到末尾且末块为标题时，Tiptap 会补一个尾部空段落，这是结构约束，不是复制 bug。
- Chromium 的合成 pointer 序列能覆盖落点/事务/清理，但不能替代 WKWebView 真机；最终仍需用户在 Tauri dev 窗口复测。

## 异步元数据

- SQLite 保存事务用 `BEGIN IMMEDIATE`。DEFERRED 事务先读后写时，后台连接持 RESERVED 会立刻收到 BUSY，`busy_timeout` 不救。
- 后台元数据连接用 `open_existing`：只 READ_WRITE、不 CREATE、不切 journal_mode、不迁移，避免删除工作区后“复活”文件或与前台抢锁。
- 异步任务用 `update_time` 做条件 upsert，晚到的旧任务不得覆盖新结果。

## 样式

- 图片 `ResizableNodeView` 的缩放点默认零尺寸；必须按 `[data-resize-handle="..."]` 样式化，并在非 hover 时 `pointer-events:none`，否则看不见的角落会拦截点击。
- Details 的 summary 是原生 `<summary>`，浏览器自带三角；单箭头需 `summary::marker`/`::-webkit-details-marker` 清除后，用按钮伪元素绘制。
- 容器 `overflow:hidden` 会裁掉列宽拖拽线；`column-resize-handle` 放回 `right:0`。
- 浮层滚动高度与 top 定位要联动；`max-height` 改大时同步改 top 预留值，否则小视口溢出。
