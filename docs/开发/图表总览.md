**不变量**

- 组件不直接 `import @tauri-apps/api`，窗口与 IPC 能力统一从 `lib/window.ts`、`api/*` 进入。
- 复杂业务、批量数据处理、权威校验与持久化全部在 Rust；前端负责展示、交互编排与轻量格式化。
- 同一业务规则只有一个权威实现：工作区切换 `workspace_service::switch_workspace`、文档保存 `document_service`、附件引用 `node_attachment`。

## 3. 启动时序

```mermaid
sequenceDiagram

  R->>R: macOS 挂原生菜单；Windows/Linux 跳过
  R->>R: 移除窗口装饰（非 macOS 兜底）
  R->>M: ensure_started（按设置决定是否监听）
```

## 5. 文档保存数据流

```mermaid
flowchart LR
  E["Tiptap onUpdate"] --> D["dirty + 1s 防抖"]
  D --> L{"前端保存锁可用?"}
  L -- 否 --> R["1s 后重试，不取消新编辑"]
  L -- 是 --> J["editor.getJSON() 取最新根 doc"]
  J --> API["api/document.ts → doc_save"]
  API --> CMD["commands/document.rs"]
  CMD --> SVC["document_service"]
  SVC --> NORM["规范化旧数据<br/>emoji / attrs / marks"]
  NORM --> HASH["顶层块 xxh3 内容寻址"]
  HASH --> LIS["保留块 LIS + 其余生成 base62 order"]
  LIS --> TX["BEGIN IMMEDIATE<br/>写 block tree / hash / node.content"]
  TX --> WDB[("workspace.sqlite3")]
  TX --> META["异步写 doc_block_meta<br/>独立连接 + 时间戳防倒挂"]
  META --> WDB
  SVC --> REF["同步 node_attachment 引用差量"]
  REF --> WDB
```

**前端守卫**：切换标签 / 文档 / 工作区 / 知识库前先 `flush`，失败阻止切换；保存期间新编辑结束后再排一次保存；加载期间关闭可编辑，避免旧文档被误标脏。

## 6. 附件生命周期

