## 3. 判据约定

- 累积型状态用等式判：第 N 次操作后的读数 == 第 1 次（行数、线程数、缓存条目）。
- 规模相关判定必须打印实际读数（行数/帧数/毫秒），不能只判"没报错"。
- 界面上会被虚拟化的内容（画布节点、长列表）不要用屏幕文本当判据，改用数据库或接口返回值。
