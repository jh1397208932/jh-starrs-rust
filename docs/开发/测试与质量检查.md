# 测试与质量检查

- 最后更新：2026-10-25

## 1. 前端/静态门禁

```bash
cd starris-rust
npm run check        # Biome，仅 src
npm run typecheck    # tsc --noEmit
npm run build        # typecheck + Vite build + 许可证门禁
```

## 2. Rust 后端测试

```bash
cd starris-rust
pnpm run test:backend              # cargo test --manifest-path src-tauri/Cargo.toml
cd src-tauri && cargo test
cd src-tauri && cargo clippy --all-targets -- -D warnings
cd src-tauri && cargo fmt --check
```

集成测试使用真实临时 SQLite + 临时工作区，不 mock 数据库；覆盖工作区/知识库/文件树、文档块、附件对象、导出导入、画板持久化、组件库、迁移等。

## 3. 真机黑盒测试（macOS）

命令：

```bash
pnpm run test
```

前置条件：

1. macOS + Xcode Command Line Tools（`swiftc`）。
2. 运行命令的终端/Qoder 已获“辅助功能”权限。
3. 没有其他星屿实例运行，`localhost:1420` 空闲。
4. 不要求生产构建；套件会启动 `pnpm exec tauri dev` 并在结束时关闭。

套件通过真实 AX/CGEvent 操作 Tauri 窗口，用系统保存/打开面板、真实 SQLite 与磁盘文件断言；**不是**浏览器 mock。

- 测试工作区：`tmp/e2e/<timestamp>/workspace`（项目内 `tmp/`，已 gitignore）
- 全局 home：`tmp/e2e/<timestamp>/home`
- 输入 fixtures：`test/fixtures/files/`
- 运行产物：报告、截图、应用日志、导出文件；`tmp/e2e/latest` 指向最近一次
- 扩展方式：添加 `test/e2e/cases/NN-*.mjs` 并在 `cases/index.mjs` 登记；详细 API 见 `test/README.md`

当前用例（15）：引导/工作区、侧栏/更多、文件树、附件树上传/预览/下载/重命名、文档与四格式导出、画板与三格式导出、设置/主题/附件、组件库、导入导出（含附件节点）、快捷键、快捷键总开关/录制/冲突/持久化、编辑器与画板自定义键位、知识库/收藏/小记、编辑器 slash/画布交互、占位视图与附件生命周期。

覆盖矩阵、操作复杂度、发现与未覆盖项见：
`docs/功能测试/2026-10-25-黑盒全量功能测试与合理性分析.md`。

## 4. 通过标准

- 前端三条命令 exit 0；Rust test/clippy/fmt exit 0。
- 黑盒套件必须逐用例输出 PASS/FAIL；任何 FAIL 退出码为 1。
- 报告只记录实际执行结果；未执行的环境/用例必须标为未执行或未覆盖，不得写成通过。
