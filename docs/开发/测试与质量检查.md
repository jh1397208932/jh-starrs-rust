## 3. 真机黑盒测试（macOS）

命令：

```bash
npm run test
```

前置条件：

1. macOS + Xcode Command Line Tools（`swiftc`）。
2. 运行命令的终端/Qoder 已获“辅助功能”权限。
3. 没有其他星屿实例运行，`localhost:1420` 空闲。
4. 不要求生产构建；套件会启动 `npm run tauri dev` 并在结束时关闭。

套件通过真实 AX/CGEvent 操作 Tauri 窗口，用系统保存/打开面板、真实 SQLite 与磁盘文件断言；**不是**浏览器 mock。

- 扩展方式：添加 `test/e2e/cases/NN-*.mjs` 并在 `cases/index.mjs` 登记；详细 API 见 `test/README.md`
