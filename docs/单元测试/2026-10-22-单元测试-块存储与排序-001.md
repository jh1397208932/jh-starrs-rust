## 2. 重点用例

### Fractional Index

- `key_between_covers_head_middle_and_tail`：`None..a`、`a..b`、`ab..ac`、`z..None`。
- `repeated_middle_inserts_grow_until_limit`：`a` 与 `b` 间最多再放 31 个中位键，随后返回 `None`。
- `rebalance_is_even_unique_and_ascending`：1000 块生成 8 位 key，严格递增且唯一。

### 块差量

- `unchanged_document_keeps_instances_and_orders`：同内容重复保存返回空 `add/rm/order`，实例 id 不变。
- `moving_one_block_keeps_lis_anchors`：`h4,h1,h2,h3` 中 LIS 保留 `h1/h2/h3`，仅 `h4` 获得新 order。
- `exhausted_between_keys_trigger_full_rebalance`：32 字符相邻键无法插入时整篇重排。
- `duplicate_hashes_pair_instances_in_order`：相同 hash 两个实例独立 UUID，删一个不删 hash。

### 集成

- `document_blocks_save_incrementally_and_roundtrip`：首次 3 块 → 同内容 → 中间插入 → 修改块 → 清空；逐步断言 add/rm/order 与树顺序。
- `duplicate_blocks_share_hash_and_respect_references`：跨文档引用时删除块不产生 `rm`；最后一个引用消失才清理 hash。
- `document_save_rejects_non_document_nodes_and_invalid_documents`：画板/非法根被拒绝。
- `document_blocks_survive_restart`：重开全局库并切换工作区后 `doc_load` 恢复正文与实例 id。
