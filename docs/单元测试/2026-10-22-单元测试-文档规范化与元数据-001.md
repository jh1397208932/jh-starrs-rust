## 1. 测试目标

验证：
1. `editor.getJSON()` 根 doc 契约与 `content[]` 切块；
2. 历史脏数据规范化（空 emoji、null attrs、空 marks/text）与幂等；
3. 文档属性 JSON、Markdown 生成覆盖常用块；
4. v4 迁移新增 `doc_block_meta`，主键与 node.id 一致；
5. 保存后异步写入 Markdown/prop，旧任务不会覆盖新结果；
6. 加载旧脏数据时重算字数并标记 `normalized`。

## 4. 覆盖边界说明

- `name` 为空、非字符串、缺少 `attrs` 的 emoji 均在规范化中删除。
- 根 content 缺失/null 视为空文档；content 为对象或顶层块非对象则拒绝。
- 规范化幂等，避免 `doc_load` 每次都触发修复保存。
- 元数据写入使用独立连接，不创建不存在的数据库文件；旧任务时间戳更小则跳过。
- 未覆盖：真实 Tauri WebView 中的异步线程退出时机（应用进程结束时元数据允许丢一批，下次保存补写）。

## 5. 已知限制

- Markdown 为派生数据，不反向驱动编辑器；颜色、对齐、下划线以文本或 HTML 语义近似表达。
- 内联 base64 图片不写入 Markdown，仅保留 alt。
