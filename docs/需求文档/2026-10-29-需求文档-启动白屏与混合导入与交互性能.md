# 需求文档 · 启动白屏、混合导入与交互性能

- 日期：2026-10-29
- 状态：实施中（真机结果待回填）
- 关联任务：`docs/开发任务清单/2026-10-29-任务-004/`

## 1. 启动白屏

现状：窗口默认可见（`tauri.conf.json` 未设 `visible:false`），Rust `setup` 立刻 `show()`；HTML 无首屏底色，React/令牌 CSS 到达前是 WKWebView 白底。

方案：

1. `index.html` 增加静态 splash（品牌字形 + STARRIS + 呼吸动画），inline CSS 与 `prefers-reduced-motion`；React 首次 render 替换 `#root` 时自然移除。
2. 主窗口改为 `visible:false`，前端在 splash 进入 DOM 后 50ms 调 `show()` + `setFocus()`；Rust 保留 6s 兜底（仅窗口仍隐藏时显示），避免脚本失败导致“启动了但看不见”。
3. 主题镜像：`ThemeProvider` 把 `{theme,mode}` 写入 `localStorage["starris.appearance"]`，`index.html` 启动脚本在 IPC 之前恢复 `data-mode/data-theme`；splash 明暗与上次一致。
4. `WorkspaceBootScreen` 继续作为工作区加载态；窗口显示不等于主界面 ready，splash → boot screen → 主界面。

验收：冷启动看不到白底；深色用户 splash 不闪白；前端脚本异常时 6s 内仍出现窗口。

## 2. 混合导入

入口：「更多 → 导入…」里的「混合导入」（选文件夹），替换原来的「选择文件夹」。

行为：

1. 先扫描（只读）：按扩展名分类——md/docx/pdf → 文档；`.excalidraw` → 画板；`.xmind/.mm/.opml/*.starris-mindmap.json` → 导图；被 Markdown 本地引用（相对路径、且位于所选目录内）的文件 → 引用附件；其余 → 跳过候选。
2. UI 显示「共 N 个文件：文档 X · 画板 Y · 导图 Z · 引用附件 W」与将跳过的文件列表（前 8 条 + 总数）；有跳过项时，点「开始导入」再弹「跳过不支持的文件？」确认，确认后才导入。
3. 导入沿用现有目录导入：保留层级（可选关闭）、同名自动改名、隐藏文件/目录与符号链接跳过、不支持的格式跳过而不是失败。
4. Markdown 本地引用：图片进对象库并替换为 attachmentImage；其它本地文件链接进对象库并追加 attachmentBlock；`http(s)`、`mailto`、`tel`、`data:`、锚点保留为链接，不下载。
5. 扫描上限 5 万文件 / 深度 32；回传跳过项最多 500 条，计数以真实总数为准。

验收：混合目录导入后节点类型/层级正确；被引用图片在对象库；外部链接原样保留；不支持文件不建节点且有确认。

## 3. 交互性能

目标：按钮点击的同步处理保持毫秒级，画面在下一个可绘制帧内更新；不把“微秒级”当成所有 DOM/React 工作的承诺，按实测报告分位数。

已定位并修复：

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| `Sidebar` 的 `onImportToFolder` 内联 | memo 失效，任何顶层状态变化都重渲染整棵文件树 | `useCallback` 稳定 |
| `WindowBar` 未 memo，且 `onSearch`/`onWindowFallback` 内联 | 每次控制器渲染标签栏都重建 | `memo` + 稳定回调 |
| `InfoPanel` 未 memo，`onOpenNode` 内联 | 浮窗打开时每次顶层渲染都重算字段/卡片 | `memo` + 稳定回调 |
| `activeNode` 每次渲染线性 `findNode` | 大树上每次状态变化 O(n) | `useMemo` 节点索引，O(1) |
| `nodeDeleteCount` 每次渲染递归 | 删除弹窗打开时反复扫描全树 | `useMemo` |
| `TabContentView` 的 `onBoardExported` 内联 | 打开任意弹窗重渲染文档/画板 | 已在上轮修复，本轮保留 |

测量：

- 探针 `src/lib/interactionProbe.ts`，仅 `VITE_INTERACTION_PROBE=1` 构建启用；点击捕获 → 微任务末尾（同步处理 + React 离散提交）与下一次 rAF 两个读数，另记 ≥50ms 长任务。
- 报表 `test/perf/interaction-report.mjs` 解析日志，输出 p50/p95/max 与最慢点击目标。
- 验收口径：同步处理 p95 目标 ≤ 5ms（单次点击的可交互工作），frame p95 ≤ 20ms（60Hz 一帧 + 余量）；超出项逐个定位。

## 4. 非目标

- 不做 OCR；扫描版 PDF 仍只保留原件与提示（上轮既定）。
- 不把混合导入做成分步向导；扫描摘要 + 一次跳过确认即完成。
- 不改 Excalidraw/导图渲染引擎。
