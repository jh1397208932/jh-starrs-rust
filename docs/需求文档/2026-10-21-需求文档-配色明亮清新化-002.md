# 需求文档 · 全主题配色明亮清新化（第五轮）

- 日期：2026-10-21　|　状态：已实施并验收（用户反馈"整体不够透亮、鲜明度低、字体过于偏向主题色、按钮文字不凸显、太安静死气沉沉"）
- 前置：第四轮「配色清新化与对比度达标」（同日）只修了对比度下限与底色降饱和，未触及文字 tint 与主色鲜明度。

## 1. 问题诊断（第四轮基线实测，脚本 scripts/check-contrast.mjs）

对 8 主题 × light 全量实测（WCAG lum/ratio）：

1. **主按钮白字对比仅 3.06~3.9 : 1**（sunset 3.06 / azure 3.13 / amber 3.08）——只达大字号 AA（3:1），普通字号按钮文字（15px/500）发虚，即用户说的"按钮颜色无法凸显核心文字"。
2. **文字组色相偏移（tint = RGB max-min）高达 24~43**（azure 41 / amber 43 / midnight 40）——muted-foreground #5F7288（蓝灰）、sidebar-muted 等中灰文字明显"泛主题色"，即"字体过于偏向主题色"。
3. **主色鲜明度不足**：第四轮为保白字 3:1 把主色提亮到极限，导致 azure #1F94DE 明度高饱和平平、forest S 仅 48%，配灰蒙蒙的 tinted 底色，整体"安静死气沉沉"。
4. **底色白度不足**：light background L*≈97~98（#FAFCFE 等），编辑器/tab 区始终有一层色罩。

## 2. 方案（令牌级，第五轮「明亮清新」改造）

**三角原则：白底 + 黑字 + 鲜主色。**

1. **底色纯白化**：8 主题 light `--background` 统一 `#FFFFFF`（编辑器/tab/卡片全白），主题个性交给 sidebar/secondary/accent 的极浅倾向（L*≥96.5）与主色承担。参考 Linear/Notion 的白底文档形态。
2. **文字组统一中性化**：8 主题 light 共用一套中性碳黑（RGB max-min ≤ 4）——
   - foreground / card-fg / popover-fg `#191A1C`（对白 17.4:1）
   - secondary-foreground `#454649`、muted-foreground / sidebar-muted `#6C6D70`（5.2:1）
   - sidebar-foreground `#343537`
   跨主题切换正文观感恒定；主题感由底色倾向/主色/激活态承担。
3. **主色鲜明化（核心）**：全主题 primary 加深提饱和（HSL S≥70%，graphite 中性除外），**白字对比从 3:1 提标到 ≥4.5:1（普通字号 AA）**：
   - sunset `#E8722A → #C55008`（鲜焦橙，白字 4.63）
   - azure `#1F94DE → #0B76D0`（品牌蓝，白字 4.65，S 90%）
   - midnight `#6873EA → #4F5BE0`（白字 5.38）
   - amber `#BE8412 → #9A6A08`（深琥珀金，白字 4.73）
   - forest `#339163 → #12834E`（鲜绿，白字 4.79，S 48%→76%）
   - rose `#E25A70 → #D0344F`（玫红，白字 4.90）
   - violet `#8463E8 → #6D4FE3`（白字 5.42）
   - graphite `#4A5058` 不变（白字 8.14）
   logo-a / glow-a / ring 同步跟随 primary；logo-b 取 primary 深一档。
4. **强调/激活文字提鲜**：accent-foreground、sidebar-active-fg 保持主题色相、加深至新浅底上 ≥4.5:1。
5. **destructive 统一** `#CE3535` / 白字（5.05:1），取代旧 `#D64545` / `#FFF5F5`（4.19 不达标）。
6. **dark 模式全部不动**（第四轮校准值，实测按钮字 6.2~11 达标）。

## 3. 验收结果（scripts/check-contrast.mjs --check 实测）

8 主题 light 全部 PASS：

- foreground vs background = **17.41**（原 15.4~16.1）
- 主按钮白字 = **4.65~8.14**（原 3.06~3.9，全部 ≥4.5 AA）
- muted-fg vs background/secondary = 5.17 / 4.51+（取严仍达标）
- sidebar-muted = 4.63~4.85；accent-fg = 4.81~10.46；active-fg = 4.66~10.66
- border = 1.33~1.44；primary 色块辨识 ≥4.65
- 文字组 tintMax = **4**（原 24~43）
- 主色饱和度：azure 75%→90%、forest 48%→76%、sunset 81%→94%、amber 83%→90%
- tsc 零问题；vite 截图验证 azure/sunset/forest 三主题观感：白底黑字、主色鲜亮、按钮文字清晰。
