## 2. 数据模型（schema v15 → v16）

### 2.1 canonical JSON（向后兼容：全部新字段可选，旧内容可无损打开）

```jsonc
{
  "schemaVersion": 2,
  "sheet": {
    "id": "sheet-uuidv7",
    "structure": "balanced | logic-right | logic-left | org-down | org-up | tree | timeline | fishbone",
    "theme": "auto | mist | warm | sea | mono | rose | violet-deny | forest",  // 8 套画布主题
    "branchColoring": "theme | rainbow",      // 彩虹分支开关
    "edgeStyle": "curve | polyline",
    "root": { /* MindmapTopic v2 */ }
  },
  "relationships": [                           // 关系线（跨树任意两点）
    { "id": "rel-1", "from": "topic-a", "to": "topic-b", "label": "依赖", "color": "auto" }
  ],
  "boundaries": [                              // 外框：圈一组同级主题
    { "id": "bd-1", "parent": "topic-p", "childIds": ["c1", "c2"], "label": "阶段一", "color": "auto" }
  ],
  "summaries": [                               // 概要：括起一组主题并挂结论
    { "id": "sum-1", "parent": "topic-p", "childIds": ["c3", "c4"], "topicId": "sum-topic-1" }
  ]
}
```

### 2.2 MindmapTopic v2 新增字段

```jsonc
{
  "style": {                      // 全部可选；缺省走主题/分支默认
    "borderColor": "auto | #hex(12 色板)",
    "borderShape": "rounded | underline | pill | plain",
    "fill": "auto | #hex",
    "borderWidth": "thin | normal | bold"
  },
  "markers": ["priority-1", "task-start", "symbol-check", "face-smile", "week-mon", "flag-red", "star", "month-1", "progress-3"]
}
```

- 标记 9 组约 60 个：priority-1..6、flag-red/orange/green/blue/purple、star、task-start/done/…、symbol-*（✓✗!？）、face-*（5）、week-mon..sun、month-1..12、progress-0..6。
- marker 合法集合由 Rust `domain/mindmap.rs` 白名单收口；导入映射尽量对齐 XMind marker 语义。

### 2.3 SQLite（v15 → v16）

- 不需要新表/新列：`mindmap_scene.content_json` 直接承载 v2 JSON；`SCHEMA_VERSION` 升 16 仅为显式表达模型版本？——**不需要升版**：content_json 是无 schema 载体，Rust 校验层同时接受 v1/v2 内容。→ 决策：**schema 保持 15**，`schemaVersion: 2` 在 JSON 层演进，避免又一次整库迁移；旧内容打开后保存即升级为 v2。

## 3. 交互与 UI 设计

### 3.1 样式面板（选中主题时检查器扩展）

- 边框色：12 色板（取自 8 套主题分支色的超集：teal/gold/rose/sky/forest/plum/amber/slate + 4 深浅变体）+「跟随分支」auto。
- 边框形状：圆角矩形（默认）/ 下划线 / 胶囊 / 直角；宽度 细/常规/加粗。
- 填充：无 / 主题浅底 / 分支浅底 / 12 色 20% 透明底。
- 标记选择器：分组网格，点击切换；多选上限 12。

### 3.2 结构切换

- 页头结构菜单 8 项，切换即时重排（布局动画 220ms --ease-pop）。
- 鱼骨图/时间轴下的折叠徽标与边线方向由布局返回（layout 节点新增 `side` 枚举扩展）。

### 3.3 手动定位与重新排列（v3 补齐）

- 主题拖到远离兄弟的空白处：记录 `topic.pos`，该主题连同子树以新位置为基准排布；手动坐标对全部 8 种结构生效（含根主题、概要主题与自由主题）。
- 拖到兄弟附近仍按「吸附排序」、拖到主题上按「换父」；两者都会清除旧的手动坐标，让主题重新参与自动布局。
- 「结构与主题」菜单新增「按结构重新排列」：清除树与概要主题的手动坐标、自由主题子树回到自动排布；自由主题自身位置保留。

### 3.4 连线

- 曲线（默认，分支色渐变 stroke，粗细 = max(1.5, 3 − depth×0.5)）；
- 折线（正交，圆角拐点 r=8）；
- 关系线：虚线 + 箭头 + 可选中（点击出现标签编辑），颜色 auto=两端分支色渐变或指定色。

### 3.5 外框 / 概要

- 选中同一父下多个兄弟（Shift+点击 或 框选）→ 浮出「添加外框 / 添加概要」按钮；
- 外框：圆角矩形，边色=分支色，标签显示在上边线中央；
- 概要：括号线 + 概要主题（悬空节点，不参与树计数）；
- 删除成员主题时自动收缩/移除外框与概要（树命令层维护）。

### 3.6 动效

- 布局重排：节点位置/尺寸过渡 220ms `--ease-pop`；React Flow nodes 用 CSS transition（transform），reduced-motion 时关闭。
- 新建主题：scale 0.85→1 + fade 180ms；删除：fade + scale→0.9 150ms。
- 边线入场：stroke-dashoffset 一次性 draw-in 240ms（仅首次加载）。

## 4. 布局算法要求（纯函数）

- 每种结构一个布局函数，输入 content 输出 nodes/edges（含 boundary/summary/relationship 的几何附件）；5000 主题 ≤ 10ms（现有基准口径）。
- 鱼骨图：父在脊骨，子呈 45° 骨刺交替上下；时间轴：横轴里程碑 + 纵向事件堆叠。

## 5. 验收标准（真机）

1. 旧工作区（残缺 v15 库）打开不再报“数据库操作失败”，思维导图可加载/保存（已在后端测试覆盖，真机复核）。
2. 8 种结构可切换，切换后布局无重叠、折叠/展开正常。
3. 任意主题可设置边框颜色/形状/宽度/填充，视觉即时生效并随主题深浅适配。
4. 关系线/外框/概要：可创建、可选中、可编辑标签、删除成员自动清理；保存后重载无损。
5. 彩虹分支开关生效；8 套画布主题下分支色与边框对比度 ≥3:1（check-contrast 扩展断言）。
6. XMind 导入：v2 样式/关系线/外框/概要能从 content.json 映射；导出回 XMind 不丢。
7. E2E 用例扩展后全量真机通过；新增布局基准 ≤10ms/5000 主题。
