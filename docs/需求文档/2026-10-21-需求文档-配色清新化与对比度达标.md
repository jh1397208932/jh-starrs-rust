# 需求文档 · 全主题配色清新化与对比度达标

- 日期：2026-10-21　|　状态：已确认（用户提出"整体偏浓郁、不够清新，底色与线条/字体区分度不足"）

## 1. 问题诊断（量化）

对 8 主题 × 浅色做 WCAG 对比度实测：

1. **次级文字（muted-foreground）全部不达标**：3.27~3.85 : 1（要求 ≥4.5:1）——长时间阅读时元信息/说明文字发糊。
2. **侧栏辅助文字（sidebar-muted）更差**：2.60~3.09 : 1——树路径、面包屑上级发糊。
3. **边线（border）与底色对比仅 1.18~1.23 : 1**（要求 ≥1.25）——分隔线"融"进底色。
4. **sunset（默认）与 amber 底色饱和度偏高**：#FAF6F1 / #FAF6EB 等高 chroma 暖底 + 高饱和 secondary/sidebar，整体氛围压过内容，即用户描述的"浓郁、不清新"。
5. sunset 附带：激活态文字 3.54、accent 上文字 4.25、主按钮白字橙底 2.90，均低于 AA。

## 2. 方案（令牌级，改 tokens.css）

**清新度准则（新增至 UI-SPEC）**：
- 浅色底明度 L* ≥ 97 且低饱和（暖/冷色相只作"倾向"）；
- 对比阶梯：foreground ≥ 12:1，muted-foreground ≥ 4.5:1，sidebar-muted ≥ 4.5:1，border vs background ≥ 1.25:1，accent/active 上文字 ≥ 4.5:1；
- 主色（品牌色）不动——调的是"底色氛围"，不是品牌。

**改动范围**：
1. sunset light：底色组清新化（background/sidebar/secondary/muted/accent 降饱和提亮），文字组对应加深（muted-fg / sidebar-fg / sidebar-muted / accent-fg / sidebar-active-fg），border/input 加深一档，主按钮文字改纯白。
2. amber light：同 sunset 力度清新化。
3. 其余 6 主题 light：只修对比度三件套（muted-foreground / sidebar-muted / border+input 加深），底色已达标不动。
4. 所有 dark 模式不动（无此问题）。

## 3. 验收标准

- 8 主题 light：muted-foreground ≥ 4.5、sidebar-muted ≥ 4.5、border ≥ 1.25（脚本实测输出）。
- sunset/amber 底色明度提升、饱和度下降（肉眼清新、截图对比）。
- 品牌 primary 与 logo/glow 色不变；8 主题深浅切换无回归；tsc/biome 零问题。

## 4. 未决问题

- 无。主按钮"白字橙底"3.05:1 属大字号粗体 AA（3:1）达标线，保持品牌观感。
