## 1. 范围

- **模板库**：把当前文档/画板另存为模板；列表、使用模板创建新节点、删除模板。
- **文档历史**：自动快照（10 分钟间隔、首次保存一份、单篇最多 50 份）；列表与恢复。
- **打印**：落盘后调用系统打印面板；打印样式只保留文档纸面。
- **画板放映**：固定层 + 全屏 + Excalidraw zen mode；Esc/按钮退出。
- **存储告警**：设置页显示磁盘剩余空间；上传前低于 256 MB 拒绝。
- **崩溃草稿**：编辑后 500ms 写入 localStorage；重新打开时若草稿更新则提示恢复/忽略。

## 2. 非目标

- 模板变量、市场、跨工作区共享。
- 历史 diff/逐字符回滚；只做整篇快照恢复。
- 打印分页精细排版/页眉页脚配置。
- 多页演示文稿、演讲者视图。
- 云同步/协作。

## 3. 规则

### 模板

- 文件存 `storage/templates/<id>.json`，结构 `{version,id,name,kind,createdAt,content}`。
- 文档模板 `content` 为 Tiptap JSON；画板模板 `content={elements,appState}`。
- 使用模板：创建同类型节点 → 写入内容；失败删除节点并报错。
- 模板名称非空；删除二次点击确认。
- 模板目录随工作区备份复制；不进入对象存储 GC。

### 历史

- schema v13 `doc_history(id,node_id,content,word_count,created_at)`，节点删除级联删除。
- 保存时若距上次快照 ≥10 分钟，写一份当前正文；首次保存也写。
- 单篇最多 50 份，超出删除最旧。
- 恢复：读取快照 → 用当前 `doc_version` 保存 → 编辑器丢弃本地 dirty 并重新加载。
- 快照只保存正文；不保证附件/画板图片历史。

### 打印

- `app_print_main_window` 调用 Tauri `WebviewWindow::print()`；前端先 flush。
- 打印 CSS 隐藏侧栏/顶栏/页头/信息浮窗/Toast，正文高度自适应。

### 放映

- 画板页头「放映」与 `⌘P`（应用内快捷键）进入；固定层覆盖应用 chrome，尝试 HTML 全屏。
- Excalidraw `zenModeEnabled` 打开；Esc 或「退出放映」按钮退出。
- 浏览器全屏被 Esc 原生退出时，`fullscreenchange` 同步撤掉固定层。

### 存储告警

- `attachment_stats` 新增 `diskFreeBytes`（Unix `statvfs`；其他平台 null）。
- 剩余 <256 MB 时上传入口拒绝并提示。

### 崩溃草稿

- key `starris.doc.draft.<nodeId>`；保存成功清理。
- 打开文档时草稿 `savedAt > updatedAt` 才提示；恢复后 markDirty，由正常保存落库。

## 4. 验收

- 模板：保存当前文档 → 列表出现 → 使用后新文档正文一致 → 删除后列表消失；E2E 92。
- 历史：两次跨 10 分钟快照 → 恢复最早版本正文一致；E2E 94 + Rust 测试。
- 打印：点击打印打开系统面板（人工/真机）；打印样式不含侧栏。
- 放映：进入显示“退出放映 (Esc)”，Esc 后消失；E2E 93。
- 存储：设置存储页显示剩余空间；低于阈值上传被拒绝（代码审查/单测）。
- 草稿：localStorage 写入/读取/清理；恢复提示可操作（代码审查/浏览器验证）。
- 全量 Rust 91+ 测试、E2E 22/22。

## 5. 风险

- 系统打印面板在 WKWebView 下是否可用需真机确认；不可用时需改为导出 PDF 后打开。
- 历史快照每 10 分钟只有一份，短时间密集编辑只保留首次与下一次；这是有意的存储取舍。
- localStorage 草稿可能包含敏感正文；仅本机浏览器存储，保存成功后清理。
- HTML 全屏 API 在 WKWebView 可能不可用；固定层仍可放映。
