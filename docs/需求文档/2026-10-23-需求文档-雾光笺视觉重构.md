# 需求文档：雾光笺 · 明亮低饱和视觉重构

- 日期：2026-10-23
- 状态：已实现（第十一轮）
- 关联任务：`docs/开发任务清单/2026-10-23-任务-002/`
- 关联设计：`docs/设计/2026-10-23-雾光笺-001/`

## 1. 背景与目标

现有界面在九/十轮迭代中不断叠加白卡与主题色块，用户反馈「太丑了」「完全看不了」。本轮不是补丁式调色，而是重定视觉语言：

1. **明亮小清新**：白/浅色为主，背景近白但不纯白，侧栏有主题浅调。
2. **低饱和、高明度、中对比**：主题色压到中低饱和，文字用中性墨色，保证久看不累。
3. **简洁但不单调**：用雾光 wash、细颗粒纸纹、宋体标题与同心圆建立层次，而不是堆卡片。
4. **高端纹理**：纹理由令牌绘制（SVG 噪点 + 径向渐变），不引入图片资源、不做无限装饰动效。
5. **一次交互反馈闭环**：扁平控件、统一边框口径、工作区入口不再是大白块。

## 2. 范围

### 2.1 本轮实现

- 9 套 light 主题重调，新增 `mist` 雾光青为默认；9 套 dark 强调层保留并复核。
- 主题迁移标记 `appearance.designVersion=2`；旧默认 `sunset` 一次性迁移到 `mist`。
- Rust 主题白名单扩到 9 项 + 单测。
- 壳层：`.app-shell` 三色 wash + 颗粒；`.app-sheet` 18px 圆角纸面。
- 空态：线稿、宋体标题、mono 眉标、浅调 CTA、同心圆。
- 侧栏：透明行、快捷图标底片、透明工作区品牌行；红绿灯去掉胶囊底座。
- 组件扁平化：Button 去掉内高光；菜单/弹窗沿用毛玻璃；对比度门禁覆盖 9 主题。

### 2.2 本轮不做

- 不改信息架构、不改编辑器交互与数据结构。
- 不新增字体文件；不引入第二套动画引擎或第二套纹理。
- 不做自动深色切换；深色仍由用户显式选择。
- 不为历史工作区做逐像素迁移，仅迁移默认主题。

### 2.3 约束

- 组件内禁止硬编码色值；所有颜色来自 `tokens.css`。
- 主题切换只改 `data-theme` / `data-mode`。
- 浅色主题禁止 `primary` 实底 + 白字；浅调底文字必须 ≥4.5:1。
- 必须尊重 `prefers-reduced-motion`。

## 4. 风险与已知限制

- **窗口非前台时 rAF 暂停**：空态入场可能停在首帧，截图需等窗口前台或强制终态；不是渲染缺陷。
- **本轮未重拍编辑器/多标签截图**：编辑器结构与上一轮一致，仅随令牌换色；其视觉复检列入后续真机回归。
- **深色模式**只在对比度脚本中复核，未逐屏截图。
- 迁移只处理「无版本号 + sunset」，若用户曾主动选择 sunset，则视为主动选择，不再迁移（符合“只改默认值”原则）。
