## 1. 背景与目标

当前画板只有 54 行 mock 场景，没有持久化、文件/附件能力，也没有主题适配。目标：

1. 画板 UI 与功能适配 Starris 主题，保留 Excalidraw 本地能力，不遗漏按钮。
2. 画板场景自动保存；图片/附件统一使用全局 `object_id`，不建画板级映射表。
3. 左下角「更多」提供组件库管理，可导入 `.excalidrawlib`。
4. 提供多领域预设组件库，可启用/禁用，并在画板中使用。

## 2. 范围

### 2.1 包含

- v8 表：`board_scene`、`board_viewport`。
- 图片使用全局 `attachment.id` 作为 `object_id`；图片图元 `fileId = object_id`。
- 非图片文件以文件卡片图元组表示，`customData.objectId` 指向全局对象。
- 粘贴/拖放任意文件；从全局附件库插入已有附件。
- 自动保存、单飞、失败重试、切换/退出前 flush、版本冲突。
- Excalidraw 主题、弹窗、按钮、工具栏、侧栏的 Starris 视觉适配。
- v9 组件库表、导入、启用/禁用、预设种子。

### 2.2 不包含

- 多人实时协作、Excalidraw+、分享链接。
- 跨工作区全局对象库（当前对象库为工作区级）。
- 画板历史版本回滚（首版不做）。
- 表格/流程图编辑器。

## 3. 业务规则

1. 画板节点 `type = 3`；场景首次保存时惰性创建。
2. 自动保存只写 `elements_json`/`app_state_json`；不携带文件字节。
3. 图片与附件必须先进入全局对象存储，画板只写 `object_id`。
4. 不建立 `board_file`、`board_object` 等映射表。
5. 画板删除只删画板表；全局对象由附件管理器管理。
6. 全局对象被删除后，画板加载返回 `missingObjectIds`，不阻断打开。
7. 场景保存使用 `scene_version` 乐观并发；冲突不覆盖。
8. 视口单独保存，不更新 `node.update_time`。
9. 自动保存：去抖 800ms、最长 5s、单飞、失败指数退避。
10. 组件库预设只读；导入库可删除；启用状态按工作区持久化。

## 4. 交互与状态

- 画板页头：面包屑 + 保存状态 + 插入附件入口。
- 加载：骨架/引擎加载 → 成功/空画板/失败重试。
- 保存：保存中/已保存/失败重试/冲突重新加载。
- 粘贴：图片走原生 image；非图片生成带格式图标的文件卡片。
- 文件卡片：双击打开/下载；对象缺失提示。
- 组件库：更多 → 组件库管理；列表、启用开关、导入、删除、来源/许可信息。
- 画板 Library 侧栏展示已启用库的组件，可插入画布。

## 5. 数据与存储

```sql
board_scene(node_id PK, elements_json, app_state_json,
            scene_version, element_count, updated_at)
board_viewport(node_id PK, scroll_x, scroll_y, zoom, updated_at)
```

- 图片：`fileId = object_id`（全局 `attachment.id`）。
- 文件卡片：`customData.objectId/name/mime/size/link`。
- 组件库 v9：`board_library` + `board_library_item`（导入/预设；启用状态）。
- 迁移：v7 → v8（画板表），v8 → v9（组件库表）；不改旧表数据。

## 6. 验收标准

| # | 标准 |
|---|---|
| A1 | 新建画板、绘制、等待自动保存、切换/重启后内容一致 |
| A2 | 粘贴图片后 `fileId` 等于全局 object_id；保存不重复上传 |
| A3 | 粘贴 PDF/ZIP 出现带格式图标卡片，重启仍在，可打开 |
| A4 | 插入已有附件不产生新对象 |
| A5 | 全局删除对象后画板显示缺失，不崩溃 |
| A6 | 9 主题 × 明暗切换，画板 chrome 跟随；无硬编码颜色回归 |
| A7 | 工具条/菜单/属性面板/弹窗/右键菜单逐项点击，无按钮遗漏（外部服务项按清单隐藏） |
| A8 | 导入 `.excalidrawlib` 成功；启用/禁用即时影响画板 Library |
| A9 | 预设库覆盖架构/UML/线框/便签/数据可视化等领域 |
| A10 | `cargo test`、`cargo clippy`、`npm run check/typecheck/build` 通过 |

## 8. 风险与未决

- 全局对象删除后画板缺图是无映射方案的直接结果，需接受。
- Excalidraw 内部类名随版本变化；锁定 0.18.1 并做回归。
- Excalifont 许可不明确，继续由构建守卫剔除。
- 社区库页面标注 MIT；单个库的来源/作者需在组件库管理中展示。
