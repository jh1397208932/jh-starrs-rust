# 需求文档 · 主色系统清新化（天空蓝方向）

- 日期：2026-10-21　|　状态：已确认（用户反馈"所有主题颜色温度太高，蓝色要天空蓝的清新感"）

## 1. 问题诊断

底色已二次清新化，但**主色系统（primary/ring/logo/glow）仍偏浓艳**：azure 主色 #1E76D2 是"系统蓝"而非"天空蓝"，其余主题主色同理偏深偏饱和。主色的对比约束：它同时承担按钮白字（≥3:1）与图标/强调文字（对底色 ≥3:1），提亮存在下限。

## 2. 方案（仅 light 模式，dark 与底色不动）

1. **primary 提亮至"白字对比 3.0~3.6"的最透点位**（每个主题各自的可达标极限），色相向清透偏移：azure #1E76D2 → #1F94DE（天空蓝）、midnight → #6873EA、amber → #C68F1A、forest → #339163、rose → #E25A70、violet → #8463E8、graphite → #4A5058；sunset #E8722A 已在极限（3.06）保持。
2. **ring / logo-a / glow-a 跟随 primary**；logo-b 保持深一档（渐变层次）。
3. 激活态文字（accent-fg / sidebar-active-fg）与底色组不动（前两轮已达标）。
4. UI-SPEC §5A 增补「主色透明度极限」说明。

## 3. 验收标准

- 8 主题：primary-fg on primary ≥ 3.0、primary on background ≥ 3.0（图标 AA）、其余指标（muted/sb-muted/border 等）保持达标。
- azure 观感为"天空蓝"；tsc/biome 零问题；截图对比。

## 4. 未决问题

- sunset 橙色已到白字对比极限，无法再提亮（保持品牌橙）；若用户希望橙也变"浅橙"，需改用"浅底深字"按钮风格（另行确认）。
