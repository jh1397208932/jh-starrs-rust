## 1. 范围

- **节点回收站（R11）**：删除进回收站、整棵子树恢复、永久删除、清空、到期自动清理。
- **反向链接与相关推荐（R15）**：从真实检索索引生成，不使用假数据。
- **保留策略（R21）**：孤儿宽限、附件回收站、暂存文件保留时长可在设置内调整。
- **单实例（R22）**：第二次启动聚焦已有窗口，不新开进程。
- **发布 CSP（R18）**：生产构建启用内容安全策略；开发态保留宽松策略以兼容 Vite HMR。
- **导出路径授权（R18）**：导出保存/目录面板由 Rust 打开，签发一次性或目录范围令牌；前端不能直接写任意路径。
- **云同步（R17 最小闭环）**：通过用户选择的云盘同步文件夹交换完整工作区备份，支持立即同步与从最新快照恢复。

## 2. 非目标

- R14 全量国际化仍单独立项。
- 云同步不做服务端账号、协作合并或端到端加密；依赖用户所选云盘自身的同步与加密能力。
- 附件下载仍走前端保存面板，未纳入导出令牌。
- 回收站不跨工作区；删除的节点仍在当前工作区库内。

## 3. 规则

### 云同步与导出授权

- 同步文件夹必须是绝对路径、可写，且不能位于当前工作区内部；配置存全局 `cloud.sync_folder`。
- 「立即同步」复用备份服务写入 `starris-backup-<timestamp>/`；「从云盘恢复」读取最新快照并恢复到空目录后切换工作区。
- 不保存账号密码，不在后台自动覆盖本地或云端文件。
- 导出保存面板由 Rust 调系统对话框；单文件令牌 10 分钟有效且一次即焚，目录令牌只允许写入所选目录及其后代。

### 节点回收站

- schema v14：`node.deleted_at`；删除只打时间戳，不删正文、附件引用、画板场景与历史。
- 文件树、搜索、文档/画板加载、知识库文档计数全部过滤 `deleted_at IS NOT NULL`。
- 删除时移除该子树的搜索索引；恢复时按当前父级重算 level/path 并重建索引。
- 回收站只列根节点；恢复整棵子树。上级仍在回收站时拒绝恢复下级。
- 永久删除/清空回收站才释放 `node_attachment` 引用并标记附件孤儿。
- 到期清理在应用启动时执行，保留天数复用「回收站」设置（默认 30 天）。

### 知识网络

- 反向链接：同知识库内其他文档正文包含当前标题（≥2 字，LIKE 字面匹配）。
- 相关推荐：标题或正文包含当前标题；标题命中的排在前面。
- 只读 `search_index` 并过滤回收站节点；无命中显示空状态，不补假数据。
- 条目点击直接打开对应节点。

### 保留策略

- 工作区级配置存 `workspace_meta`：未使用附件 1–365 天、回收站 1–365 天、临时文件 1–168 小时。
- 默认值保持 7 / 30 / 24；非法或损坏值回退默认。
- 看门狗、立即清理、节点回收站到期清理共用同一份配置。

### 单实例与 CSP

- `tauri-plugin-single-instance` 最先注册；第二实例聚焦、还原并显示主窗口。
- 生产 CSP：脚本仅同源；样式允许内联（Tiptap/Excalidraw）；图片/媒体允许 data/blob；IPC 允许 `ipc:` 与 `http://ipc.localhost`。
- 开发态 `devCsp: null`，避免 Vite HMR 内联脚本被拦截。

## 4. 验收

- 删除文档后文件树/搜索/打开均不可见；回收站可恢复且正文、附件引用完整。
- 永久删除后数据库行移除、附件进入孤儿流程；超过保留期启动时自动清理。
- 两篇互不相关的文档不会互相推荐；提到标题的文档出现在反向链接并可打开。
- 设置中修改回收站天数后写入 `workspace_meta`，维护读取同一值。
- 第二实例启动不产生新进程（单实例插件；真机 E2E 顺序启动不冲突）。
- `npm run build` 在 CSP 配置下通过；生产包启动无 CSP 拦截（待打包验证）。
- 云同步：连接目录 → 立即同步生成含 `backup.json` 与工作区库的快照；从快照恢复后正文回到同步时状态。
- 导出令牌：单文件令牌二次使用被拒绝；目录令牌只允许后代路径。
- Rust 96 项测试、E2E 全量通过。

## 5. 风险

- 反向链接基于标题字面匹配，标题改名或正文改写会即时改变结果；这是可解释的轻量方案。
- 回收站期间附件不释放空间；需要空间时应清空回收站或等待到期。
- CSP 对 Excalidraw 的 worker/blob 行为敏感；若生产包出现拦截，需要按控制台逐项放行。
