# 需求文档 · 界面精简与浮窗互斥（含多平台打包配置）

> 日期：2026-10-28 ｜ 关联任务：docs/开发任务清单/2026-10-28-任务-002 ｜ 状态：已确认（用户口头拍板 + 截图标注）

## 1. 背景

用户在实际使用中指出：① 画板/思维导图视图右侧的浮窗开关按钮没有作用；② 「表格」「流程图」两种节点类型不是想要的产品方向，要求先全部清理；③ 文档大纲当前藏在文档页头工具栏的下拉菜单里，位置与样式简陋；④ 右侧浮动按钮应当打开大纲，且大纲/信息等浮窗面板互斥。

## 2. 目标与范围

### 2.1 界面（本次实现）

1. **浮窗按钮只在文档标签出现**：画板、思维导图、收藏、回收站等视图不再渲染右侧浮钮与浮窗。
2. **浮窗互斥**：`信息`、`大纲` 共用一个右侧浮窗位置；打开其一自动关闭另一个；同一点击再次打开的按钮 = 收起。
3. **右侧浮钮改开大纲**：点击右侧浮钮展开「大纲面板」而不是信息面板；信息面板仍从文档页头「信息」按钮打开。
4. **大纲面板重做**：脱离页头下拉菜单，改为与信息面板同规格的右侧浮窗面板（标题 + 层级列表 + 空态 + 点击跳转），样式对齐 `InfoPanel` 的设计规格。

### 2.2 清理「表格 / 流程图」节点类型

- 前端：新建入口（`NODE_KIND_ORDER`）移除两种类型；打开/渲染分支移除（画板只走 `board`；文档只走 `doc`）；文件树/搜索/收藏等按 kind 过滤，**已有历史节点不再展示但保留在数据库**（不做破坏性迁移）。
- 后端：`create_node` 拒绝 type 4/5；`document_service`/`board_service` 的打开校验收窄为 `Doc` / `Board`；`node_service` 移除表格默认 3×3 内容生成；导出的文档过滤移除 type 4。
- 明确不做：删除数据库历史行；Tiptap 文档内表格（这是文档内排版能力，不是节点类型）。

### 2.3 构建与打包（接续任务）

- `package.json` 增加 `debug`（开发调试）、`debug:build`（生产前端 + debug 二进制）、`build:prod` / `build:prod:dmg`（release 生产编译）。
- 生产构建：前端 debug 日志编译期剔除（`logDebug` 仅开发构建）；Vite Oxc 压缩、无 sourcemap；Rust release 已有 `lto/codegen-units/strip/panic=abort`。
- Windows 兼容包：`bundle.windows.webviewInstallMode = embedBootstrapper`（官方方案，Win10 无 WebView2 时安装器内置引导安装）；提供 `build:prod:win` 脚本（需 Windows 或 cargo-xwin 环境，官方推荐各平台分别构建）。

## 3. 验收标准

1. 画板/导图/收藏/回收站视图无右侧浮钮；文档视图浮钮出现且打开大纲。
2. 打开大纲后点击「信息」按钮 → 大纲自动收起、信息展开；反之亦然；再点当前按钮 = 收起。
3. 新建菜单无「表格/流程图」；Rust `create_node` 对 type 4/5 返回校验错误。
4. 文件树/搜索/收藏不出现历史表格/流程图节点；数据库行未删除。
5. 全量黑盒 e2e 通过（22-table-flow 用例随功能移除）。
6. `pnpm/npm run build:prod` 产出 release 包；macOS 包内无 devtools、无前端 debug 日志 IPC。

## 4. 风险与说明

- 历史表格/流程图节点被隐藏而非删除；如需恢复支持，回滚 `NODE_KIND_ORDER` 与过滤即可。
- Windows 包无法在 macOS 上交叉编译 Rust 二进制（Tauri 官方限制），脚本仅在装好 `cargo-xwin` 的环境可用，或用 CI/Windows 机器执行。
