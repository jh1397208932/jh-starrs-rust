# 需求文档 · 表格与流程图复用

| 项 | 内容 |
|---|---|
| 日期 | 2026-10-25 |
| 关联调研 | `docs/产品功能调研/2026-10-25-缺失功能与需求调研-001/调研报告.md`（R16） |
| 目标 | 让已存在的表格/流程图节点可用；不新写编辑器，分别复用文档编辑器与画板 |
| 状态 | 已实现 |

## 1. 范围

- 新建弹窗恢复五类：文件夹、文档、画板、表格、流程图。
- 表格节点（type 4）复用文档编辑器与文档存储；新建时写入默认 3×3 空表。
- 流程图节点（type 5）复用画板（Excalidraw）与 `board_scene` 存储。
- 单篇导出、整库导出、知识库计数覆盖表格与流程图。

## 2. 非目标

- 表格公式、单元格类型、行列冻结等专用电子表格能力。
- 流程图专用连线语义、自动布局、BPMN 形状库；本次直接使用画板组件库与自由连线。

## 3. 规则

### 表格

- `node.type = 4`，正文存 `node.content`，与文档共用 `doc_version` 乐观锁与历史快照。
- 新建时事务内写入 `doc → table → 3×3(tableRow/tableHeader)`，首行为表头。
- 编辑器页头标识「表格」，正文 aria-label 为「表格正文」；其余写作能力（斜杠菜单、附件、查找、历史、打印）保持一致。
- 单篇导出（Markdown/HTML/Word/PDF）与整库导出按文档处理。

### 流程图

- `node.type = 5`，画布存 `board_scene`，与画板共用版本号、组件库、附件图片与视图偏好。
- 打开后使用画板页头与全部画板动作（组件库、附件、放映、导出 PNG/SVG/Excalidraw）。
- 整库导出按画板处理。

### 兼容

- 已创建但此前无法打开的 type 4/5 节点直接沿用新视图，无需迁移。
- 删除、收藏、搜索、树排序行为与其他节点一致。

## 4. 验收

- 新建表格后自动打开编辑器，数据库默认内容为 3 行 × 3 列且首行为表头；单元格输入可自动保存并读回。
- 新建流程图后自动打开画板视图，具备「放映画板」「导出」等入口；`board_scene` 可保存/加载图元。
- 表格可从页头导出；整库导出不跳过 type 4/5。
- E2E 22 覆盖表格/流程图创建、默认表格、输入落库与删除。
- Rust 集成测试覆盖表格默认内容保存/读回与流程图画板往返。

## 5. 风险

- 表格复用富文本编辑器，复杂数据表能力有限；后续如需公式/大数据量表格应另立需求。
- 流程图复用自由画板，不提供语义化流程校验；用户可用形状与箭头自行表达。
