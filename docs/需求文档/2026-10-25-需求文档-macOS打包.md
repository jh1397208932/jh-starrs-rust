# 需求文档 · macOS DMG 打包

| 项 | 内容 |
|---|---|
| 日期 | 2026-10-25 |
| 目标 | 提供可重复的 macOS DMG 打包命令，并产出安装包 |
| 状态 | 已完成 |

## 1. 范围

- Tauri release 构建 + `.app` / `.dmg` 打包。
- 应用名 `Starris`，窗口标题保持「星屿 Starris」。
- DMG 名称、分类、最低系统版本与窗口布局。
- npm 脚本：单架构与 universal 可选命令。

## 2. 非目标

- Apple Developer ID 签名、公证（notarization）与自动更新。
- 图标重绘；沿用现有 `src-tauri/icons`。
- Windows / Linux 安装包。

## 3. 规则

- `npm run package:dmg`：`tauri build --bundles dmg`；`beforeBuildCommand` 已包含前端构建。
- `npm run package`：`tauri build`，按 `bundle.targets` 产出 app + dmg。
- `npm run package:dmg:universal`：需要已安装 `aarch64-apple-darwin` 与 `x86_64-apple-darwin` Rust target。
- 默认最低 macOS 12.0；未配置证书时生成未签名/临时签名包，Gatekeeper 需右键打开。
- 产物路径：`src-tauri/target/release/bundle/dmg/Starris_<version>_<arch>.dmg`。

## 4. 验收

- 命令退出码 0，DMG 文件存在且 `hdiutil verify` 通过。
- 挂载 DMG 可见 `Starris.app` 与 Applications 快捷方式。
- 应用可启动并显示引导/主界面。
- 记录架构、版本、签名状态与产物路径。

## 5. 风险

- 未签名包在他人机器上会触发 Gatekeeper；正式分发需 Developer ID + notarytool。
- universal 构建体积更大，且要求两份 Rust target。
- release LTO 构建耗时较长；与本机 dev 实例并行时 CPU 占用较高。
