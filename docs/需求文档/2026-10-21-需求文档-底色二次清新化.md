# 需求文档 · 底色二次清新化（编辑器/tab 区去浑浊）

- 日期：2026-10-21　|　状态：已确认（用户反馈"编辑器/tab 区域颜色浑浊不够清新，整体主题清新度偏低"）
- 设计参照：Notion / Linear / Things 的浅色基准——chrome 层（侧栏/tab 区）用极低色度灰（chroma ~0.5%），画布（编辑器区）接近纯白，主题感只留一线倾向

## 1. 问题诊断

上一轮已解决文字/边线对比度，但**大面积铺开的底色仍有可感知色度**：sunset 的 sidebar #F6F4EF、secondary #F3F0E9 属"暖灰"，L≈96% 且 chroma 偏高，大面积铺开显雾/浑浊；各主题 secondary/muted 同理。card(#FFF) 与 background 差距过小，画布缺乏"透气感"。

## 2. 方案（仅 light，dark 不动）

1. **画布最亮**：background 提至 L≈98.5~99（如 sunset #FDFDFB），card 保持 #FFFFFF。
2. **chrome 层降色度**：sidebar / secondary / muted 的 chroma 减半（灰更"爽"，主题倾向只留一线）。
3. **accent 微降饱和**（激活底面积小，保留主题味）。
4. **border/input 自动重校准**：底色提亮后对比下降，脚本自动加深至 border ≥1.30、muted-fg ≥4.5 等既有标准。
5. 8 主题全部执行；dark 与品牌色不动。

## 3. 验收标准

- 对比度脚本全绿（沿用上轮阶梯：muted ≥4.5、sb-muted ≥4.5、border ≥1.30、accent-fg/sb-active-fg ≥4.5、fg ≥14）。
- 截图对比：tab 区/编辑器区"雾感"消除，画布透气。
- tsc/biome 零问题。
