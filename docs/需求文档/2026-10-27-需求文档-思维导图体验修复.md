# 需求文档 · 思维导图体验修复与视觉升级（2026-10-27）

## 1. 背景

用户在实际使用思维导图时反馈 15 个问题：页面闪烁、大纲闪烁、标签/备注不可见、链接不能跳转、默认配色发灰、预设色少、下划线样式变空、贴纸与标记溢出且难辨认、内容不自适应、大纲过于简陋且挤占布局、右侧检查器过宽、操作不够流畅缺动画、新导图打开侧栏后中心偏移。目标是一次性修复并统一视觉语言。

## 2. 设计决策

| 问题 | 方案 |
|---|---|
| 1/2 闪烁 | 大纲与检查器改为**画布上的浮动浮层**（不再改变画布尺寸）；画布节点不再整体重建（签名去重）；移除布局 transform 过渡；聚焦定位只在显式导航时触发；用户未手动平移时窗口尺寸变化自动回到中心 |
| 3/4/10 标签·备注·标记 | 节点悬停卡片展示完整文本、备注、标签、链接与标记中文名；标签 chip 直接显示 `#标签`；标记带中文 tooltip 与可辨识图形 |
| 5 链接 | 链接按钮通过 Tauri opener 打开系统默认浏览器（仅 http/https/mailto） |
| 6/7 颜色 | 新增「缤纷」主题并作为新导图默认；导图内部使用独立的鲜艳分支色（不再继承全局主题）；边框色板 12 → 32 色（含 4 个旧色兼容） |
| 8 下划线 | 下划线只去掉上/左/右边框，保留内容与浅色底；选中态仍可见 |
| 9 贴纸/内容溢出 | 贴纸、标记、标签、编号全部收进节点内部的可换行行，不再绝对定位溢出；测量把标记/贴纸计入高度；文本宽度上限提升并可自动增高 |
| 11/12 大纲 | 浮动卡片（左侧浮层），丰富层级缩进、分支色点、主题计数与空态；不参与布局 |
| 13 动画/流畅 | 节点入场淡入缩放、悬停浮起、选中描边过渡；浮层用 Motion 滑入；画布只渲染可视节点；移除每帧都会触发的过渡 |
| 14/15 检查器与居中 | 检查器为右侧浮动窄卡（300px，可关闭），不改变画布宽度；新导图/未手动平移时画布始终把根主题放在可视中心 |

## 3. 范围

- 前端：节点渲染、标记/贴纸、检查器、大纲、画布交互与动效、配色与尺寸测量、外部链接。
- 后端：主题枚举新增 `vivid`；32 色板校验；新导图默认主题改为 `vivid`（旧数据不变）。
- 不做：远程图片、多人协同、导出器主题扩展（沿用现有导出逻辑）。

## 4. 验收标准

1. 打开/关闭大纲与检查器时，画布宽度和视口中心不变，无闪烁。
2. 节点文字、编号、贴纸、标记、标签、备注入口全部位于节点边界内；长内容节点自动增高；标记可读出含义（悬停/图例）。
3. 超链接点击后由系统默认浏览器打开。
4. 新导图默认鲜艳配色；边框色板 32 色；切换「跟随应用主题」仍可用。
5. 下划线节点仍显示文字与浅底，不再“变空”。
6. 大纲为左侧浮动卡片，含层级缩进、分支色点、主题总数。
7. 全量真机 E2E 通过（30 例，含新增 26b 视觉用例）；无窗口逻辑烟雾与门禁全绿。

## 5. 风险

- 浮动浮层在小窗口可能遮挡画布：限制宽度并提供关闭/收起。
- 新导图默认 `vivid`；旧数据 `auto` 打开时按 `vivid` 渲染并在首次编辑后落盘，不主动改写 `content_json`。
- 新增动画遵循 `prefers-reduced-motion`。
