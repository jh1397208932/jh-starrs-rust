## 1. 背景与目标

- 当前顶栏只有搜索外观，没有索引与命令；快速跳转/放映仍是不可用动作；编辑器没有查找。
- `doc_block_hash` 只在一篇文档保存时回收；删节点/知识库后残留。
- `storage/objects` 下没有数据库行的文件不会被扫描；崩溃或手工复制会永久占盘。
- 本轮实现：工作区内搜索、快速跳转、文档内查找、块哈希 GC、对象孤儿文件隔离。

## 2. 范围与非目标

**范围**

1. 当前知识库内的节点标题搜索 + 文档正文搜索；结果可点击打开。
2. 空查询的快速跳转：最近更新的节点。
3. 文档内查找：`Mod+F` 打开、高亮、上/下一处、计数、Esc 关闭。
4. 维护任务回收无 `doc_block_tree` 引用的 `doc_block_hash`。
5. 维护任务扫描 `storage/objects/big` 与 `storage/objects/small/packs`，把无 DB 行且超过 24h 的文件移入 quarantine；quarantine 保留 7 天。
6. schema v12 新增 FTS5 索引；旧库迁移回填。

**非目标**

- 跨知识库搜索/切换后打开（v1 只搜当前知识库；后续可扩展）。
- 搜索画板内部文本、附件二进制内容、OCR。
- 正则搜索、替换、全词匹配、搜索历史。
- 删除 quarantine 中未过期文件；只按 7 天清理。
- 不做单独的搜索引擎进程或新依赖。

## 3. 规则

### 3.1 索引

- FTS5 表 `node_search`：`title`、`body`（可检索），`node_id`、`kb_id`、`node_type`、`updated_at`（UNINDEXED），`tokenize='trigram'`。
- 所有节点创建/改名/移动/删除都维护索引；文档保存更新正文纯文本；附件/画板/表格/流程图只索引标题。
- 索引写入与节点/文档事务同事务，失败回滚，避免“正文保存了但搜不到”。
- 迁移 v12 从 `node` + `doc_block_meta.markdown` 回填；`doc_version` 等 v11 数据保持不变。
- 删除节点/知识库时删除对应索引行；知识库删除按 `kb_id` 清理。

### 3.2 查询

- 查询字符串 trim 后为空：返回最近更新的 20 个节点（标题/类型/更新时间），供快速跳转。
- 字符数 ≥3：`MATCH` + 引号转义；按 `bm25` 排序，限制 50 条。
- 字符数 1–2：`LIKE '%q%'` 回退（FTS trigram 无法命中 2 字），限制 50 条，按更新时间倒序。
- 只搜当前知识库；返回标题、知识库名、节点类型、片段、更新时间。
- 结果片段由 SQL `snippet` 或 Rust 截取；不返回完整正文。
- 查询失败显示错误，不静默空结果。

### 3.3 快速跳转与打开

- 顶栏搜索按钮打开“搜索”模式；`Mod+K` 打开“快速跳转”模式（空查询，最近节点）。
- 上下键移动、回车打开、Esc 关闭；点击结果也可打开。
- 结果节点必须在当前文件树中；找不到提示“内容可能已被删除”并刷新树。

### 3.4 文档内查找

- `Mod+F` 打开页内查找条；输入即时高亮所有匹配（ProseMirror Decoration）。
- 显示“当前 / 总数”；Enter/下一处、Shift+Enter/上一处；Esc 关闭并清除高亮。
- 不修改文档内容，不进入撤销栈。
- 大小写不敏感；空查询清除高亮。

### 3.5 块哈希 GC

- 维护任务执行：`DELETE FROM doc_block_hash WHERE NOT EXISTS (SELECT 1 FROM doc_block_tree WHERE hash = doc_block_hash.hash)`。
- 与文档保存的即时回收互不冲突；保存路径保留现有逻辑。
- 计入维护结果 `docHashesRemoved`；不删除仍被任何文档引用的 hash。

### 3.6 孤儿文件隔离

- 扫描 `objects/big/<hh>/<hh>/<64hex>`：只处理文件名是 64 位小写十六进制、mtime > 24h、且 `attachment_blob` 无该 hash 的文件。
- 扫描 `objects/small/packs/*.pack`：只处理 mtime > 24h、且 `attachment_pack` 无该 id 的文件。
- 不处理 `tmp/`（由 staging 清理负责）、不处理未知扩展名/隐藏文件。
- 移入 `storage/quarantine/<UTC 时间戳>/<相对路径>`，保留 7 天；清理时只删除 quarantine 下超过 7 天的目录。
- 维护结果新增 `orphanFiles`、`quarantineFiles`；日志只写相对标签，不写完整用户路径。
- 任何移动失败只记录并保留原文件，不视为删除成功。

## 4. 数据与迁移

```sql
-- v12
CREATE VIRTUAL TABLE node_search USING fts5(
    title, body, node_id UNINDEXED, kb_id UNINDEXED, node_type UNINDEXED, updated_at UNINDEXED,
    tokenize='trigram'
);
INSERT INTO node_search(node_id, title, body, kb_id, node_type, updated_at)
SELECT n.id, n.title, COALESCE(m.markdown, ''), n.knowledge_base_id, n.type, n.update_time
FROM node n LEFT JOIN doc_block_meta m ON m.id = n.id;
```

- `SCHEMA_VERSION=12`。
- 索引表无外键；由业务事务维护。
- 迁移前备份沿用 R03 的 `db/backups/` 机制。
- 纯文本提取：遍历 TipTap JSON 的 `text` 节点，用空格连接；不包含附件字节/URL。
- 搜索命令：`search_nodes(input)`；输入 `query`、`knowledge_base_id`、`limit`（默认 20，最大 50）。
- 返回 `SearchHit[]`：`nodeId`、`title`、`kbId`、`kbName`、`nodeType`、`snippet`、`updatedAt`。

## 5. 交互状态

| 场景 | 表现 |
|---|---|
| 搜索面板打开 | 自动聚焦输入；空查询显示最近节点；加载中显示“正在搜索…” |
| 无结果 | “没有找到匹配内容”，保留输入 |
| 查询失败 | 红色错误条 + 重试，不清空输入 |
| 快速跳转 | 标题“快速跳转”，空查询最近节点；不请求全文 |
| 文档内查找 | 页内条显示计数；无匹配显示“0 / 0”；关闭清除高亮 |
| 索引迁移 | 旧库打开时一次回填；日志记录节点数；失败回滚迁移 |

## 6. 验收标准

### 搜索/跳转

- [ ] 新建文档标题“星屿检索验证”，搜索“检索验”命中；搜索 2 字“检索”也能命中（LIKE 回退）。
- [ ] 正文包含“穿过正文的关键词”，搜索 3 字以上命中并显示片段。
- [ ] 改名后旧标题不再命中，新标题命中。
- [ ] 删除节点后结果消失；知识库删除后不残留。
- [ ] `Mod+K` 打开快速跳转，空查询显示最近节点，回车打开。
- [ ] 搜索面板支持上下键/回车/Esc/点击；结果点击打开正确文档。

### 文档内查找

- [ ] `Mod+F` 打开查找条；输入关键词高亮全部匹配并显示计数。
- [ ] Enter/Shift+Enter 在匹配间移动；Esc 关闭并清除高亮。
- [ ] 查找不修改正文、不产生保存。

### 存储闭环

- [ ] 删除文档/知识库后维护删除无引用 `doc_block_hash`；仍被其他文档引用的保留。
- [ ] 在 objects/big、packs 放无 DB 行且 mtime>24h 的文件，维护后进入 quarantine；有 DB 行的文件不动。
- [ ] quarantine 超过 7 天的目录被清理；未过期保留。
- [ ] 维护结果返回 `orphanFiles`、`quarantineFiles`、`docHashesRemoved`，UI 提示包含数量。
- [ ] 现有附件生命周期、pack 压缩、导入导出测试全部通过。

### 质量门禁

- [ ] Rust 全量测试、clippy、fmt；前端 check/typecheck/build；真机 E2E（新增搜索/跳转/查找/GC 用例）。
- [ ] schema v12 迁移测试与旧库备份测试通过。

## 7. 风险与未决

1. **中文 2 字查询**：FTS trigram 不支持 2 字；走 LIKE 全表扫描，数据量大时需评估；当前限制 50 条，可接受。
2. **索引体积**：FTS 保存标题+正文副本；先接受，后续可改 external content。需在 1 万文档基准测量。
3. **正文来源**：保存时从 TipTap JSON 提取纯文本，可能包含 Markdown 标记（例如 `#` 是节点属性，不在 text 中）；搜索以纯文本为准。
4. **跨知识库搜索**：v1 只搜当前知识库，结果不跨 KB；后续如需要，需实现切换 KB 后打开。
5. **孤儿扫描**：只处理符合命名规则的文件；未知文件保留，避免误删。quarantine 占空间 7 天。
6. **快捷键**：`Mod+Shift+F` 可能被 WKWebView 保留；若真机不触发，顶栏按钮仍可用，后续可在菜单层注册。
