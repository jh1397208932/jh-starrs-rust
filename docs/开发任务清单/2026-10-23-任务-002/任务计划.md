# 任务-002 计划：雾光笺视觉重构

- 日期：2026-10-23
- 关联需求：`docs/需求文档/2026-10-23-需求文档-雾光笺视觉重构.md`
- 关联设计：`docs/设计/2026-10-23-雾光笺-001/`

## 1. 问题

用户判定当前 UI「完全看不了」：白卡层层堆叠、按钮带内高光、主题色铺得过多；随后逐条指出快捷钮/CTA 太立体、两组按钮边框不一致、左上工作区按钮白色区域过大。

## 2. 目标

用「主题浅调画框 + 近白纸面 + 三色雾光 + 细颗粒」重建视觉语言；控件全扁平；工作区入口改为透明品牌行；9 主题统一低饱和高明度，默认 mist。

## 3. 步骤

1. 重写 `tokens.css`：9 套 light + dark 强调层；统一中性墨色；新增 `wash-1/2/3`、`texture-grain`。
2. 重写 `app.css` 壳层与侧栏：app-shell 雾光/颗粒、app-sheet 纸面、空态同心圆、透明工作区行、快捷图标底片。
3. 组件扁平化：`button.tsx` 去掉内高光；`empty-state.tsx` 线稿/眉标/宋体标题；`TrafficLightSlot` 去掉胶囊。
4. 侧栏：工作区入口切透明行；hover 降至 24–28% 白；红绿灯槽位只留拖拽区。
5. 主题系统：`theme.tsx` 加 mist 默认 + designVersion 迁移；设置页 9 卡；Rust 白名单 + 单测。
6. 门禁：contrast 9 主题、Biome、tsc、Vite build、licenses、cargo test。
7. 截图：空态（mist）、设置（mist）、第二主题（midnight）；更新 UI-SPEC / DESIGN_TOKENS / UX_SPEC / 日志 / 记忆。

## 4. 风险

- 移除红绿灯胶囊底座后，失焦灰点缺少承托；实测浅色画框上三色点仍可辨识，故接受。
- 9 主题对比度脚本若只按 mist 调参，其它主题可能破线；因此脚本从令牌现算，全主题跑。
- 主题迁移写 `memory_save` 时若 Rust 白名单未同步会静默失败；用单测固定 9 项。

## 5. 验收

见需求文档 §3。所有门禁 exit 0 后，再以真机截图确认视觉终态。
