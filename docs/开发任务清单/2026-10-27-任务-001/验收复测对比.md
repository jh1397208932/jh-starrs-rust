## 6. 动效体系二次收敛（2026-10-28）

目标：把「有动效」升级为「连贯、克制、有来源」的动效，统一到设计语言 §6 的时长/缓动刻度，并修掉入场跳变。

| 项 | 旧值 | 新值 | 影响面 |
|---|---|---|---|
| 时长令牌 | 150 / 300 / 500ms | 120 / 220 / 380ms，统一乘 `--seed-motion` | 全站过渡 |
| 标准缓动 | `cubic-bezier(.25,1,.5,1)` 命名为 `--ease` | `--ease-out = cubic-bezier(.22,1,.36,1)`，`--ease` 指向它 | 全站过渡 |
| 弹性 | 所有 pop/dialog 走 `--ease-pop`（过冲 1.36） | 仅开关/点睛元素用 `--ease-spring`（1.56）；弹层与大面板走 `--ease-out`，不再回弹 | 菜单/弹窗 |
| 浮层入场 | 4px + 0.98 | 6px + 0.97（220ms 入 / 120ms 出） | 菜单、Select、Tooltip、编辑器浮层 |
| 模态入场 | 8px + 0.97 + 过冲 | 10px + 0.975，无过冲；出场 120ms | 全部 Dialog |
| 标签内容切换 | 4px + 0.98（整块缩放） | 只 6px 上移，不缩放 | TabsContent / 视图切换 |

组件级补齐（全部落在 `components/ui` 封装层或共享 CSS）：

- **浮层从触发器展开**：DropdownMenu / Select / Tooltip 使用 Radix 的 `--radix-*-content-transform-origin`，不再从自身中心“弹出”。
- **Tab 下划线**：触发器 `::after` 以 `scaleX(0→1)` 从中间展开（200ms），替换原先 2px 边框瞬切。
- **文件树**：折叠箭头改单图标 `-rotate-90` 过渡（150ms）；展开子树整体 120ms 淡入上移；不做高度动画（避免逐帧布局）。
- **开关**：底色 220ms；滑块走弹性曲线。
- **按压缩放**：Button 全局 `active:scale-[0.97]`；侧栏品牌行/快捷入口/底部更多、窗口标签与关闭键、文档页头图标钮、画板页头、查找栏、设置卡片、看板页头按钮均补 active 反馈。
- **悬停点睛**：快捷入口图标与设置卡片悬停上浮 1px；标签关闭键悬停放大。
- **居中浮层跳变修复**：编辑器气泡的颜色/链接面板原本 `anim-pop-in` 会覆盖基类 `-translate-x-1/2`，动画结束瞬间向左跳半宽；新增 `anim-pop-in-center`（关键帧自带 -50%）修正。

**动效取证（真机录屏，60fps 抽帧）**：打开「更多」菜单的入场变化跨 **14 个连续帧（≈230ms）**，逐帧差分单调衰减（0.516 → 0.330 → 0.228 → 0.136 → … → 0.015），呈标准减速曲线，无单帧跳变。产物：`/tmp/starris-motion.mov`（本机临时文件，不入库）。

### 6.2 独立代码审查与修正（同日）

独立审查发现并已修复的问题（均为本轮新引入或遗漏，非历史缺陷）：

1. **Tailwind v4 的 `translate`/`scale` 是独立属性**（构建产物里 `-translate-x-1/2` 输出 `translate:-50%`）。我先前新增的 `anim-pop-in-center` 关键帧又自带 `translate(-50%)`，与类上的 `translate` 叠加成 -100% → 气泡面板入场会左移半宽。**已回退为 `anim-pop-in`**（关键帧只动 Y 与缩放，二者正常叠加），删除该变体。
2. **`transition-[…,transform]` 不覆盖 `scale`/`translate`**：窗口标签关闭键、文档/画板/导图页头、查找栏、设置卡片等处的缩放/上浮原本是瞬变。已改为 `transition-[…,scale]`（设置卡片补 `translate`）。Tab 下划线同理改为 `after:transition-[scale,opacity]` 且时长走 `--dur-2`。
3. 树行退出期仍可点击：`useIsPresent()` 在退出时设 `pointer-events:none`。
4. `dismissStrayPanels` 读到空树时先复核一次（250ms）再按 Escape，避免 AX 瞬时重建误关浮层。
5. 减少动态效果时 Motion 的 whileTap 会被降级 → Button 保留 `active:opacity-90` 作为静态反馈。
6. 清理：移除未使用的 `--ease-pop`；修正 BlurFade 过期注释；检查表第 22 行改为“药丸去实时 blur”。
7. **CSS 层叠顺序**：`app.css` 是**无层样式**，会压过 Tailwind v4 `@layer utilities` 里的工具类。我一度在 `.anim-pop-in` 上写了 `transform-origin: top center`，于是 Radix 的 `[transform-origin:var(--radix-…)]` 失效——浏览器实测 origin 变成 110px（自身中心）而不是触发器的 0px。已删除该行；复测菜单 origin 回到 `0px 0px`。

审查通过项：Button 的 `HTMLMotionProps` 化类型与 `type/disabled` 传递正常、无双重缩放；`layoutId` 药丸单实例无残留；reduced-motion 双链路覆盖；三个文件仅格式化无语义变化。

### 9.2 原生毛玻璃

`tauri.conf.json`：`transparent: true` + `windowEffects { underWindowBackground, followsWindowActiveState, radius 12 }`；`html/body` 透明，`.app-shell` 86%、`.app-sheet` 92–94% 半透明，浮层 90–95% + 12px blur + saturate。大面积模糊交给 macOS 原生 vibrancy，WebView 不再承担整窗模糊。

判定实验：临时把壳层 alpha 降到 30% 并 `tauri build` 后采样屏幕像素——同一 UI 在亮/暗背景下读值不同（sheet 182 vs 162），证明透明链路真实生效；随后恢复 86/92–94% 以保文字对比度。

### 9.3 拖拽连续性

- **弹窗拖动**：Motion `dragControls`，仅标题区/顶边 10px 起拖，按钮/输入框排除；实测拖拽 translate(120, 90) 跟手，从关闭键起拖不移动；关闭后重开自动归位。
