## 3. 事实结论（不粉饰）

1. **平台封顶 60fps 已坐实**；120fps 不在当前栈能力内。
2. 已落地修复（模糊预算、memo 边界、指针合帧、标签并行过渡、草稿节流、封装层按压反馈）在**机制层均成立**（代码可核），但**本机在本轮可用的干净数据中未测出稳定的帧率提升**；差异多在 ±5ms 噪声带内，长帧尖峰（130-180ms）集中在**视图/编辑器挂载**与**主题切换**。
3. 因此「所有交互零掉帧」的验收 **未达成**；不能宣称性能已优化到位。
4. 两次全量复测被环境因素作废（并发重活、设备休眠）——采集纪律已写入 `docs/记忆`：采集期必须 `caffeinate` 且禁止任何并发命令。

## 4. e2e 全量失败复盘（2026-10-28）

首轮全量：30 用例 / 通过 11 / 失败 19（真实退出码 1）。逐因定位：

| 现象 | 证据 | 结论 |
|---|---|---|
| `10-shell` 失败（等待「新建工作区」） | 失败截图：主界面正常、工作区切换浮层未打开；隔离复跑 `--case=00-onboarding,10-shell` **PASS** | 长跑下的 AX/Radix 弹层时序抖动，**非代码回归** |
| `30-doc` 失败（等待 `E2E Doc.docx`） | 失败截图：系统保存面板仍停在 `E2E Doc.html`、背后显示「正在导出…」；隔离复跑 `--case=00-onboarding,20-tree,30-doc` **PASS**（含 docx 导出） | 原生保存面板在长跑/高负载下未被驱动完成，**非导出功能缺陷** |
| 其余 19 个 0 点击连环失败 | 均发生在 30-doc 之后、耗时 ~8.9s | 卡住的系统保存面板进入模态循环 → AX 整树不可用 → 级联 |

加固（`test/e2e/run.mjs`）：`dismissStrayPanels` 在 **AX 树不可读/为空**（原生 sheet 模态的典型表现）时也按一次 Escape 兜底；AX 树正常且无 Cancel 时仍不按，避免误关下一个用例的弹窗。

加固后重跑全量（2026-10-28 10:23，`caffeinate`）：**30 用例 / 通过 28 / 失败 2**，级联消失（30-doc 全通过）。剩余两例隔离复跑均 PASS：
- `10-shell`（等待「通用」失败）→ `--case=00-onboarding,10-shell` **PASS**
- `22-table-flow`（等待菜单项「删除」失败）→ `--case=00-onboarding,20-tree,22-table-flow` **PASS**

结论：全量 28/30，两例为长跑下 AX/弹层时序抖动，非代码回归；e2e 硬门的 2 个残余抖动需后续单独立项（harness 时序加固），不阻塞业务结论。
