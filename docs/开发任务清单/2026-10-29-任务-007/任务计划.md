# 任务计划：思维导图体验与极限场景（大纲 / 连接线 / 配色 / 性能 / 磁盘）

- 任务编号：2026-10-29-任务-007
- 关联需求：用户 2026-10-29 反馈（大纲深层级右侧面板、边框配色、极限性能、磁盘写满）
- 开始日期：2026-10-29

## 目标

1. **大纲层级变深后右侧不可达**：面板宽 300px 且 `overflow: hidden`，行缩进按 `6 + 深度*14` 无上限增长 → 文本尾巴、hover 动作按钮与横向滚动条被推出面板，既看不见也拖不到；在大纲里点行右侧检查器也不出现。
2. **节点一多连接线消失**：父子线走 React Flow 的 edge 通道，端点节点不在视口内就没有测量结果，`getEdgePosition` 返回 null → 整条线静默丢弃；时间线/鱼骨/向上 org 还引用了节点上不存在的 handle id。
3. **选中主题输入时其他节点发虚**：编辑态把被编辑节点切成不透明白卡，周围彩色淡底被压灰；显式导航又把画布强设成 1.05 非整数缩放，整屏文字按非整数设备像素重采样。
4. **边框颜色太浅**：分支色描边只混 62% 分支色 + 中性边框，填充仅 16%，整体偏灰。
5. **高频输入卡死 + 磁盘被写满**：外壳复用缺陷已在任务前修复（`buildTree` 重复灌子节点，40 次自动保存后侧栏 38.4 万行）；本条继续收敛保存链、测量缓存与构建产物，给磁盘写入加硬上限。
6. **每个功能都要极限场景测试**：新增纯逻辑烟雾用例（缩进封顶、连接线完整性）与一条真机极限用例（24 层大纲 + 20 次高频新增 + 8 种结构）。

## 范围

- 前端：思维导图画布/大纲/检查器/配色、文件树回调稳定性、持久化防抖链。
- Rust：AI 审计与待审区的保留策略。
- 脚本/构建：e2e 构建新鲜度判断、测试包装日志硬上限、cargo dev profile。

## 不做

- 不做增量布局（布局仍按整树计算，属独立课题）。
- 不引入新依赖（边绘制只用已有 `@xyflow/react` 的路径函数）。
- 不改主题令牌体系，只在 `mindmap.css` 内提亮分支配色。

## 关键风险

- 连线改自绘后，关系线的点选必须仍可用（已补 `pointer-events: stroke` 与键盘可达）。
- 删除节点上的 `Handle` 会影响任何依赖 handle 的交互；本项目 `nodesConnectable={false}`，不涉及连线拖拽。
- `[profile.dev] debug = "line-tables-only"` 会让下一次构建全量重编一次，但之后 target 体积显著下降。

## 验收标准

- `node test/smoke/run.mjs` 全绿（含新增缩进与连接线用例）。
- `npm run typecheck`、`node scripts/check-contrast.mjs --check`、`npm run check:mindmap-colors` 全绿。
- `cargo test` 全绿（含新增 AI 历史保留用例）。
- 真机：26c 极限用例通过（深层大纲右侧检查器可达、高频新增不卡死、8 种结构连接线完整）。
