# 任务计划：Windows 平台适配与开源文档重整

- 任务编号：2026-10-31-任务-001
- 关联需求：[2026-10-31-需求文档-Windows适配与开源文档](../../需求文档/2026-10-31-需求文档-Windows适配与开源文档.md)
- 目标平台：Windows 10/11 x64（主验证），macOS 12+（不回归）

## 1. 目标

1. 在 Windows 环境完成依赖安装、`cargo check`、前端构建与 NSIS 安装包。
2. 为 Windows/Linux 实现自绘窗口控制与平台化 UI（快捷键文案、拖拽区、菜单策略）。
3. 审计并修复工作空间、路径、文件操作、附件、导入导出等平台差异。
4. 重写开源 README，并补全架构、时序、数据流、生命周期、ERD、交互与质量门禁图。

## 3. 依赖与风险

- 依赖：Node 24 / npm 11、Rust 1.99 MSVC、VS 2026 + MSVC 14.51、Windows SDK 10.0.26100、WebView2 156。
- 风险：无代码签名 → SmartScreen 提示；无边框窗口圆角依赖系统；macOS 侧未真机回归；黑盒自动化工具缺失时只能做编译与手工冒烟。
- 磁盘：`node_modules` 约 525 MB，`src-tauri/target` 调试 + 发布缓存约数 GB；不额外安装大型工具，仅复用现有 VS/Rust/Node。
