# 任务计划 · 思维导图（2026-10-26-任务-014）

- 关联需求：`docs/需求文档/2026-10-26-需求文档-思维导图.md`
- 关联调研：`docs/产品功能调研/2026-10-26-思维导图-001/调研报告.md`
- 引擎：React Flow `@xyflow/react` 12.12.0（MIT 核心）+ Starris 自研树模型
- 授权边界：不使用 React Flow Pro 示例、付费组件或闭源素材；画布不显示归属角标，在“关于”中列明 MIT 归属

## 目标

新增 `mindmap` 内容类型，完成创建、编辑、自动保存、回收站、搜索、导入导出、整库导出、备份恢复和真机回归的完整闭环。

## 范围

### 后端

- node type 7、schema v14→v15、node 表 CHECK 重建。
- `mindmap_scene`、`mindmap_viewport`、模型、仓储、服务、IPC。
- canonical tree 校验、搜索正文、冲突版本、图片对象引用。
- XMind 现代/旧版、FreeMind、OPML、Markdown、Native JSON 导入导出。
- 整库导出 manifest 与目录导入识别。

### 前端

- 节点类型、文件树、标签页、新建菜单、图标、快捷键作用域、i18n。
- React Flow 懒加载画布、自定义节点/边、布局、命令、撤销、自动保存。
- 页头、工具栏、检查器、搜索、结构/主题、图片插入、导出。

### 测试

- Rust 单测/集成测试、许可证/包体检查、浏览器 smoke、macOS 真机 E2E、性能基准。

## 实施步骤

1. 需求与任务文档、UI 原型。
2. 安装 React Flow 与 Rust 格式依赖，核对官方文档和许可证。
3. 数据层：迁移、模型、仓储、服务、命令、注册。
4. 前端类型与节点接入，先完成空画布加载/保存。
5. 自研树模型、布局、文本测量、React Flow 渲染。
6. 编辑命令、键盘、拖拽、折叠、撤销、搜索、检查器。
7. 格式转换与文件对话框。
8. 回收站、整库、备份、快捷键、i18n、视觉细节。
9. 单测、E2E、性能、门禁、文档和更新日志。

## 依赖与风险

- React Flow 12 受控节点与拖拽语义需按官方文档适配，不能复制 Pro 示例。
- `.xmind` 是事实标准；真实 XMind 打开验证需要安装 XMind 的环境。
- SQLite node CHECK 需要重建表，迁移必须先备份并做 `foreign_key_check`。
- 图片主题依赖附件对象引用计数，删除/恢复必须闭环。
- 5,000 主题布局与 WKWebView 性能需实测。
