# 任务计划 · 第三方依赖许可证审查与门禁（2026-10-22-任务-002）

- 需求来源：用户要求核对 Tiptap 编辑器组件许可，并确保项目不存在非开源、需要开源或需要商业授权的产品。
- 目标：
  1. 给出 Tiptap 3.32.0 全部引入包的许可结论；
  2. 对前端（含嵌套依赖）、Rust 依赖与随包字体做许可证审查，列出禁止项与弱 copyleft；
  3. 增加可复跑门禁，保证后续新增依赖不会破坏规则。

## 方案

- 审查脚本 `scripts/check-licenses.mjs`：
  - 遍历 `node_modules` 读取 `license`/`licenses`，缺失时读取 `LICENSE*` 文件推断；
  - `cargo metadata --offline` 读取 Rust 依赖许可；
  - 检查 `dist` 产物字体是否在开源白名单；
  - OR 表达式任一分支宽松即通过；仅弱 copyleft 警告；强 copyleft/商业/不明失败。
- 构建防线 `vite.config.ts` 的 `fontLicenseGuard`：打包阶段删除白名单外字体资产（Liberation 旧许可、Excalifont 许可未明确等）。
- `npm run build` 末尾追加 `check:licenses`，许可证失败即构建失败。
- 输出 `docs/开发/第三方依赖许可证审查.md`，记录结论与证据来源。

## 拆分步骤

1. `npm view` + 已安装包元数据核对 Tiptap。
2. 全量 npm/Rust 许可证扫描。
3. 解析 WOFF2 字体 name 表，核对随包字体许可与产物字体。
4. 实现 `check-licenses.mjs` 与 Vite 字体守卫，接入 build。
5. 跑门禁与构建，归档报告。

## 验收标准

| 编号 | 标准 |
|---|---|
| C1 | Tiptap 全部已安装包许可为 MIT，无 Pro/Cloud 付费包 |
| C2 | 全仓无 GPL/AGPL/SSPL/BUSL/非商业/UNLICENSED/专有依赖（含 OR 分支判定） |
| C3 | 弱 copyleft 项已列明且说明无“开源本项目”义务 |
| C4 | 产物字体仅包含许可明确的开源字体；白名单外字体被构建剔除且门禁失败 |
| C5 | `npm run check:licenses` 通过；`npm run build` 通过 |
| C6 | 审查报告归档并提供可复核来源 |

## 风险

- `@excalidraw/excalidraw` 包内含许可不明确的 Excalifont 与旧许可 Liberation；已通过构建白名单确保不随包分发，但 `node_modules` 中仍存在文件。
- 若未来需要画板使用这些字体外观，必须先替换为许可明确的 OFL 字体并更新白名单。
- MPL-2.0 依赖（lightningcss 等）为弱 copyleft：未修改其文件，无需开源本项目；分发时保留其声明。
