# 任务计划 · 画板组件库与附件收口

- 关联需求：`docs/需求文档/2026-10-29-需求文档-画板组件库与附件收口.md`
- 目标：删除画板附件入口与模块；把组件库面板重做为分类缩略图网格，支持点击与拖拽插入。
- 范围：见需求文档第 2 节；不做自定义组件管理与旧文件卡片恢复。
- 依赖：Excalidraw 0.18（restoreElements / convertToExcalidrawElements / exportToSvg）、现有组件库导入链路、画板自动保存。

## 实施步骤

1. 删除画板附件前端：页头按钮、选择器、文件接入 hook、帮助与快捷键项、导出提示。
2. 删除后端文件卡片判据、sidecar 导出/导入恢复与相关测试；整库导出保留图片 `attach/`。
3. 组件库数据：内置目录 `libraryCatalog.ts`；`useBoardLibraryEntries` 合并内置与导入库；后端组件 DTO 补库名与来源。
4. 面板 UI：分类标签、分区标题、双列缩略图（`exportToSvg` 缓存）、搜索、加载/空态、底部提示。
5. 插入交互：点击插入视口中心；指针拖拽按落点插入，含幽灵、落点框与 click 抑制；ID/分组/绑定重映射。
6. 测试与文档：更新 e2e 40/50/70、性能脚本；补需求文档、任务记录与更新日志。

## 验证项

- tsc、biome、cargo fmt / clippy、后端测试。
- e2e 40：分类切换、缩略图可见、点击插入、拖拽插入。
- e2e 50：无「插入附件」步骤；附件树上传仍正常。
- e2e 70：整库导出不再要求 `attachments.json`。
- e2e 60：组件库导入/启停不受影响。
- 全量真机 e2e：31+ 用例通过。

## 风险

- 缩略图首次生成有短暂延迟；按可见标签生成并缓存。
- 社区 v1 库组件多数无名，只能按文字/图形推导名称。
- 旧导出的文件卡片不再恢复为附件，按普通矩形保留。
