# 任务计划 · 黑盒全量功能测试自动化（2026-10-25-任务-002）

- 关联需求：`docs/功能测试/2026-10-25-黑盒全量功能测试与合理性分析.md`（测试设计与分析）
- 前置任务：`docs/开发任务清单/2026-10-25-任务-001/`（画板导出导入）

## 目标

1. 用真实 Tauri 应用模拟用户操作，覆盖引导、工作区/知识库、文件树、文档、画板、组件库、设置、附件、导入导出、快捷键、收藏、占位视图。
2. 形成 `pnpm run test` 可执行、可扩展的自动化套件。
3. 工作区/导出产物全部落在项目 `tmp/`；测试输入放 `test/fixtures`。
4. 输出每个功能的 UI 位置、操作步骤、点击复杂度与合理性分析。

## 方案

- macOS 原生黑盒：Swift AX 辅助程序 + Node 编排；不 mock SQLite/后端。
- 每次使用 `STARRIS_HOME=tmp/e2e/<时间>/home` 启动 `pnpm exec tauri dev`；首次引导创建 `workspace/`。
- 用例文件导出 `{id,title,area,steps,complexity,run}`；框架统计点击/按键/输入/对话框并生成报告。
- 原生保存/打开面板用 Cmd+Shift+G + 粘贴路径 + 面板按钮。
- 断言：AX 可读文本、真实 SQLite、导出文件签名/JSON 结构、截图。

## 风险

- 需要辅助功能权限和 Xcode CLT；无权限时明确失败。
- 系统文件面板/快捷键有平台差异；路径使用 ASCII `tmp/`。
- 部分功能为 mock/占位（模板库、备份、全局搜索、表格/流程图），测试记录发现而不强行判失败。
- 用例按顺序依赖工作区与基础节点；新增用例需登记，复杂场景可拆独立 scenario。

## 验收

- `pnpm run test` 12/12 通过，报告与截图归档。
- 覆盖与未覆盖项、发现与建议写入分析文档。
- 项目门禁（check/typecheck/build、Rust）不被测试脚手架影响。
