# 任务计划 · 画板导出与导入（2026-10-25-任务-001）

- 关联需求：`docs/需求文档/2026-10-25-需求文档-画板导出导入.md`
- 关联设计：`docs/设计/2026-10-25-画板导出导入-001/说明.md`
- 前序任务：`docs/开发任务清单/2026-10-24-任务-002/`

## 目标

1. 画板页头可选导出 PNG / SVG / Excalidraw。
2. 全部导出纳入画板：同名文件夹、多格式、图片与附件。
3. 导入 `.excalidraw` 为可编辑画板。

## 拆分

1. 需求/设计/任务记录。
2. 后端：画板 snapshot、全部导出画板目录与源文件、写文件 IPC。
3. 后端：`.excalidraw` 导入（图片上传、fileId 改写、附件映射）。
4. 前端：画板导出菜单与官方导出工具落盘。
5. 前端：全部导出补渲染 PNG/SVG、文案与结果合并。
6. 前端：导入过滤器/文案。
7. 测试、门禁、真机与文档收尾。

## 风险

- Excalidraw `exportToBlob/Svg` 在 WKWebView 的字体/图片内联行为需真机校准。
- 全部导出的画板 PNG/SVG 依赖前端渲染；渲染失败不回滚源文件，需明确 warning。
- `.excalidraw` 单文件无法携带文件卡片附件，需在 UI 文案与结果提示中说明。
