# 任务-003 计划：文档操作下沉到正文页头

- 日期：2026-10-23
- 关联需求：`docs/需求文档/2026-10-23-需求文档-文档操作下沉页头.md`
- 关联设计：`docs/设计/2026-10-23-文档页头-001/`

## 1. 问题

第十一轮的单行顶栏同时承载标签、面包屑、保存态、5 个文档操作、搜索与设置；1280px 下信息密度过高，且保存态与正文 `SaveIndicator` 重复。

## 2. 目标

- 顶栏只保留标签页、全局搜索与窗口控制。
- 文档操作与面包屑进入正文页头；保存态只由 `SaveIndicator` 承担。
- 信息浮窗展开时不遮挡页头操作。
- 首次打开文档时目录可用。

## 3. 步骤

1. 精简 `WindowBar`：删除面包屑、保存胶囊、文档操作、设置；清理 props 与导入。
2. 新增 `DocPageBar`：面包屑 + 收藏/目录/信息/分享/打印，目录订阅 `useEditorOutline`。
3. `DocEditor` 页头接入 `DocPageBar`；`TabContentView` / `WorkspaceLayout` 透传回调。
4. 信息浮窗起点下移到 `top-16`。
5. 目录首开修复：加载后 `updateTableOfContents()`，并用来源编辑器过滤旧实例回调。
6. 门禁：`npm run check`、`npm run typecheck`、`npm run build`。
7. 截图：1280×800 下真机页头 + 浏览器桩的页头/信息浮窗/目录四张；更新 UI-SPEC、需求/任务/更新日志。

## 4. 风险

- 操作进入正文后随页面滚动，长文档需回到顶部才能操作；这是“文档页头”的语义，顶栏不再重复入口。
- 信息浮窗仍可能覆盖正文右侧；只保证不覆盖操作行。
- 目录修复涉及异步 TOC 更新，StrictMode 下存在旧实例回调；已加来源校验。

## 5. 验收

见需求文档 §4。所有门禁 exit 0，截图与快照能证明顶栏与页头职责分离。
