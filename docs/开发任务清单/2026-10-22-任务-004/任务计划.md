# 任务-004 任务计划：编辑器数据闭环与交互重构

- 需求：`docs/需求文档/2026-10-22-需求文档-编辑器交互重构.md`
- 日期：2026-10-22
- 目标：修复数据格式/回显、`:null:`、回车样式继承、拖拽与全块样式，新增文档元数据。

## 实现方案

### 后端

1. 工作区库版本 v3 → v4，新增 `doc_block_meta`。
2. `domain/document.rs`：
   - `normalize_document`：根校验、移除非法 emoji、清理 null attrs/空 marks；
   - `extract_blocks` 基于规范化结果；
   - `to_markdown`：Tiptap JSON → Markdown；
   - `document_props`：wordCount/blockCount/version。
3. `services/document_service.rs`：
   - load 返回规范化 doc 及 `normalized` 标记；
   - save 使用规范化 doc 写正文与块树，提交后投递异步元数据任务。
4. `doc_meta` 仓储与后台 writer：独立连接、WAL、busy_timeout；失败仅日志。
5. 集成测试覆盖：旧 emoji 清理、meta 表写入、markdown/prop 内容、重启保留。

### 前端

1. `editorExtensions`：
   - Emoji 移除 `enableEmoticons`，扩展 `renderText/renderHTML` 守卫空 name；
   - 新增 `ClearMarksOnEnter` 扩展（官方 `addKeyboardShortcuts` + command）；
   - StarterKit 配置官方 Dropcursor。
2. `DocEditor`：
   - ~~官方 DragHandle 重做外观与生命周期（滚动/窗口变化隐藏）~~ → 2026-10-22 执行变更：官方 DragHandle 在 WKWebView 下无法完成正文拖拽，依赖已移除；改为 `useBlockHandle` 自绘定位/显隐 + `useBlockPointerDrag` 指针拖拽 + `BlockDragHighlight` Decoration；
   - 增加块 hover 时手柄状态、拖动中状态；
   - 加载后如后端标记 normalized，自动 markDirty 修复落库。
3. 菜单与样式：
   - Slash/Bubble/Context 统一分组、间距、图标、快捷键；
   - 补齐全部块和行内 mark 的样式，包含 resize handle、drop cursor、代码块、表格、图片、details。
4. 浏览器测试页（临时，完成后删除）验证交互与保存 payload。
