## 2026-10-22 追补：自绘手柄与 PointerEvent 拖拽

- 背景：真实 Tauri 窗口复测“手柄能拖、正文不动”。官方 `@tiptap/extension-drag-handle` 把手柄定位与 HTML5 DnD 绑定，WKWebView 对 `dragstart/dataTransfer/effectAllowed` 的处理与 Chromium 不一致；用户决定不再使用官方手柄。
- 完成：
  - 移除 `@tiptap/extension-drag-handle`、`@tiptap/extension-drag-handle-react` 依赖与相关 payload 补丁；
  - 新增 `useBlockHandle`：按顶层块 DOM rect 自绘定位，180ms 离开缓冲，左侧走廊同块行内保持、跨行重新定位，滚动/resize/keydown 隐藏，切换文档时隐藏；
  - 新增 `useBlockPointerDrag`：pointerdown 4px 阈值、指针捕获、顶层落点计算、源块淡化、自绘落点线/类型标签、边缘自动滚动、Escape/blur/pointercancel 取消，松手后派发 `delete + insert` 事务；
  - 新增 `BlockDragHighlight` Decoration（直接改 DOM class 会被 ProseMirror 重绘回滚，并触发重绘循环）；
  - `BlockHandle` 改为绝对定位渲染在 `.doc-editor-body`，`DocEditor` 移除官方 DragHandle portal 与 52px `.tiptap` 内走廊。
- 浏览器复测（真实 Tiptap + 真实 DOM，Chromium）：
  - hover 段落：手柄 `pos=5`、`type=paragraph`，右键距正文 5px；
  - 鼠标移到六点并停留 320ms 仍可见；在左走廊同块行内移动保持 `pos=5`，移到第二段行后更新为 `pos=13`；回到正文后随块更新；
  - 下拖：`H2/P1/P2/UL/末段 → H2/P2/UL/末段/P1`，源块 opacity 0.42，落点线全宽 728，标签「段落」；
  - 上拖：末段 → 首块，落点线位于首块上方；
  - 列表整块拖动：`bulletList → 首位`，标签「无序列表」；
  - 无位移释放与 Escape：JSON 不变，Decoration/落点线/标签/body 类全部清理；
  - 长文 50 段：拖到底部触发自动滚动（后台页 rAF 受限，900ms 内 scrollTop +55，落点持续更新）；
  - 滚动 251px 后 hover 可见块：手柄 top 与目标块对齐；＋插入空段落正常。
- 门禁：`npm run check` 101 files 通过；`npm run typecheck` 通过；`npm run build` 通过（许可证门禁通过，9 项 MPL 警告）；`cargo test` 39 passed / 0 failed；`cargo fmt --check` 通过。
