# 任务计划 · UI 动画过渡优化

- 日期：2026-10-20　|　需求：`docs/需求文档/2026-10-20-需求文档-动画过渡优化.md`
- 目标：以 motion（唯一 JS 引擎）+ Magic UI 免费组件 + 自建 CSS keyframes，统一提升全部弹窗/交互/界面动画质感；零新增 npm 依赖；严格保性能。

## 步骤

1. tokens.css 增补 `--ease-pop` 微回弹缓动；app.css 增补 shimmer/spin keyframes、升级弹窗/下拉入场（位移+回弹）、View Transitions CSS。
2. 复制 Magic UI 免费组件（number-ticker / blur-fade / shimmer-button / magic-card）至 `src/components/common/motion/`，令牌化适配 + 中文注释 + reduced-motion 兜底。
3. theme.tsx 增加指针原点捕获与 View Transitions 圆形揭示（特性检测降级）。
4. 集成：App（Toast 弹簧 / 信息浮窗弹簧 / 标签内容过渡 / 空状态 CTA 换 ShimmerButton）、InfoPanel（NumberTicker + 相关卡 MagicCard）、EmptyState（BlurFade 分层入场）、KbManageDialog（docCount 滚动）、Sidebar（树展开过渡）。
5. 质量门禁：tsc / biome 零问题；vite dev 实测 sunset 明暗截图 + 浏览器交互抽查。
6. 更新完成进度、文件改造清单、更新日志、UI-SPEC 动效章节。

## 风险

- Magic UI 组件为 Next.js 生态写法 → 复制时移除 next-themes 等引用。
- View Transitions 平台差异 → `document.startViewTransition` 特性检测，不支持直接切换。
- 树展开 height 动画为布局动画 → 限定小列表（≤10 节点）。

## 验收标准

见需求文档 §4 / §6。
