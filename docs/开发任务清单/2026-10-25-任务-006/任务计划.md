# 任务计划 · 快捷键体系（2026-10-25-任务-006）

- 需求：`docs/需求文档/2026-10-25-需求文档-快捷键体系.md`

## 目标

建立应用内快捷键注册表与设置 UI；支持总开关、作用域开关、录制、冲突与持久化；编辑器/画板自有动作可改键，第三方内置键只读。

## 步骤

1. **动作目录**：定义 app/editor/board 动作 id、默认键、标签、是否可用。
2. **组合键工具**：规范化、显示、匹配、冲突检测。
3. **配置层**：读写 `shortcuts.config`，损坏回退默认，持久化防抖。
4. **应用调度器**：替换 `useWorkspaceShortcuts`，支持总开关/作用域/优先级。
5. **设置 UI**：总开关、作用域、搜索、录制器、冲突、恢复默认。
6. **编辑器 keymap**：ProseMirror 插件读取最新配置并执行 Tiptap 命令。
7. **画板动作**：用 Excalidraw 公共 API 接管自有动作；内置键只读展示。
8. **测试**：配置/冲突纯逻辑测试（可执行 Node 脚本或 Rust 侧不适用时以 E2E 覆盖）；真机录制、关闭、重启保持、编辑器与画板动作。

## 风险

- WKWebView/系统保留键可能截获组合；设置中给出提示，不虚假承诺。
- Tiptap 默认键位与自定义键位冲突；自有动作优先，内置只读项明确说明。
- Excalidraw 无改键 API；只接管可通过公共 API 执行的动作，不修改依赖源码。
- 配置变更需即时生效且不能重复注册监听器。
