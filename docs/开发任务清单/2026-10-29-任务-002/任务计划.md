# 任务计划：文档内嵌与画板界面收口

- 任务编号：2026-10-29-任务-002
- 关联需求：`docs/需求文档/2026-10-29-需求文档-文档内嵌与画板界面收口.md`
- 开始日期：2026-10-29

## 目标

按需求文档七条：文档查找改为右上角浮层并输入即跳转；修草稿误报；文档内嵌画板/思维导图只读已导出 PNG；
排查多标签下「新建」弹窗延迟；画板去原生 links、把帮助/重置收进页头、自建帮助与右侧组件库面板、画布背景迁移。

## 关键约束

- 文档编辑器**不得**实时渲染画板/导图；PNG 由源视图在保存静止后导出，文档块只查询最终图片。
- 预览对象复用附件对象库与 `node_attachment` 引用链；不新建第二套存储。
- 原生 Excalidraw 汉堡/素材库/帮助入口没有可注入 API：整体隐藏，能力迁到页头 `⋯`。

## 现状勘察结论

| 事实 | 证据 | 影响 |
| --- | --- | --- |
| 查找条渲染在文档页头流内 | `DocEditor.tsx` 原 `AnimatePresence` 分支 | 展开会顶开标题；改为浮层 |
| 输入查询只算匹配不滚动 | `DocFindBar.updateQuery` 原实现只 `setFindQuery` | 命中在视口外时像“没生效” |
| 草稿 2s 定时器在保存成功后仍会再写一份 | `DocEditor.tsx` 原 `onUpdate` 定时器 + `onSaved` 只 `clearDraft` | 下次打开必弹「未保存草稿」 |
| `node.content` 允许未知块类型通过 | `domain/document.rs::normalize_node` 只清理 null/emoji | 新块无需改保存校验 |
| 导出按类型显式分派 | `domain/document.rs`、`services/export_render.rs` | 新块需补占位，否则静默丢失 |
| 画板/导图可用官方导出器离屏渲染 | `exportScene.renderBoardPng`、`exportGraphics.renderMindmapSvg` + `svgToPngBlob` | 预览图复用同一实现 |
| 附件对象可被 `node_attachment` 引用保住 | `node_attachment_repository::mark_all_unreferenced` 只标记无引用对象 | 预览对象挂源节点引用即可沿用回收 |
| 原生 chrome 类名可用 | `main-menu-trigger` / `default-sidebar-trigger` / `default-sidebar` / `help-icon` | CSS 可整体隐藏 |
| 组件库数据已有 | `listLibraryItems` + `BoardView.insertLibraryItem` | 右侧面板直接复用插入逻辑 |
| 页头 `TabContentView` 的 memo 被内联回调击穿 | `WorkspaceLayout.tsx` 原 `onBoardExported={(m)=>…}` | 打开任意弹窗都会重渲染文档/画板 |

## 实现步骤

1. **查找浮层**：查找条移出文档流，绝对定位到编辑区右上角（窄窗口下移）；输入后落到第一处并 `scrollIntoView`，上下/Enter 同步滚动。
2. **草稿**：新增 dirty 标记；保存成功取消挂起的 2s 定时器并清草稿；定时器到点无未保存修改则跳过。
3. **预览后端**：
   - `node_preview` 表（v17 迁移 + 自愈清单）；
   - `node_preview_service`：`load` / `save`（版本与字节双重去重、替换引用）；
   - 命令 `board_image`、`mindmap_image`、`node_preview_save`；
   - `sync_board_refs` / `sync_mindmap_refs` 保留预览对象引用；
   - 附件列表默认排除 `__preview`。
4. **内嵌块**：`boardEmbed` / `mindmapEmbed` 两个 atom 节点；NodeView 只查已存 PNG；Slash 插入 + 选择弹窗；缺图提示打开源内容；导出补占位。
5. **源侧导出**：画板/导图视图在状态变为 `saved` 后 1.2s 防抖导出；已有且未过期直接复用；同节点单飞。
6. **性能**：稳定 `onBoardExported` 引用，修 memo 击穿；其余按真机打点结果处理。
7. **画板 UI**：隐藏原生汉堡/素材库/帮助入口；页头改为 附件/放映/导出/⋯/已保存；`⋯` 承载帮助、背景、打开文件、画布内查找、重置；自建帮助弹窗读快捷键配置；右侧停靠组件库面板 + 右缘把手。
