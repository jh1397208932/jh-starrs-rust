## 目标

在现有导入入口增加 PDF：文本型走 pdf-inspector → Markdown → Tiptap；原始 PDF 作为附件保留；扫描件明确提示未启用 OCR。

## 实现

1. `src-tauri/Cargo.toml` 增加 `pdf-inspector = "1.25.2"`（默认特性，无 OCR）。
2. 新增 `services/import_pdf.rs`：
   - 128 MB 上限、普通文件校验；
   - `process_pdf` 分类与 Markdown；
   - TextBased/Mixed → `parse_markdown`；Scanned/ImageBased/空正文 → 单段提示，不伪造正文；
   - 编码问题、需 OCR 页码写入 warnings。
3. `services/import_service.rs`：`PDF_EXTENSIONS`、`parse_content` 分支、`is_supported`、错误文案。
4. 前端：`pickImportFiles` 过滤加 `.pdf`；导入弹窗说明加 PDF 与扫描件限制；导入结果展示具体 warnings（去重后前 3 条）。
5. 夹具与测试：`test/fixtures/files/pdf-sample.pdf`；Rust 集成测试断言文档正文与原始附件；e2e `70-import-export` 增加 PDF 导入与正文断言。
