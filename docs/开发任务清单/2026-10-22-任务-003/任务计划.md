# 任务计划 · Tiptap 块级持久化与编辑器交互增强（2026-10-22-任务-003）

- 需求来源：`docs/需求文档/2026-10-22-需求文档-编辑器块存储与交互增强.md`
- 目标：
  1. 工作区库 v3 新增 `doc_block_hash` / `doc_block_tree`，按顶层块内容寻址存储；
  2. Rust 侧 xxh3-128 哈希、重复块匹配、LIS 锚点 + Fractional Index 最小重排、越界全量重排；
  3. `doc_load` / `doc_save` IPC 返回 `add/rm/order/tree/wordCount/updatedAt` 差量；
  4. 前端 1s 防抖 + 单飞互斥 + 锁冲突延长 1s，拿锁后 `editor.getJSON()` 取最新；
  5. 引入 Tiptap MIT 扩展，提供气泡菜单、右键浮层、Slash 菜单、颜色/对齐/表格/图片/折叠块等。

## 方案

### 后端

- 依赖：`xxhash-rust`（xxh3，MIT/Apache-2.0）。
- 迁移：`SCHEMA_VERSION = 3`；v1→v2→v3 顺序执行，v3 建块表与索引，旧数据保留。
- `domain/fractional_index.rs`：base62 字典序键；before/after/between；32 字符上限；8 位等距全量重排。
- `domain/block_plan.rs`：
  - 按最终顺序贪心复用同 hash 旧块；未匹配旧块删除、未匹配新块 UUIDv7 新增；
  - 保留块对旧位置求 LIS，锚点不动；其余按连续区段生成新键；
  - 生成失败/超长/顺序异常 → 全量重排；输出分段 order 差量。
- `repositories/document_repository.rs`：节点正文读写、块树读取/更新、hash 引用检查。
- `services/document_service.rs`：校验文档节点 → 哈希 → 计划 → 单事务写 tree/hash/content/word_count/update_time；提交后返回差量。
- `commands/document.rs`：`doc_load` / `doc_save`（`#[tauri::command(async)]`）。

### 前端

- `types/document.ts` + `api/document.ts`：IPC 类型与封装。
- `useDocumentPersistence`：dirty + debounce 1s + 保存互斥 + 冲突延长 1s + flush。
- `DocEditor` 重写：加载正文、保存状态、StarterKit + MIT 扩展、BubbleMenu/右键菜单/Slash 菜单、颜色与高亮、表格、图片 data URL（≤2MB）、任务列表、折叠块、Emoji、代码高亮、TOC。
- Toolbar 大纲接入真实标题。

## 风险

- 图片 data URL 放大文档体积；本期限制 2MB 并在文档中注明后续迁移附件。
