## MCP 缺陷清单与处置

审查依据：`src-tauri/src/mcp.rs`、`services/mcp_host.rs`、`services/ai_service.rs`、`commands/ai.rs` 逐行核对。

已修：
1. 6 个 AI 命令未标 `async` → 全部改 `#[tauri::command(async)]` + `spawn_blocking`（`commands/ai.rs:16`）。
2. 令牌互斥锁中毒被静默跳过、空令牌被 `unwrap_or_default` 吞成"永远 401" → 中毒容错 + 显式错误态（`mcp_host.rs:57`）。
3. 读配置失败时 MCP 默认开启 → 默认关闭并记日志（`mcp_host.rs:142`）。
4. 快速开关端口竞争 → 绑定重试 5 次 / 120ms（`mcp_host.rs:216`）。
5. JSON-RPC 批量请求被 202 吞掉 → 返回 `-32600`（`mcp_host.rs:311`）。
6. 序列化失败返回空串且 `isError:false` → 返回错误（`mcp.rs:41`）。
7. 工具调用无超时 → 60s 上限并回 `-32000`（`mcp_host.rs:35,333`）。
8. `blocks/elements/elementIds` 无长度上限 → `MAX_WRITE_ITEMS=500`，超限报错不静默截断（`ai_service.rs:1134`）。
9. `doc_replace_range` 缺 `end` 时区间为空却仍写版本 → 要求显式 `end`（`ai_service.rs:908`）。
10. 审批的工作区 TOCTOU → 执行前复核工作区身份，不一致则失败回写；审计只写真正落库的那个库（`ai_service.rs:654`）。
11. 入队/失败无审计痕迹 → 入队补记 `pending`（`ai_service.rs:570`）。
