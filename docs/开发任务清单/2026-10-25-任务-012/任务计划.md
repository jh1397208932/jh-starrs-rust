# 任务计划 · 界面国际化（R14）

- 任务编号：2026-10-25-任务-012
- 关联需求：`docs/需求文档/2026-10-25-需求文档-界面国际化.md`
- 目标：中文 / English 双语界面、即时切换、持久化、菜单与 Excalidraw 同步。

## 实现方案

1. `src/lib/i18n.tsx`：无依赖 Provider + `t()` + `useI18n()`；`appearance.locale` 读取/保存。
2. `src/lib/messages/en-US.ts`：中文源文案 → 英文词典（含界面、错误、快捷键、块类型、颜色、内置快捷键）。
3. 组件：`t("...")` 替换静态文案，`useI18n()` 订阅语言变化；动态标签在渲染处 `t(variable)`。
4. 后端：`SETTING_LOCALE` 白名单校验；启动按语言构建原生菜单，保存语言时重建菜单。
5. Excalidraw：`langCode` 随语言切换。
6. 覆盖探针：`scripts/check-i18n.mjs`、`scripts/check-i18n-keys.mjs`。

## 验证

- `npm run typecheck` / `npm run check` / `npm run build`。
- `cargo test` / clippy / fmt。
- 真机 `test/e2e/cases/12-language.mjs`（后台执行，需独占窗口）。
