# 项目文件改造清单 · 界面国际化（R14）

## i18n 内核

| 文件 | 改动 |
|---|---|
| `src/lib/i18n.tsx` | Provider、`t()`、`useI18n()`、语言订阅与持久化 |
| `src/lib/messages/en-US.ts` | 中文源文案 → 英文词典（界面、错误、快捷键、块类型、颜色） |
| `src/api/memory.ts` | `appearance.locale` 记忆键 |
| `src/api/client.ts` | API 错误消息经 `t()` 翻译 |
| `src/App.tsx` | 挂载 `I18nProvider` |
| `src-tauri/src/models/mod.rs` | `SETTING_LOCALE` |
| `src-tauri/src/services/memory_service.rs` | locale 白名单校验 |
| `src-tauri/src/menu.rs` | 原生菜单按语言构建，预定义项显式中英文标签 |
| `src-tauri/src/lib.rs` | 启动按持久化语言安装菜单 |
| `src-tauri/src/commands/memory.rs` | 保存语言后重建菜单 |
| `src/features/board/components/BoardView.tsx` | Excalidraw `langCode` 随语言切换 |

## 界面接入（全部 `features/**` 组件）

- 组件统一 `t("中文源")`；`useI18n()` 订阅语言变化。
- 动态标签（快捷键动作、块类型、主题、颜色、节点类型、语言名）在渲染处 `t(variable)`。
- 表单占位、aria-label、标题、空态、toast、确认文案全部覆盖。

## 工具

| 文件 | 用途 |
|---|---|
| `scripts/check-i18n.mjs` | 找出未被 `t()` 包裹的中文 |
| `scripts/check-i18n-keys.mjs` | 找出 `t()` 键缺失英文的项 |
| `scripts/i18n-wrap.mjs` | 批量包裹中文展示文案（开发期 codemod） |
| `scripts/i18n-add-hooks.mjs` | 为使用 `t()` 的组件补 `useI18n()` |
