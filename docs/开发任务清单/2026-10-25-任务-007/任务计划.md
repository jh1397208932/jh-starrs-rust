## 2. 实现方案

### 2.1 前端关闭守卫

- 新增 `src/api/app.ts`：`onExitRequested` 监听 `starris://exit-requested`，`confirmAppExit` 调 `app_confirm_exit`；`onWindowCloseRequested` 封装 `getCurrentWindow().onCloseRequested`。
- 新增 `src/features/workspace/hooks/useAppCloseGuard.ts`：注册窗口关闭与退出事件；调用 `flushActivePersistence`；成功调 `confirmAppExit`；失败 toast 并保持窗口；8 秒超时。
- 在 `useWorkspaceMainController` 中调用该 hook，复用 `showToast`。

### 2.2 Rust 退出协调

- `lib.rs` 改为 `.build(...)` + `app.run(|app, event| ...)`。
- 静态 `EXIT_ALLOWED: AtomicBool`；`RunEvent::ExitRequested` 时若未允许：`api.prevent_exit()`，向主窗口 emit `starris://exit-requested`；emit 失败则允许退出。
- 新增 `commands/app.rs::app_confirm_exit`：设置允许标志后 `app.exit(0)`。
- 注册命令；补单元测试只测标志/纯函数（不启动 Tauri）。

### 2.3 迁移备份

- `db/workspace.rs`：`SCHEMA_VERSION = 11`，新增 `MIGRATION_V10_TO_V11`。
- `open` 读取版本，若旧库则 `backup_before_migrate(path, version)`；失败返回错误。
- 备份目录 `db/backups/`；文件名 `workspace-v{version}-{timestamp}.sqlite3`；保留 3 份。
- `backup_before_migrate` 先 `PRAGMA wal_checkpoint(TRUNCATE)`，再 `fs::copy`；返回备份路径。
- 测试：v10 夹具升级生成备份；备份失败（注入不存在目录/只读）不迁移；保留 3 份；v11 不再备份。

### 2.4 文档版本

- schema v11 `node.doc_version`；`DocumentNodeRow` 增加 `doc_version`。
- `DocLoadResult`/`DocSaveResult` 增加 `version`；`SaveDocumentInput` 增加 `base_version`。
- `document_service::save` 在事务内比较版本；不一致返回 conflict；`update_content` 原子写 `doc_version = doc_version + 1` 并返回新版本。
- 前端 `DocSaveResult`/`DocLoadResult` 增加 `version`；`saveDocument(nodeId, document, baseVersion)`；`useDocumentPersistence` 维护 `baseVersionRef`，`setBaseline(wordCount, updatedAt, version)`；冲突时 `onConflict` 回调。
- `DocEditor` 加载时传 `loaded.version`；保存冲突时显示错误并保留内容；`onDocumentSaved` 签名增加 version（可选，store 只用于更新时间）。

### 2.5 入口诚实化

- `MoreMenu` 保持"即将推出"。
- `WindowBar` 搜索按钮禁用 + tooltip "搜索即将推出"。
- `DocPageBar` 打印按钮禁用 + tooltip "打印即将推出"。
- `SettingsDialog` 语言选择器禁用并显示"其他语言即将推出"。
- `InfoPanel` 相关列表传空数组；删除 `MOCK_RELATED`/`MOCK_OUTLINE`。
- `StarredList` 空态改为静态提示，不使用 `onMockAction`。
- `NodeCreateDialog` 只显示文件夹/文档/画板；保留已有 table/flow 节点打开占位。
- 主控制器：quickJump/globalSearch/presentBoard 不再绑定 mock；未实现动作在快捷键表中保持 unavailable。
- 搜索/打印按钮的快捷键提示保留但标注即将推出。

### 2.6 维护互斥

- `attachment_maintenance_service::run`：将 `big_to_remove` 的 unlink 移到 `drop(lock)` 之前；pack compaction 仍在锁外。
- `remove_big_object` 调用前重新查询 `attachment_blob` 是否仍不存在；存在则跳过。
- 补并发测试：同 hash 上传 + 维护循环，验证对象可读。
