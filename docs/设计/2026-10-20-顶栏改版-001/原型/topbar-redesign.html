设计说明

1

三行并两行：112px → 80px

空置的 36px 标题栏拆除，标签页上移进窗口栏；文档工具栏 40→36px。垂直空间省 32px，全部让给内容区。

2

职责分层：窗口层 / 文档层

窗口层只放与窗口相关的（红绿灯、标签、搜索、设置）；文档层只放随文档变化的（类型、路径、保存、操作）。切换标签时只有文档层变化，认知负担更低。

3

搜索升级为 ⌘K 命令入口

右上角裸图标 → 带快捷键提示的搜索胶囊，占据原 Logo 的视觉锚位但右置、不与标签争宽；聚焦展开 + 环形高亮；窄屏自动收缩为图标。

4

面包屑补齐上下文

原「空间名 · 标签名」文字与侧栏、标签页三重重复，删除；文档层左侧改为 类型徽标 + 知识库 / 文档名 面包屑，一眼知道「我在哪」。

5

激活标签与内容同色顺接

激活标签使用内容区底色（--background）并盖住分隔线，形成「标签打开内容」的连续感；未激活标签悬停浅灰，层次自然。

6

边界与降级

<900px 搜索收缩为图标；标签溢出横向滚动；Windows / Linux 红绿灯区换自绘窗控（沿用现有 fallback 逻辑）；红绿灯左侧 76px 永远保留拖拽。

落地改动映射

TitleBar.tsx重构为 WindowBar（44px）：合并 TabBar；右侧搜索胶囊 + 设置；保留 data-tauri-drag-region、macOS Overlay 76px 注入区与 Windows 自绘窗控 fallback。
TabBar.tsx并入 WindowBar 后删除；激活态由 bg-accent 改为「与内容区同色顺接」（bg-background + 盖住分隔线）。
Toolbar.tsx40→36px；Badge 右侧新增面包屑（数据：tab.parent / 知识库名）；按钮 32→28px；画板类隐藏目录按钮的逻辑保留。
App.tsx布局由「TitleBar + TabBar + Toolbar 三层」改为「WindowBar（全宽）+ 主区 Toolbar」；TitleBar 的 workspaceName prop 移除，改传 tabs 数据。
tokens.css可选新增 --winbar-h: 44px / --doctoolbar-h: 36px，供布局与动效引用。
