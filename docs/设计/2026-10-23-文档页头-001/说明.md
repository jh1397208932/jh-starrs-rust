# 文档页头下沉 · 设计与验证（2026-10-23）

- 关联需求：`docs/需求文档/2026-10-23-需求文档-文档操作下沉页头.md`
- 关联任务：`docs/开发任务清单/2026-10-23-任务-003/`
- 上一版：`docs/设计/2026-10-23-顶栏单行化-001/`（顶栏单行制）

## 目标

把文档级控件从 44px 全局顶栏移到正文页头：面包屑回到正文左上，收藏/目录/信息/分享/打印放到同一行右侧；保存态只保留正文 meta 行的 `SaveIndicator`。

## 终态

1. **顶栏**：标签页 + 全局搜索（macOS 保留红绿灯，Windows 保留自绘窗控）。无面包屑、无保存胶囊、无文档操作、无设置。
2. **文档页头**：`DocPageBar` 顶行左侧 `产品设计 › 文档标题`，右侧 5 个 28px 图标钮；下方仍是「文档」徽标、输入提示、标题与 meta。
3. **信息浮窗**：起点由 `top-4` 改为 `top-16`，展开时从操作行下方开始，分享/打印等按钮保持可点。
4. **目录**：首次打开即发布大纲；旧编辑器实例的延迟 TOC 回调被来源校验过滤，不再把新目录清空。
