# 设计说明 · 本地工作区与文件树（2026-10-21）

- 关联需求：`docs/需求文档/2026-10-21-需求文档-本地工作区与文件树.md`
- 关联任务：`docs/开发任务清单/2026-10-21-任务-005/`
- 设计基线：`UI-SPEC.md`、`docs/设计/starris-design-system.html`、现有 8 主题令牌

## 目标

在不改变星屿既有视觉语言的前提下，把“本地工作区”这一新能力做成可感知、可恢复、低误删风险的桌面交互：

1. 首次启动明确选择“新建/打开本地工作区”，不让用户停在空壳界面。
2. 左上角工作区入口同时承担工作区与知识库的查询、切换、新建与管理。
3. 文件树支持任意层级与 5 类节点；只有文件夹出现“新建子级”，拖拽提供清晰的落点反馈。
4. 删除工作区时把“移除登记”和“删除本地文件夹”拆成两个明确选择。

## 界面与状态

### 首次引导

- 固定全屏遮罩（`bg-background/95` + 轻模糊）+ 480px 居中面板；不使用可关闭 Dialog，避免进入无数据主界面。
- 两个等权入口：新建工作区（主色浅底卡片）、打开工作区（普通卡片）。
- 若已有登记记录，追加“最近的工作区”列表，支持直接切换。
- 状态：按钮 loading 文案、行内错误、空列表。

### 创建工作区

- 440px 模态；名称、目标文件夹（绝对路径 + 原生选择）、6 色头像。
- 文案明确“所选目录将成为工作区根目录，自动创建 db/ 与 storage/”。
- 默认路径按 `~/Starris/<名称>` 推导；用户选择文件夹后不再自动覆盖。
- 异步创建期间禁止关闭，失败保留输入并显示后端错误。

### 左上角入口

- 工作区列表：头像 + 名称 + 等宽路径 + 当前勾选。
- 知识库列表：主色圆点 + 名称 + 描述 + 当前勾选；无库时显示空提示。
- 尾部动作：新建工作区、打开已有工作区、新建知识库、管理知识库、管理工作区。

### 工作区管理

- 560×440 模态；搜索框按名称/路径过滤。
- 行内展示最近打开时间；操作菜单：切换、重命名、删除。
- 重命名只改显示名（说明文案明确不改目录）。
- 删除弹窗：路径展示、当前工作区自动切换提示、默认不勾选的“同时删除本地文件夹”复选框、危险按钮文案随勾选变化（移除工作区 / 删除工作区与文件夹）。

### 知识库管理

- 560×400 模态；名称/描述/条目数；当前行使用 accent 底色 + 当前徽标。
- 支持切换、编辑名称与描述、删除（说明会级联删除节点）。

### 文件树

- 行高 32px；层级缩进 14px；文件夹 chevron 14px；类型图标 16px。
- 选中 = `bg-sidebar-active` + 加粗；悬停显示操作菜单。
- 文件夹可展开/折叠；非文件夹单击打开标签；文件夹单击只展开。
- 顶部“文件/知识库名 + 新建按钮”；无知识库时按钮禁用并提示先建库。
- 空态：无知识库 / 有知识库但无节点，分别给出下一步。
- 拖拽：
  - 文件夹中部 → 子级，目标行 accent + 主色内描边；
  - 节点上/下缘 → 同级插入，2px 主色指示线；拖到列表底部 → 根级末尾。
- 键盘：↑↓ 移动焦点，←/→ 折叠/展开文件夹。

## 令牌与无障碍

- 颜色全部使用语义令牌（`bg-sidebar`、`bg-accent`、`text-sidebar-muted`、`border-primary` 等），未引入硬编码色值。
- 文字保持既有 13/12.5/11.5px 阶梯；危险操作使用 `destructive`。
- 所有图标按钮有 `aria-label`；树行 `role=treeitem`、`aria-level`、`aria-expanded`、`aria-selected`；根级拖放区 `fieldset aria-label`。
- 弹窗使用统一 `DialogContent` 契约；引导面板为自定义 `role=dialog aria-modal`，因需叠加创建弹窗而避免双重焦点陷阱。
