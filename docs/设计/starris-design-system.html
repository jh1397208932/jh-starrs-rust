Brand Identity

品牌图标 —— 一颗星，落成一座屿

标志由三个部件构成：金色的星（三角形）、主岛（大圆角体）与伴屿（深色小块），外加一颗远星（圆点）。 造型全部采用大圆角有机形态，呼应「知识聚合而成岛屿」的品牌隐喻。颜色绑定主题令牌，随 8 套预设联动。

构成解析 · 64×64 网格
虚线为各部件的几何中心参考线。星以 7px 圆角描边 软化尖角；主岛 rx≈10.5 / -5°，伴屿 rx≈6.5 / +6°，倾斜制造漂浮感。

Developer Handoff

接入指南 —— Tailwind v4 + shadcn/ui

主题层即数据：应用只需要维护「主题名 → 变量组」的映射，运行时切换 data-theme / data-mode 两个属性即可全局换肤，组件层零改动。

/* app.css — Tailwind v4 */ @import "tailwindcss"; @theme inline { --color-background: var(--background); --color-foreground: var(--foreground); --color-primary: var(--primary); --color-sidebar: var(--sidebar); --color-accent: var(--accent); --radius-lg: var(--radius-lg); --font-sans: system-ui, "PingFang SC", …; } /* 运行时切肤：两行代码 */ root.dataset.theme = "sunset"; // 8 预设 root.dataset.mode = "dark"; // 浅 / 深 /* 组件内直接用工具类 */ <button class="bg-primary text-primary-foreground rounded-[10px] h-[38px] px-[18px]">创建</button>
Tauri 侧把 theme + accent 持久化到工作空间配置；窗口 chrome（tauri.conf.json 的 transparentTitlebar）跟随 data-mode。
✓
文字一律使用 --foreground / --muted-foreground，禁止出现色板外的灰色深浅模式共用组件时对比度始终由令牌保证
✓
选中态 = --accent 底 + --accent-foreground 字，主按钮才是 --primary参考稿中侧栏选中项即为该组合
✓
圆角三档 8 / 12 / 16，窗口与弹窗 16，控件 10icons 用 lucide，线条 1.5px 圆头
✓
