# 细节打磨（第八轮）· 方案与截图（2026-10-23）

> **迭代修正**：首轮为解决「按钮边界」给侧栏加了白卡与 chrome 渐变，用户反馈「效果很差，寻找成熟方案」。对照 Notion / Apple 备忘录 / macOS Ventura 设置的成熟范式修正：**侧栏回归扁平**（无卡片、无边框、无渐变），主题色只出现在选中 pill 与点缀；毛玻璃浮层与圆角内容薄片保留。以下第 1、4 条按修正后终态描述。

## 一、问题清单（用户 6 条）与终态处理

| # | 问题 | 终态处理 |
|---|---|---|
| 1 | 按钮边界没了 | 按成熟范式：侧栏交互件不描边不加卡，hover 用浅调底、选中用主题 pill 承担反馈（扁平 Notion 式）；白卡/渐变方案已回退 |
| 2 | 角落过渡不够细节优美 | 内容区改「圆角薄片」：`rounded-tl-[14px]` + 发丝边（border-l/t），白纸浮在主题浅调画框上（Ventura 设置式） |
| 3 | 字体颜色不合适 | 空态 CTA 改白心 + 深色字 + 主色图标（hover 落浅调底） |
| 4 | 区域颜色与主题色过渡不平滑 | 回退渐变，保持扁平浅调 + 白薄片圆角承接；`chrome-gradient` 工具类删除（含死代码清理） |
| 5 | 不需要顶栏加号 | 移除 WindowBar 新建标签 "+"（含 onNew prop 链清理） |
| 6 | 细节纹理少（毛玻璃/色彩过渡） | 毛玻璃浮层：下拉菜单 `bg-popover/85 + backdrop-blur-xl`、信息浮窗 `bg-card/85 + backdrop-blur-xl`（把手 blur）、弹窗内容 `bg-popover/90 + backdrop-blur-2xl`、Toast `bg-popover/85 + backdrop-blur-xl` |

## 二、成熟范式要点（本轮沉淀）

- 侧栏 = 扁平浅调底，交互反馈只靠「hover 浅调底 / 选中主题 pill」，不画框不加卡；
- 内容区 = 白色圆角薄片 + 发丝边，浮在 chrome 上；
- 浮层（菜单/浮窗/弹窗/Toast）= 半透明毛玻璃（85~90% + blur）；
- 主题色出现位置收敛：选中态、CTA 图标、badge、品牌区。
