## 二、终态方案（参考稿的真正结构）

1. **侧栏是一块"面"**：`#F4F2ED` 级浅暖灰（azure `#EFF4F9` / midnight `#F0F0F8` / amber `#F4F1E7` / forest `#EFF4F1` / rose `#F6F0F2` / violet `#F1EFF9` / graphite `#F0F1F2`），比白内容深一档、可感知为独立表面；行内全部透明。
2. **交互反馈两级**：hover = `secondary` 浅灰底；选中 = `sidebar-active` 主题色 pill（橙底深字）——参考稿同款，也是全侧栏唯一色块。
3. **白块只属于浮控件**：顶栏激活 tab（白底 + ring 发丝边）、搜索胶囊（白底 + border）——浮在 chrome 上才需要"块"。
4. **工作区/快捷钮/更多**：透明行 + hover 浅灰底，无框无卡。
5. 树图标 `primary/70`、内容薄片圆角 + 阴影描边、毛玻璃浮层均保留。
