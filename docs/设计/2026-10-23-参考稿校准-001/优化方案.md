# 参考稿校准（第九轮）· 方案与截图（2026-10-23）

## 一、问题（用户 3 条）

1. 内容区纯白与暖黄侧栏不协调；
2. 内容薄片圆角的发丝边框在弧角处样式错误（直边框线不贴弧）；
3. 按钮、树行没有边界。

## 二、处理（对照用户提供参考稿校准）

1. **侧栏降饱和至「参考稿级」近中性暖白**（个性交给选中 pill / 徽标 / 图标，而非大面积底色）：
   - sidebar：sunset `#F8F6F2` / azure `#F5F9FD` / midnight `#F6F6FC` / amber `#F9F7EE` / forest `#F3F8F4` / rose `#FBF5F7` / violet `#F7F5FD` / graphite `#F4F5F6`；secondary/border/input 同步降饱和；**内容区保持纯白**——两侧都接近白，过渡自然不冲突。
2. **圆角边界修正**：内容薄片去掉 `border-l/t`（直边框线与弧角割裂），改 `shadow-[0_0_0_1px_rgb(0_0_0/.04),0_2px_12px_rgb(0_0_0/.05)]`——描边随弧度完整包裹 + 轻浮起。
3. **边界回来了（白块语言）**：
   - 工作区切换钮 / 快捷钮：白卡（`bg-background` + `border-border/50~60` 发丝边）；
   - 树行：白块填充（`bg-background`）+ 行间 2px 间隙，hover 落 `accent/60`，选中为主题 pill；树图标改 70% 主色（参考稿同款暖色图标）；
   - 顶栏：激活 tab 加 `ring-border/50` 发丝描边、搜索胶囊加 `border-border/60`、图标钮 hover 改 `bg-secondary`。

## 三、验证

- `check-contrast --check` 8 主题 PASS（边框降饱和后仍 ≥1.30）；tsc / biome / build 三绿；
- mock-IPC 截图 sunset ×3 无页面错误（azure 同结构未单测，值同批校准）。
