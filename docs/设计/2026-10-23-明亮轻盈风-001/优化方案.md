# 明亮轻盈风重设计（第六轮 · Apple 式）· 评审与方案（2026-10-23）

## 一、评审结论（改前）

第五轮配色（暖调 chrome + 深饱和主色）在扁平化后仍显得「沉稳、不透亮」：

| # | 问题 | 表现 |
|---|---|---|
| 1 | chrome 暖陈旧 | 侧栏/顶栏为暖米色（sunset #F9F6F1），整体泛黄发闷，不清爽 |
| 2 | 主色过深 | primary 高饱和深色（#C55008 等），观感厚重，与 Apple/Chrome 级产品的轻盈感差距大 |
| 3 | 按钮范式沉重 | 主按钮 = 深色实底 + 白字，面积感大、压迫感强 |
| 4 | 阴影带色温 | 各主题阴影用暖色调 rgba，叠加暖底更显浑浊 |

## 二、设计方案（集众家所长：Apple 系统级灰阶 + 高明度主题色 + 网易云/Numbers 式浅调选中）

1. **中性 chrome（8 主题统一）**：sidebar `#F5F5F7`、secondary/muted `#F0F0F3`、border `#E0E0E5`、input `#D9D9DE`、阴影中性化—— Apple「图片/Finder」式冷静灰阶，白内容区对比更透亮。
2. **高明度主题色（眼前一亮）**：primary 提亮为明度高、饱和适中（vs 白 ≥3.0）：sunset `#DF751E` / azure `#2B97E8`（浅天蓝）/ midnight `#7377F2` / amber `#C48408` / forest `#2FA35A` / rose `#EA5F7C` / violet `#8B5CF6` / graphite `#707880`。
3. **浅调描边按钮范式（用户指定）**：主按钮 = 浅调底（近白心）+ 主题色内描边 + 深色字（如 amber：浅黄描边 + 白心 + 深金字）；hover 加深一档；全 App 经 `button.tsx` default 变体一次生效。白字填充范式仅在 destructive 与 dark 保留。
4. **文字深浅分工**：`--accent-foreground`（主题深色）做文字（≥4.5），`--primary` 只做图形/描边/图标（≥3.0）；选中态 = 主题浅调 pill + 深字（网易云式）。
5. dark 模式不动（自身已协调）。
