# 雾光笺（第十一轮）· 方案与截图（2026-10-23）

> 用户反馈：当前配色「完全看不了，太丑了」。要求：明亮、小清新、白/浅色为主；简洁干净但不单调；低饱和度、高明度、中对比度；搭配高端颜色纹理。后续三条即时反馈：①快捷钮/空态 CTA 太立体；②两组按钮边框口径不一致；③左上工作区按钮白色区域太大。

## 一、视觉方向

一句话：**一张暖白的纸，浮在主题浅调画框上，三种雾光从角落渗进来。**

| 层 | 做法 | 目的 |
|---|---|---|
| 画框（app-shell） | 侧栏主题浅调 + 三色低饱和 wash 径向渐变 + 5% 细颗粒纸纹 | 远看是浅色，近看有材质，不靠大面积纯色撑场面 |
| 纸面（app-sheet） | 近白 `--card`、18px 圆角、66% 发丝边框、顶部 220px 主题雾光、`--shadow-sheet` | 内容区成为唯一“纸”，与画框拉开一层 |
| 空态 | 宋体大标题 + mono 眉标 + 星屿线稿 + 560px 同心圆 + 雾光 | 留白不空，有书写感与品牌记忆点 |
| 控件 | 透明行 / 浅调底 / 1px 发丝线；无渐变、无高光、无重投影 | 扁平但不单薄，层级交给底色与阴影 |

主题色只出现在：图标、选中态、CTA、品牌星点、焦点环。**不再用主题色大面积铺底，也不给每一行铺白卡。**

## 二、令牌（以默认 mist 为例）

| 令牌 | light | 说明 |
|---|---|---|
| `--background` | `#FCFDFC` | 近白纸底（略带青） |
| `--card` | `#FFFFFF` | 纸面/浮层 |
| `--foreground` | `#1D201F` | 中性墨色正文（9 主题共用，tint ≤ 4） |
| `--muted-foreground` | `#626663` | 次要文字 |
| `--primary` | `#5C8F83` | 雾光青：图标/描边/选中指示 |
| `--accent` | `#E7F1ED` | 浅调强调底 |
| `--accent-foreground` | `#2F5C51` | 浅调底上的文字（≥4.5） |
| `--sidebar` | `#F2F6F4` | 侧栏浅调面 |
| `--sidebar-active` | `#E3EFEA` | 侧栏 hover / 选中 |
| `--border` | `#D7E0DC` | 结构线 |
| `--wash-1/2/3` | `#D8EAE3` / `#E2E8F6` / `#F3E9DC` | 青 / 蓝 / 米三色雾光 |

**9 套预设**：雾光青 `mist`（默认）/ 晴空蓝 `azure` / 星澜紫 `midnight` / 暖砂金 `amber` / 苔屿绿 `forest` / 樱雾粉 `rose` / 暮霭紫 `violet` / 石墨灰 `graphite` / 晨光橙 `sunset`。所有 light 主题共用中性墨色文字组，主题个性只由 `primary / accent / sidebar / wash` 承担。

## 三、壳层与纹理

- **画框**：`radial-gradient` 三色 wash（58% / 50% / 42%）压在 `158deg` 的 sidebar 渐变上；`::before` 铺 180px 颗粒，`opacity .05`、`multiply`（dark 10%、`soft-light`）。
- **纸面**：右上角 12% wash-2 + 顶部 220px 的 7% wash-1，避免整张纯白；边框只取 `--border` 的 66%。
- **空态**：640×380 / 560×340 / 440×300 三团 wash（42% / 34% / 36%）+ 170px 颗粒 4.5%；中心 560px 圆环用 13% primary、外环 110px 用 4.5% primary 作“呼吸”。
- **侧栏**：主题浅调面；行一律透明，hover 只用 `--card` 24–28% 或 `--sidebar-active`，选中用 `--sidebar-active`；**没有白卡、没有边框、没有渐变**。

## 四、控件终态（针对三条反馈）

1. **去掉立体感**：`Button` 主变体改为 `bg-accent + accent-foreground + ring-1 ring-primary/20`，撤销内高光；快捷钮/CTA 不再叠加内外阴影。
2. **统一边框口径**：快捷钮的 32px 图标底片 = 1px `currentColor 16%` + 10px 圆角；工作区入口不再“画框”，改为透明行，从根上消除“一个有框、一个没框”的比较。
3. **工作区入口重做**：
   - 26px 品牌 logo（32px 命中盒）+ 两行文字（14px 工作区名 / 10.5px 知识库名）；
   - 高 44px、左右 12px 外边距、透明底；hover / 展开时用 `--sidebar-active` 55% 的浅调，不再出现大面积白色；
   - 右侧 `ChevronsUpDown` 仅 hover / focus 显现，提示“可切换”；
   - 红绿灯槽位撤掉半透明胶囊底座，左上角不再有孤立浅色圆角块。

## 五、主题迁移

- `appearance.designVersion = 2`。
- 仅在“没有版本号且已存主题是旧默认 `sunset`”时，一次性迁移到 `mist`；用户主动选过的其它主题不动。
- Rust `THEME_NAMES` 同步扩到 9 项，并新增单测 `theme_names_accept_all_presets_and_reject_unknown`，防止前端加主题、后端拒写。
