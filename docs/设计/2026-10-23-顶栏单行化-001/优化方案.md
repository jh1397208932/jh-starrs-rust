# 顶栏单行化与清新扁平化 · 评审与优化方案（2026-10-23）

## 一、现有 UI 评审结论（改前）

对照 wolai 参考稿与用户反馈，改前主界面有四类问题：

| # | 问题 | 具体表现 |
|---|---|---|
| 1 | **层级冗余** | 窗口栏（44px）+ 文档工具栏（36px）两行堆叠，内容区上方 80px 全是"机器边框"；两组操作背靠背，视觉重心全挤在右上角 |
| 2 | **线条过多过硬** | 两行各一条 `border-b` + 侧栏通高 `border-r` + 搜索胶囊描边 + 激活 tab 梯形描边 + 右侧 2 条竖分隔线——红框内可见线段 6~7 条 |
| 3 | **观感浓郁厚重** | 树/图标继承近黑前景色；新建文档按钮深橙底 + 金色扫光 + 内高光，与"清新"基调冲突 |
| 4 | **圆角混排** | 树行 8px、按钮 6px、tab 9px、胶囊 999、卡片 16px 同屏混排，无节奏 |

## 二、优化方案（参考 wolai 的三条精髓）

1. **两行并一行**：44px 单行顶栏承载 标签页 + 面包屑 + 文档操作 + 搜索 + 设置（`Toolbar` 组件删除）。
2. **以色代线**：顶栏与侧栏同为 `bg-sidebar` 连成 L 形色块，内容区纯白；所有结构性描边（border-b/r、tab 描边、胶囊描边、竖分隔线）全部移除，分界只靠色差。全界面结构性线条归零。
3. **减淡 + 统一圆角**：树图标降为 muted 色、字重降级；CTA 改浅橙 tonal（hover 反填主色）；交互控件圆角一律 10px。
