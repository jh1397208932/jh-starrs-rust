## 视觉决策

1. **颜色全部来自令牌**：分支色 `--mindmap-branch-*` 由 `--primary`/`--logo-c`/`--glow-a` 派生，主题切换（跟随应用/暖屿/雾海/墨线）只换分支变量映射，不动组件。原型内联的两套值与 `tokens.css`「雾光笺 mist」一致。
2. **圆角三档**：画布节点 `--radius-sm`(8)、根与浮层本体 `--radius`(10)、徽标 `999`；未引入新档位。
3. **选中靠描边与光环，不铺色**：保持琥珀以外的中性层级观感，语义色不参与品牌表达。
4. **图标统一 lucide 线性 14px**：页头与浮动工具栏一致；无文本符号按钮（本原型修订了早期 Unicode 字符版本的 toolbar）。
5. **动效**：hover 与选中间 150ms `--ease`；实现里 `prefers-reduced-motion` 下取消。

## 与实现的已知差异

- 原型为静态摆位；实现里坐标由 `utils/layout.ts` 计算，间距 H_GAP=56 / V_GAP=18。
- 原型的分支色图例仅示意 balanced 结构的三条分支；logic-right 与 org-down 由同一变量组驱动。
- 真实界面截图未采集（不抢占前台窗口的约束），原型不等价于实现验证。

- 边框形状：圆角（默认）/ 下划线（无框，仅底部分支色线）/ 胶囊 / 直角。
- 粗细：1px / 1.5px / 2.5px；填充：自动 / 无色 / 色板 15% 透明底。
- 边框色为 `auto` 时跟随一级分支色（主题或彩虹分支）。

### 结构形态

| 结构 | 几何 |
|---|---|
| balanced | 根居中，一级分支左右交替 |
| logic-right / left | 全部向右 / 向左 |
| org-down / up | 根在顶部向下 / 底部向上 |
| tree | 同 logic-right，弱化根节点强调 |
| timeline | 根在左端，子主题沿横轴排布，孙级纵向堆叠 |
| fishbone | 脊骨横贯，骨刺交替上下，孙级沿骨刺外扩 |

### 连线与动效

- 曲线（贝塞尔 curvature 0.28）/ 折线（圆角 8）；线宽 `max(1.25, 3 − depth×0.35)`，随层级递减。
- 关系线：虚线 `6 4`、1.5px、标签胶囊按内容自适应宽度（最大 180px）。
- 节点位置过渡 220ms `--ease-pop`；`prefers-reduced-motion` 下关闭。
