# 主题色回归（第七轮）· 方案与截图（2026-10-23）

## 一、问题（第六轮回退过头）

用户反馈：「改造后已经没有颜色风格了，全是灰色效果」——第六轮把 chrome 全部中性化（侧栏 #F5F5F7、图标全灰），主题色只剩按钮/徽标几个小点，产品失去个性。

## 二、方案：高明度低饱和主题浅调回归

- **侧栏/顶栏 L 形 chrome 重新上主题浅调**（比第五轮旧暖米色更亮更淡，L*≥95、低饱和）：sunset `#FBF4EB` 暖橙 / azure `#F1F8FE` 浅天蓝 / midnight `#F2F2FD` / amber `#FBF7E6` / forest `#F0F8F2` / rose `#FDF2F5` / violet `#F5F2FE` / graphite `#F3F4F6`。
- **交互面同步上色**：hover 底（secondary）、树行选中 pill（sidebar-active）、边框/输入框描边全部主题化（仍过 1.30 对比门禁）。
- **快捷钮图标 primary 化**：收藏/小记/新建图标用主题主色，标签文字保持 muted——色彩点睛不吵闹。
- **内容区保持纯白**：白纸 + 主题色画框，Airy 感与个性兼得；选中 pill、badge、信息面板激活态、保存勾选随令牌自动上色。

## 三、验证

- 独立脚本先算 8 主题全组 ratio（sidebar-muted、active-fg、border/input、mut/sec）→ 全 PASS 后落盘；
- `check-contrast.mjs --check` 8 主题 PASS；tsc / biome / build 三绿；
- mock-IPC 截图：sunset 3 张 + azure 3 张，无页面错误。
