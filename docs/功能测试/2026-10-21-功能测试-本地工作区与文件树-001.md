## 2. 浏览器 UI 冒烟（替代验证，明确为 mock 后端）

为验证 React 组件、store、拖拽与记忆逻辑，使用临时 `public/__ipc_mock.html` 注入 `window.__TAURI_INTERNALS__`，在 Chrome 中运行同一套 React 代码；mock 在 localStorage 中持久化工作区/知识库/节点/记忆，用于模拟重启。测试结束已删除该临时文件，不进入仓库。

## 4. 本轮发现并修复的缺陷

| 缺陷 | 现象 | 根因 | 修复 | 复测 |
|---|---|---|---|---|
| D1 主题记忆不落盘（StrictMode） | 浏览器 dev 下切换主题后 memory 无 theme；重启不恢复 | 加载 effect 使用 `memoryRequested` 阻止第二次请求，同时 StrictMode 清理把首个请求标记 cancelled，`hydrated` 永不置位 | 移除“一次请求 + 取消”组合，允许 StrictMode 重复读取 | F18 通过 |
| D2 删除最后一个工作区后管理弹窗残留 | 引导页下方仍显示“工作区管理” | Root 门禁切换时未清理非创建类 dialog | Root effect 在当前工作区为空时关闭管理类弹窗 | F16 通过 |
