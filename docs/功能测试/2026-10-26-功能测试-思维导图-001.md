## 真机暴露并修复的缺陷

1. **思维导图页打开即白屏（严重）**：`MindmapView` 加载 effect 把每次渲染都是新对象的 `history` 放进依赖并无条件 `reset()`，无限 setState 触发 React "Maximum update depth exceeded"，根树被卸载。改为只依赖稳定的 `resetContent` 与 `persistence.initial`。
2. **单键快捷键在真机永不生效**：AXPress/工具栏点击不移动 DOM 焦点，旧判据要求 `event.target` 在 `.mindmap-canvas` 内，Tab/Enter 全被拦。改为 `.mindmap-view` 内或 body 未聚焦即视为画布上下文（`useMindmapKeymap.ts`）。
3. **主题文字折行**：测量字体栈/字重（550）与 CSS 实际（400，var(--font-ui)）不一致，边界宽度下最后一字被挤到第二行。改为隐藏 span 按真实排版测量 + 2px 余量（`measure.ts`）。
4. **测试框架加固**（非产品缺陷）：`nativePath` 在面板 AX 树读不到时盲走「粘贴+回车」；每用例开始前 Escape 清理遗留面板（`harness.mjs` / `run.mjs`）。
