## 2. 关键操作与判定

### 表格 / 流程图

1. 新建表格 → 自动打开编辑器，页头徽标「表格」，正文 aria「表格正文」。
2. 默认内容解析为 3 行 × 3 列，首行 `tableHeader`。
3. 点击首个单元格粘贴「表格黑盒内容」，等待数据库正文包含该文本与「已保存」。
4. 新建流程图 → 打开画板视图，出现「放映画板」「导出」。
5. 删除两个测试节点，断言活跃节点为 0（保留在回收站）。

### 知识网络

1. 新建目标文档与来源文档；来源正文写入「参见 E2E Network Target 的说明」。
2. 目标文档信息面板 → 反向链接 → 出现 `打开 E2E Network Source`。
3. 点击条目直接打开来源文档。
4. 测试节点移入回收站，不影响后续用例。

### 回收站

1. 新建并删除 E2E Trash；数据库 `deleted_at` 非空，文件树不再显示。
2. 更多 → 回收站 → 恢复；文件树重新出现。
3. 再次删除 → 回收站 →「永久删除」→ 二次确认（动态 aria「确认永久删除 …」）。
4. 断言节点数据库行被移除。

### 云同步

1. 设置 → 云同步，填写测试同步文件夹并连接。
2. 立即同步 → 出现「已同步」「最新快照」。
3. 断言同步目录存在 `starris-backup-*`、`backup.json`、`db/workspace.sqlite3`。

### 导出路径授权

文档四格式、画板三格式、整库导出均通过 Rust 系统面板选择路径；真机用例 30/40/70 全部通过，证明一次性令牌与目录令牌未破坏保存流程。
