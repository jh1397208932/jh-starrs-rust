## 功能与交互

- **导入入口合并**：更多菜单去掉「导入思维导图…」，`.mm/.xmind/.opml/.starris-mindmap.json` 统一走「导入…」，
  并因此获得原来没有的「导入到指定文件夹」能力。
- **新建弹窗**：类型图标行按类型数量等分整行宽度，不再在右侧留大片空白；页脚新增「上传附件」，
  附件的上传入口与文件树其它新建动作同处。
- **设置 → 存储**：改为纯统计页。位置 + 工作区总大小 / 数据库 / 附件总大小 / 回收站 / 临时文件 / 隔离区
  六格占用，加一行「可回收 · 剩余空间 · 最近维护」；保留时间编辑器留在原处。
  上传、搜索附件、附件列表、回收站切换按钮全部下线（设置里那个「回收站」开关本就不好用）。
- **立即清理**：需要二次确认，文案写明只清理过期临时文件、超过保留期的回收站条目、失去引用的对象与失效哈希索引，
  完成后回报清理条数与释放字节；有效内容不在处理范围内。
- **设置 → 关于**：补一句话简介、桌面运行时与数据存放信息、上游开源项目列表（默认可见），
  完整第三方清单（前端/后端/字体共 40 项，含许可证、仓库与用途）默认收起、一键展开。
- **设置 → 快捷键**：撤下「与画板/思维导图重复，当前作用域优先」提示。同一时刻光标只在一个标签页，
  tab 内键位在捕获阶段先于应用级监听执行，本就不是冲突；同作用域内的真实冲突仍然报错。
- **回收站**：「清空回收站」从页头移到页脚，不再与对话框关闭按钮重叠；清空仍为二次确认。
