# 更新日志 · 2026-10-27 · MCP 改为客户端托管（018）

## 架构调整

- MCP 不再是独立的 stdio 程序：删除 `src-tauri/src/bin/starris_mcp.rs`、stdio 循环与 headless 启动分支（`initialize_headless` / 追加日志）。
- 客户端新增 `services/mcp_host.rs`：进程内 axum HTTP 服务，随窗口启动，可随时开关；工具执行复用现有 `ai_service` 与当前 `AppState`（同一工作区连接、同一权限与待审区）。
- 传输：`POST /mcp`（JSON-RPC 2.0：initialize / ping / tools/list / tools/call）+ `GET /health`；仅监听 `127.0.0.1`，默认端口 `47821`（`STARRIS_MCP_PORT` 覆盖）。
- 鉴权：64 位十六进制 Bearer 令牌，首次启动生成并存全局库 `settings.mcp.token`；常量时间比较；无令牌 401，不执行工具。请求体上限 4 MiB。
- 设置 → AI 协作 → MCP 服务：运行状态、端点、令牌（显示/复制/重置）、开关（`mcp.enabled`，默认开）。关闭开关或退出客户端后端口立即不可用。
- 单实例端口冲突会在设置里显示可读错误，不影响桌面端其他功能。
- 删除 `default-run`（已无第二个二进制），`cargo run` 只剩桌面端。
