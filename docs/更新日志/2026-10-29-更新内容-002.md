## 用户可见的变化

1. **文档查找改成右上角浮层**：不再把标题顶下去；输入关键字就落到第一处并滚动到视口，`Enter` / `Shift+Enter` 与上下按钮继续跳转，当前命中是主色实底。
2. **不再莫名提示「检测到未保存的草稿」**：草稿只在确实有未保存修改时写；自动保存成功就清掉。崩溃/强退仍能恢复最近输入。
3. **文档可以引用画板图和思维导图**：Slash 菜单新增「画板图」「思维导图」，选一个源内容后插入预览卡片；卡片只显示已经导出的 PNG，点击标题或图片可打开源内容。源内容保存后约 1 秒会在后台重新导出，回到文档即为新图；文档里不加载源场景、不实时渲染。
4. **画板更干净**：
   - 画布左上不再有汉堡菜单，右上不再有原生素材库入口；Excalidraw links、原生帮助与「重置画布」菜单项全部消失。
   - 页头操作为 附件 / 放映 / 导出 / ⋯ / 已保存。`⋯` 里有：帮助与快捷键、画布背景、打开画板文件、画布内查找、重置画布（二次确认）。
   - 右侧组件库改成星屿样式的停靠面板：右缘「组件」把手展开，可搜索、连续插入；页面头不再重复放「组件库」按钮。
   - 画布背景从菜单移到 `⋯`，选色立即生效并参与自动保存。
5. **帮助弹窗重做**：只列本应用内容；工具与画板两组键位实时读「设置 → 快捷键」的当前绑定，清空的动作不显示；画布内置键位单独标注「固定键位，不可修改」；右上角 `×` 与底部「关闭」都可关。
6. **多标签下「新建」弹窗**：修复了一个确定的重复渲染点（打开任意弹窗都会连带重渲染当前文档/画板）；真机三种场景的耗时数字待统一测试时补齐。

## 实现要点

- 预览图不新建存储体系：PNG 作为内部附件（`logical_path = "__preview"`）进现有对象库，`node_preview` 只记「源节点 → 对象 id + 尺寸 + 生成时的源更新时间」。
- 回收沿用 `node_attachment`：预览对象挂在源节点引用上；替换时先插新引用再删旧引用，旧对象进入孤儿流程；源节点删除时引用级联，宽限期后由现有维护任务回收。附件选择器默认过滤 `__preview`。
- 导出端遇到两个内嵌块输出可读占位（`画板：标题（内嵌预览，请在 Starris 中查看）`），不静默丢块。
- 预览生成只在源视图：画板/导图保存静止 1.2 秒后渲染；已有且未过期的预览直接复用；同节点单飞，先查后渲染。

## 与原始需求的偏差（需要知道）

- 原生工具条最右侧的下拉（画框/嵌入/激光笔/Mermaid）是 Excalidraw 内部组件，没有注入 API，无法把「帮助/重置」塞进去；因此「最后一个按钮」落在页头 `⋯`，原生汉堡整体隐藏。
- 「打开画板文件」「画布内查找」通过把原生 `⌘O` / `⌘F` 转发给画布容器保留；若 WKWebView 真机不响应，将改为自实现，不能静默消失（已列入待办）。
- 「重置画布」不再调用 Excalidraw 原生清空确认，改为星屿确认弹窗 + `updateScene({elements: []})`，只清图元，不动背景。
