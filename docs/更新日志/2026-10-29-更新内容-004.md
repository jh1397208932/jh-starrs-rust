## 用户可见的变化

1. **启动不再先白一下**：窗口在 HTML 首屏 splash（品牌字形 + STARRIS + 呼吸动画）画好后才显示；主题镜像让深色用户的首屏也是深色，不会先闪白。前端异常时 6 秒兜底仍会显示窗口。
2. **混合导入**：导入弹窗里的「混合导入」选文件夹后先扫描，显示「文档 / 画板 / 导图 / 引用附件」数量与将跳过的文件；有跳过项时必须再确认一次。导入保留目录层级：
   - Markdown / Word / PDF → 文档
   - `.excalidraw` → 画板
   - XMind / FreeMind / OPML / Starris 导图 → 思维导图
   - Markdown 里相对路径引用的图片/文件 → 附件对象库
   - `http(s)` / `mailto` / `tel` / 锚点 → 原样保留，不下载
   - 不支持的格式 → 跳过，不建节点
3. **按钮响应优化**：修掉几处会让整棵文件树/标签栏/信息面板跟着重渲染的 memo 击穿；文档当前节点改为索引取值，不再每次状态变化线性扫树。

## 实现要点

- 窗口 `visible:false` + 前端 50ms 后 `show`/`setFocus`；补 `core:window:allow-show` / `allow-set-focus` 权限；Rust 6s 兜底只在仍隐藏时执行。
- 扫描与导入共用同一套扩展名判定；扫描迭代遍历（5 万文件 / 深度 32），Markdown 引用用 pulldown-cmark 收集并 canonicalize 限制在所选目录内；隐藏项与符号链接跳过。
- 交互探针仅在 `VITE_INTERACTION_PROBE=1` 构建启用，记录点击的同步处理（micro）与到下一帧（frame）时间、≥50ms 长任务；`test/perf/interaction-report.mjs` 汇总 p50/p95/max。
