# 更新日志 · 2026-10-26 · 思维导图（013）

## 功能

- 新增「思维导图」节点类型（type 7）：新建对话框可选，文件树显示专用图标，标签页内全屏编辑。
- 编辑器：React Flow（MIT，`@xyflow/react` 12.12.0）受控画布 + 自研树模型与布局。坐标不入库，只存树结构与视图状态。
  - 结构三种：思维导图（左右）/ 逻辑图（向右）/ 组织结构（向下）；主题四种：跟随应用 / 暖屿 / 雾海 / 墨线。
  - 快捷键：Tab/Enter/F2/Delete/Space/方向键导航、Mod+Z/Mod+Shift+Z、Mod+D 复制、Mod+↑↓ 同级移动、升降级；作用域 `mindmap`，可在设置里改键。
  - 检查器：备注、标签、超链接、图片（图片入附件对象库并计引用）。
  - 搜索：文本/备注/标签匹配，自动展开祖先并居中。
  - 撤销/重做：100 步或 20 MB 上限；备注、标签、超链接的逐字输入合并为一格历史。
- 自动保存：800ms 去抖 + 5s 最长等待，失败退避重试，`base_version` 乐观锁冲突时提示重新加载；视口位置独立保存。

## 数据与迁移

## 导入导出

- 单图导出：XMind、FreeMind `.mm`、OPML 2.0、Markdown 大纲、Starris 无损 JSON、SVG/PNG。
- 导入：`.xmind`（含 XMind 8 旧版 content.xml 与多 sheet 拆分）、`.mm`、`.opml`、Markdown、原生 JSON；批量入口在「更多 → 导入思维导图…」，通用导入过滤器同步扩展。
- 整库导出/导入、备份、回收站、搜索索引、附件引用计数全链路接入。
- 安全面：ZIP 条目数/总量/单项上限与路径穿越拒绝；XML 实体受限解析；导入图片入库。
