## 数据库初始化改为「登记 + 启动异步执行」

- 新增 `db/init_registry.rs`：库表结构、版本迁移、结构自愈统一登记为 `InitTask { id, priority, run }`；`run_tasks` 按 priority 执行并返回执行顺序，供日志与测试核对。
- 登记项：全局库 `global-schema`（P10）；工作区 `schema-version`（P20）、`structure-repair`（P30）。
- 启动改为异步：`bootstrap::spawn_startup` 在 `spawn_blocking` 中恢复工作区与清理回收站，不阻塞窗口首帧；结果写入 `BootstrapGate` 并广播 `starris://bootstrap`。
- 前端新增 `waitForAppBootstrap`：轮询 `app_bootstrap_status` 就绪后再拉工作区数据，避免启动瞬间拿不到会话。
- 业务路径不写 DDL：`WorkspaceSession::open` 只在 `needs_initialization`（版本或关键表）为真时走同一注册表，否则仅 `open_connection`（目录 + PRAGMA）。
- 迁移事务不再夹带结构自愈；自愈独立成任务，带自己的事务与日志。
- 新增测试：任务优先级顺序、全新库建完即完整（不依赖自愈）、漂移 v15 库自愈、缺 v10 产物的 v15 库自愈。
