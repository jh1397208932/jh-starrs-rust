# 更新日志 · 2026-10-23 · 第十一轮：雾光笺（011）

- 关联设计：`docs/设计/2026-10-23-雾光笺-001/`
- 关联规范：`UI-SPEC.md`、`docs/DESIGN_TOKENS.md`

## 背景

用户反馈当前配色「完全看不了，太丑了」，要求：明亮、小清新、白/浅色为主，简洁干净但不单调，低饱和度、高明度、中对比度，并搭配高端颜色纹理。随后三条即时反馈：快捷钮/空态 CTA 太立体；两组按钮边框口径不一致；左上工作区按钮白色区域太大。

## 终态

1. **9 套低饱和高明度主题**：新增 `mist` 雾光青为默认，`azure / midnight / amber / forest / rose / violet / graphite / sunset` 全部重调；light 共用中性墨色 `#1D201F / #626663`，主题个性只由 primary / accent / sidebar / wash 承担。
2. **主题迁移**：写入 `appearance.designVersion=2`；仅在「无版本号且旧默认主题为 sunset」时一次性迁移到 mist；Rust `THEME_NAMES` 扩到 9 项，新增单测防前后端白名单漂移。
3. **壳层材质**：三色雾光 wash + 5% 细颗粒纸纹；内容区改为 18px 圆角白色纸面（66% 发丝边 + `shadow-sheet`），空态叠 560px 同心圆与三团 wash。
4. **空态重绘**：宋体大标题 + mono 眉标 + 星屿线稿 + 浅调 CTA + 「本地优先 · 自动保存」提示。
5. **控件全扁平**：撤销按钮内高光/渐变；主按钮 = accent 浅底 + 深字 + 20% primary ring；快捷钮只保留 32px 语义图标底片。
6. **工作区入口重做**：从大白卡改为透明品牌行——26px logo + 14px 工作区名 + 10.5px 知识库名，hover/展开只加 `sidebar-active` 55% 底，chevron 仅 hover/focus 出现；侧栏行 hover 白度降到 24–28%。
7. **左上清场**：`TrafficLightSlot` 撤掉 58×16 胶囊底座，红绿灯直接落在侧栏浅调上，不再有孤立浅色圆角块。
8. **字体层级**：空态标题/品牌字标改用宋体 `--font-display`；UI/正文仍走系统栈；眉标、键帽、数字走 mono。

## 方法论沉淀

- **白不是留白的答案**：近白背景 + 主题浅调画框 + 雾光/颗粒，比在纯白上堆白卡更有层次。
- **控件层级交给底色与发丝线**，不给每个按钮加内高光；立体感一重，整页就像 2010 年的拟物。
- **品牌入口用“行”不用“卡”**：一个透明行 + 两行信息，既省空间，也不会与快捷钮产生边框口径之争。
- **门禁先于观感**：9 主题对比度、tsc、Biome、构建、Rust 白名单单测全绿，再谈“好不好看”。
