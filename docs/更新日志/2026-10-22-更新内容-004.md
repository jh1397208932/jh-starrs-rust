## 一、数据与后端

1. 工作区库 v3 → v4，新增 `doc_block_meta`：
   - `id` 与 `node.id` 完全一致，删除节点级联删除；
   - `markdown` 存派生 Markdown，`prop` 存 JSON 属性，`update_time` 防止旧任务覆盖新结果。
2. 新增文档规范化（Rust 唯一权威实现）：
   - 删除 `emoji.name` 为空/null/非字符串的节点，修复历史 `:null:`；
   - 清除 null attrs、空 marks、空 text；规范化幂等。
3. 新增 Markdown/属性生成：
   - 标题、段落、marks、列表、任务、引用、代码块、分隔线、图片、表格、折叠块、emoji；
   - prop 含 version/wordCount/blockCount/headingCount/listCount/tableCount/codeBlockCount/imageCount。
4. 保存：改为 `BEGIN IMMEDIATE`，避免后台元数据写入时 Deferred 事务升级失败；正文提交后异步写元数据，连接不创建文件、不改 journal_mode，乱序写入被时间戳保护。
5. 加载：返回 `normalized` 标记；旧脏数据加载时重算字数并触发前端一次修复保存。
6. 后端测试 39 项全部通过，含迁移、规范化、Markdown、异步元数据、乱序任务、旧数据修复。

## 二、前端数据闭环

1. 确认并固化 `editor.getJSON()` 契约：根 doc 对象 + `content[]`；Rust 只切 content。
2. 修复 `setEditable()` 默认 emit update 导致“加载即脏/误保存旧文档”的问题（显式 `emitUpdate=false`）。
3. 保存器在拿到单飞锁后才取 `getJSON()`；编辑器已销毁时跳过快照，避免卸载竞态。
4. 加载后若 `normalized=true` 自动补一次保存，回显与块树一致。
5. 修复 `:null::null:`：移除 Emoji 的 `enableEmoticons` 空列表规则，并给渲染加空 name 守卫。

## 三、交互与视觉

1. 回车新块清理行内样式（官方 Extension.addKeyboardShortcuts）：
   - 列表用 `splitListItem` 保持列表结构；
   - 标题尾部回车显式插入正文段落；
   - 空列表/引用交还默认行为退出结构；
   - 代码块/表格/折叠标题不拦截。
2. 拖拽手柄重做（第二轮改为自绘，官方 DragHandle 已移除）：
   - **移除 `@tiptap/extension-drag-handle` 与 `-react`**：官方把手柄定位与 HTML5 DnD 绑定，WKWebView 下 `dragstart/dataTransfer/effectAllowed` 行为不一致，出现“手柄能拖、松手正文不动”；`mouseleave` 显隐也不可控；
   - 新增 `useBlockHandle`：按顶层块 DOM rect 自绘定位，180ms 离开缓冲，左侧走廊保持当前块，滚动/resize/keydown 隐藏，切换文档隐藏；
   - 新增 `useBlockPointerDrag`：pointerdown 4px 阈值、指针捕获、顶层落点计算、边缘自动滚动、Escape/blur/pointercancel 取消；松手后派发 `delete + insert` ProseMirror 事务；
   - 新增 `BlockDragHighlight`：用 Decoration 淡化源块（直接改 DOM class 会被 ProseMirror 重绘回滚）；
   - 目标块中文提示（拖动段落/标题/无序列表…）；＋在当前块后插入空段落并聚焦；
   - 自绘 3px 主色落点线（两端圆点）与跟随光标的块类型标签；官方 Dropcursor 仅保留给图片/文件原生拖放。
3. 行级落点线：块拖拽使用自绘 `.editor-block-drop-indicator`（3px 主色、两端圆点、全宽）；图片/文件原生拖放仍使用 StarterKit 官方 Dropcursor `.starris-drop-cursor`。实测拖动标题/列表到目标位置顺序真实改变。
4. 全块样式重构：
   - 840px 页面、40px 手柄走廊、15.5px/1.78 正文；
   - H1–H3、引用、代码块、分隔线、表格、图片（官方 ResizableNodeView）、折叠块、任务复选框、占位符；
   - 图片居中，四角 11px 缩放点，非 hover 不拦截点击；
   - 折叠块移除原生 summary 双箭头。
5. 浮层统一：Slash（304px，分组 + 说明 + 键帽）、右键（分组 + 640px 内滚动）、气泡（分隔 + 清除格式 + 颜色面板）；仅用语义令牌与 `--shadow-lg`，不使用 `!important` 覆盖官方内联样式。
6. 增强可访问性：手柄/按钮 aria-label、右键 role=menu、Slash role=menuitem + data-active、复选框原生 input。

## 五、已知限制

- 图片仍为 ≤2MB data URL，未接附件后端。
- Markdown 为派生文本，颜色/对齐等以近似语义表达，不反向驱动编辑器。
- 后台元数据允许短暂滞后；应用在写入前退出时，下一次保存/加载补齐。
- 自绘拖拽仅覆盖顶层块；触屏长按与键盘拖拽未实现。
- 大文档性能未做万块级基准，不声明加速数字。
