## 完成内容

### 1. Windows 编译与打包入口

- Tauri 配置按平台拆分：
  - `src-tauri/tauri.conf.json`：跨平台窗口、安全策略与通用 bundle 信息；
  - `src-tauri/tauri.macos.conf.json`：`macOSPrivateApi`、Overlay 红绿灯、DMG；
  - `src-tauri/tauri.windows.conf.json`：`decorations:false`、NSIS、WebView2 bootstrapper、安装器语言与图标。
- `Cargo.toml`：`macos-private-api` 改为 macOS 目标专属；`libc` 改为 Unix 目标专属；新增 Windows `windows-sys`（仅文件系统子集）。
- `package.json`：新增 `package:win`（`tauri build --bundles nsis`）。
- `biome.json`：`lineEnding: "auto"`，解决 Windows CRLF 与默认 LF 导致的全仓格式失败。

### 2. 窗口控制与 UI 适配

- 新增 `WindowControls`：46×32 贴右缘、最小化 / 最大化还原 / 关闭，关闭按钮 Win11 红 hover，最大化状态随窗口 resize 同步。
- 侧栏顶部新增 44px 拖拽带（非 macOS）；双击标题栏或拖拽带切换最大化，跳过按钮与标签页。
- 平台判定集中到 `lib/platform.ts`；i18n、`bindingLabel`、内置快捷键、空态、侧栏、Toast 徽标全部平台化，Windows 显示 `Ctrl/Alt/Shift`。
- 原生菜单只保留在 macOS；Windows/Linux 不挂菜单栏，避免与自绘顶栏重叠。
- 字体栈补充 Segoe UI 与 SimSun 回退。

### 3. 工作空间与文件操作

- `path_to_string` 还原 Windows `\\?\` / `\\?\UNC\` 前缀，工作区路径展示与持久化正常。
- 空目录判定忽略 `.DS_Store` / `Thumbs.db` / `desktop.ini`。
- 附件磁盘可用空间在 Windows 使用 `GetDiskFreeSpaceExW`。
- 保存对话框默认文件名统一清理 Windows 非法字符、结尾点/空格与设备保留名（附件 / 文档 / 画板 / 导图）。
- 新增平台单元测试：verbatim 前缀、UNC、系统噪音文件。
