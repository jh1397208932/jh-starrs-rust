## 渲染性能与动效（任务 001，三轮）

1. **真退场**：Radix 弹窗/菜单/下拉/Tooltip 关闭不再瞬灭——`forceMount + AnimatePresence` 真退场（弹窗 200/160ms、菜单与下拉 180/120ms），窗口标签、文档查找条、设置分区、Toast 同步补进出场；Toast 去弹簧回弹。
2. **原生毛玻璃**：窗口 `transparent + windowEffects(underWindowBackground)`，壳层 86% / 纸面 92–94% 半透明，浮层 90–95% + 12px blur + saturate；大面积模糊交给 macOS vibrancy。
3. **拖拽**：弹窗标题区可拖动；文件树隐藏系统拖影、改为跟手拖拽牌 + 行间滑动落点线；修复导图节点拖拽中被旧坐标覆盖（“只在拖动前后生效”）。
4. **其他**：侧栏折叠宽度 220ms 过渡；启动遮罩半透明淡入；按钮/标签/开关等微交互统一到 120/220/380ms 刻度。
5. **验证**：全量黑盒 e2e 多轮 30/30（`tmp/e2e/20261028T0*`）；浏览器采样退场中间态；30% alpha 实验验证透明链路。

## 构建与打包

- `package.json` 新增：`debug`（HMR+devtools+debug 日志）、`debug:build`（生产前端+debug 二进制）、`build:prod` / `build:prod:dmg`（Rust release lto/strip + 前端 Oxc 压缩、无 sourcemap/devtools/debug 日志）、`build:prod:win`（Windows NSIS；需 Windows/CI）。
