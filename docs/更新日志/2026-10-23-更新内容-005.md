- 关联规范：UI-SPEC.md §2（主按钮范式）、§5A.0（第六轮准则）

## 背景（用户反馈）

整体色彩仍不够明亮：蓝色应是「浅色天蓝、明度高、饱和度低」；按钮应是「浅色高明度描边 + 白色中心背景 + 合适字体」；要 Apple 及主流软件的轻盈感，「眼前一亮」，不被已有风格束缚。

## 完成内容

1. **中性 chrome（8 主题 light 统一）**：sidebar `#F5F5F7`、secondary/muted `#F0F0F3`、border `#E0E0E5`、input `#D9D9DE`，暖调主题底与暖调阴影全部中性化。
2. **primary 高明度化**（vs 白 ≥3.0）：sunset `#DF751E` / azure `#2B97E8` / midnight `#7377F2` / amber `#C48408` / forest `#2FA35A` / rose `#EA5F7C` / violet `#8B5CF6` / graphite `#707880`；accent 浅调、accent-fg 深字、sidebar-active 浅调 pill 随之重算；logo/glow 跟随。
3. **按钮范式切换**：`button.tsx` default 变体 = `bg-accent` + `text-accent-foreground` + `ring-primary/25` 内描边 + hover `bg-primary/15`；link 变体改 `text-accent-foreground`；空态 CTA 同步；白字填充仅剩 destructive（语义红）与 dark。
4. **门禁升级**：`check-contrast.mjs` 第六轮线——移除 light `primary-foreground/primary` 白字检查，新增 `accent-foreground vs background ≥4.5`（白心按钮深字），8 主题 PASS。
5. UI-SPEC §2 主按钮行、§5A 拆分 5A.0（第六轮现行）/ 5A.1（第五轮历史，白字规则标注退役）。
