## 用户可见的变化

1. **PDF 可以直接导入成文档**：在「更多 → 导入…」里和 Markdown/Word 一起选择 `.pdf`，会生成同名文档；标题、段落、列表、表格尽量保留为可编辑块，原始 PDF 附在文档末尾。
2. **扫描件不再假装成功**：扫描版/图片版 PDF 会生成一份带说明的文档，并保留原始 PDF；导入结果里会写「扫描件、未启用 OCR」和需要 OCR 的页码。没有 OCR 就不伪造正文。
3. **导入结果更具体**：以前只显示「部分内容有格式警告」，现在列出前 3 条具体原因（文件名：原因）。
4. **导入说明**：弹窗顶部注明支持 PDF，以及扫描件当前会保留原件并提示。

## 实现要点

- 引入 `pdf-inspector 1.25.2`（MIT，纯 Rust，默认特性无 OCR/无模型/无外部服务），由它完成 PDF 分类与 Markdown 提取。
- Markdown → Tiptap 复用现有 `import_markdown::parse_markdown`，不引入第二套块解析；原始文件复用现有导入的 `attachmentBlock` 附件链路。
- 单份 PDF 上限 128 MB；加密/损坏走现有导入兜底（文档 + 说明 + 原始附件），不崩溃。
- 日志记录 PDF 分类、页数、置信度与耗时，便于后续判断是否需要 OCR。

## 未采用

- **本轮不启用 OCR**：`ocr` / `ocr-oar` / `render-pdfium` 特性会引入 ONNX Runtime、PDFium 与模型下载，体积与部署成本高；扫描件先保留原件并提示。
- **不保留精确版式**：PDF 的分页、页眉页脚、批注与表单不进入文档，只保证文字结构可编辑。
