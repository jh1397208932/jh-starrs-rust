# 更新日志 · 2026-10-23 · 主界面单行顶栏与清新扁平化（004）

- 关联归档：`docs/设计/2026-10-23-顶栏单行化-001/`（优化方案 + 前后截图）
- 关联规范：UI-SPEC.md §4（圆角节奏 / 以色代线）、§5（Magic UI 清单）

## 背景（用户两轮反馈）

1. 参考 wolai 布局：顶栏区域（窗口栏 + 文档工具栏两行）线条太多、太硬、太复杂、布局杂乱；
2. 整体重设计：直角/圆角混排不协调；图标字体太浓郁（侧栏尤甚）；新建文档按钮（深橙扫光）与主题不搭、厚重；要求「扁平简洁高端、清新、不浑浊、不厚重」。

## 完成内容

1. **顶栏两行并一行（44px 单行制）**
   - 原 `Toolbar.tsx`（36px 文档层）整组件删除，职责并入 `WindowBar.tsx`：标签页组 + 所在位置面包屑（知识库 › 文档，去 Badge 盒）+ 保存状态（缩短为「已保存」）+ 收藏/目录/信息/分享/打印 + 搜索胶囊 + 设置 + Windows 窗控；
   - `WorkspaceLayout.tsx` 相应精简；`--doctoolbar-h` 令牌删除（tokens.css）。
2. **以色代线（参考 wolai）**
   - 顶栏去 `border-b`、侧栏列去 `border-r`：顶栏与侧栏同为 `bg-sidebar` 连成 L 形色块，内容区 `bg-background`，分界全靠色差；
   - 激活标签页改无边框药丸（`bg-background`，30px 高），废弃原梯形描边 tab（border + -mb-px + shadow 骑缝）；
   - 搜索胶囊去描边（白底无边框），⌘K 键帽去边框改裸 mono 文本；右侧两组竖分隔线 span 删除；
   - hover 统一 `bg-foreground/5`（原 `bg-secondary` 在侧栏底色上不可见）。
3. **清新扁平化**
   - 新建文档 CTA：ShimmerButton（深橙底 + 金色扫光 + 内高光 + 全圆角）→ 扁平 tonal 按钮（`bg-accent` 浅橙底 + `accent-foreground` 字，hover 反填 `bg-primary` 白字，10px 圆角）；
   - `ShimmerButton.tsx` 组件与 app.css 扫光 keyframes（starris-shimmer-slide/spin-around）一并删除（唯一调用方即该 CTA）；
   - 侧栏减淡：文件树图标由继承前景色（近黑）改为 `text-sidebar-muted`（选中态随 `sidebar-active-fg`）；选中字重 semibold→medium；工作区名 bold 15px→medium 14.5px；更多按钮 ⌘J 键帽改裸文本。
4. **圆角统一（消直角/圆角混排）**
   - 交互控件（树行、快捷钮、工作区按钮、更多、图标钮、标签页、面包屑）一律 10px；小件（行内关闭/操作钮）8px；搜索胶囊保留 pill；UI-SPEC §4 固化「交互控件一律 10px，禁止同界面混排多档」。
