# 更新日志 · 2026-10-23 · 细节打磨与成熟范式收敛（008）

- 关联归档：`docs/设计/2026-10-23-细节打磨-001/`（方案迭代说明 + sunset/azure 终态截图）

## 背景（用户 6 条反馈 + 1 条追加 + 1 条修正）

①按钮边界没了 ②角落过渡不够优美 ③字体颜色不合适 ④区域颜色与主题色过渡不平滑 ⑤顶栏加号多余 ⑥细节纹理少（毛玻璃/色彩过渡）；追加：可适当半透明；修正：「当前效果很差，寻找成熟的设计方案」。

## 终态内容

1. **内容区圆角薄片**：`rounded-tl-[14px]` + `border-l/t border-border/60` 发丝边——Ventura 设置式内容薄片（问题②④）。
2. **顶栏移除新建标签 "+"**（问题⑤）：WindowBar 删按钮并清理 `onNew` prop 链。
3. **空态 CTA 白心化**（问题③）：白底 + `ring-primary/30` 描边 + 深色字 + 主色 "+" 图标，hover 落 accent 浅调。
4. **毛玻璃浮层铺开**（问题⑥+追加）：DropdownMenuContent `rounded-[12px] bg-popover/85 + backdrop-blur-xl`；InfoFloat `bg-card/85 + backdrop-blur-xl`（把手 blur）；DialogContent `bg-popover/90 + backdrop-blur-2xl`（遮罩原已 blur）；AppToast `bg-popover/85 + backdrop-blur-xl`。
5. **白卡/渐变方案回退（成熟范式收敛）**：用户对白卡+chrome 渐变不满意 → 对照 Notion/Apple 备忘录/Ventura 设置回退为扁平侧栏：工作区钮/快捷钮/更多/树 hover 全部恢复浅调底（bg-secondary），无描边无卡片；`.chrome-gradient` 工具类删除（死代码清理）。侧栏主题色由底色与选中 pill 承担。

## 验证

- tsc / biome / build 三绿；
- mock-IPC 截图 sunset ×3 + azure ×3 无页面错误。

## 方法论沉淀

- 侧栏成熟范式 = 扁平浅调 + hover 浅调底 + 选中主题 pill；卡片描边在列表型侧栏是业余信号；
- 毛玻璃只用于「浮层」（菜单/浮窗/弹窗/Toast），chrome 层保持扁平；
- 用户方向摇摆（要边界→嫌卡片差）时，先取成熟产品参照而不是继续加装饰。
