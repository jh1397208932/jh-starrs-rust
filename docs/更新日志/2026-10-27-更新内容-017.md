# 更新日志 · 2026-10-27 · 全量代码审查修复与 UI 走查（017）

## 一、全量代码审查（Rust / 思维导图前端 / 其余前端）

三路并行审查，逐条复核后修复：

### 安全与数据完整性

- **目录令牌 `..` 越界**：`resolve_write` 的 `Path::starts_with` 把 `..` 当普通组件，`/granted/../evil` 可通过前缀检查。现在拒绝含 `ParentDir` 的导出路径，并加回归测试。
- **MCP 启动副作用**：`starris-mcp` 原先复用桌面启动流程，会改写 `current_workspace`、清理回收站、并清空桌面端正在写的日志。新增 `initialize_headless`：日志追加模式、只装载工作区不写全局偏好、不跑回收站清理。
- **审批可重复执行**：`approve` 先读状态再执行写入，双击/并发会执行两次。改为原子认领（`WHERE status='pending'`），失败写 `failed`；新增单次审批回归测试。
- **节点工具跨作用域**：`node_rename/node_move/node_create_folder/node_trash` 可作用于任意节点类型却使用固定作用域。现在按目标节点类型解析：画板→board、导图→mindmap，其余（文档/文件夹/附件等）→doc；新增作用域跟随测试。
- **迁移外键检查时机**：`foreign_key_check` 原在提交后执行，失败会留下“版本已升级但数据是坏的”库。现已移入事务、提交前拦截。
- **XMind 导入图片失败**：单张图上传失败会让整张画布保存失败（节点已建、主题全丢）。现在丢弃该图片并记 warning，画布其余内容照常导入。
- **导出/切换数据丢失**：导出不再用加载时的过期 `baseVersion`，改走持久化 `flush`；工作区新建/打开/切换/删除前统一 `flushActivePersistence`，未保存则中止并提示。
- **撤销/重做不落盘**：历史层现在把 apply/undo/redo 的内容变化都回调持久化，撤销后关闭不会复活旧内容。
- **保存竞态**：在途保存期间的新改动会设置 pending 并在结束后补存；`flush` 循环等待在途与后续保存，避免“dirty 被误清空导致关闭丢改动”。
- **冲突判定依赖译文**：文档/画板/导图改用 `isConflictError` 判断 Rust 原始错误文本，英文界面下冲突横幅与重载入口不再失效。
- **移动主题连带清引用**：换父/升级改用摘挂（`detachTopic`），不再经过会清理关系线/外框/概要的删除路径；自由主题吸附同理。
- **自由主题与概要删除**：支持删除自由主题子树内节点与概要结论主题（同时移除概要）。

### MCP 工具 schema

- 20 个工具此前声明“无参数”，严格按 schema 调用的 agent 会直接失败。现在 21 个工具都有完整 `properties` / `required`（节点、段落、画板元素、节点管理、回收站），`test/mcp/smoke.mjs` 增加逐工具 required 断言。

### DDL 登记表统一（用户新增任务）

- `db/workspace.rs` 新增 `REQUIRED_STRUCTURES` 单一清单（表名 + 缺失时的幂等补齐语句）：初始化门、结构自愈与修复测试共用。
- `needs_initialization` 与 `structure_needs_repair` 现在完全一致；基线表缺失时执行幂等 `SCHEMA`，迁移期产物按各自批次补齐（含 `search_index`、`doc_history`、`mindmap_viewport`、`doc_block_meta`、`ai_audit`）。
- 新增测试 `ensure_initialized_repairs_every_registered_structure`：同时删除基线表与迁移期产物后，一次初始化全部补齐且门恢复为 false。
- 业务路径仍只做轻量目录查询；结构就绪后才渲染（前端等待 `app_bootstrap_status`）。

### 前端交互与 UI（真机截图走查）

- **PNG/SVG 导出补齐**：此前只画树连线与文本，关系线、外框、概要、主题边框色/填充/形状/粗细、自动编号全部丢失，自由主题子树也不展开。现在导出与画布同一套布局语义，并新增真机导出用例（PNG 文件头/尺寸、SVG 头校验）。
- **外框/概要不可选中**：装饰层 `pointer-events:none` 导致检查器的标签/颜色/删除是死代码。pane 点击现在做几何命中（`hitTestFrame`），选中后显示描边并提供原有编辑面板；新增纯逻辑测试。
- **检查器原生文件控件**：`Choose File no file selected` 替换为设计语言内的「选择图片 / 更换图片」按钮；取消选择不再上传 0 字节文件。
- **边框/填充色板**：12 色改为 6×2 网格，不再 10+2 断行。
- **系统蓝色焦点环**：设置页仍出现 WebKit 默认蓝框，与既定“全局去焦点环”冲突；补上全局 `:focus,:focus-visible{outline:none}`。
- **失败提示**：destructive toast 不再显示红底对勾，改为 `!` 且 `role=alert`。
- **硬编码琥珀色**：导入失败提示与快捷键冲突提示改用 `--logo-c` 令牌。
- **弹窗快捷键守卫**：有 `[role=dialog]` 时应用级快捷键不触发（重命名输入时 ⌘N 不再叠弹窗）。
- **文档加载失败**：两个失败分支恢复 `setEditable(true)`，修好保存问题后正文不再永久只读。
- **导入后打开**：思维导图导入后从 `nodesRef` 读取刷新后的节点，首个节点能立即打开。
- **导图加载失败重试**：加载态「重试」改为重新加载（原先调用保存重试是空操作），文案改为「加载失败 · 重试」。
