# 更新日志 · 2026-10-23 · 参考稿校准：近中性 chrome + 白块边界（009）

- 关联归档：`docs/设计/2026-10-23-参考稿校准-001/`

## 背景（用户 3 条反馈 + 1 张参考稿）

①内容纯白与暖黄侧栏不协调 ②内容薄片圆角处边框样式错误 ③按钮/树没有边界；随后给出 wolai 式参考稿定调：侧栏近乎中性暖白、内容纯白、色彩只出现在选中 pill/徽标/图标。

## 终态

1. **8 主题 light chrome 降饱和至近中性**（sidebar sunset `#F8F6F2` / azure `#F5F9FD` / midnight `#F6F6FC` / amber `#F9F7EE` / forest `#F3F8F4` / rose `#FBF5F7` / violet `#F7F5FD` / graphite `#F4F5F6`；secondary/border/input 同步），内容区回归纯白——协调性来自两侧贴近。
2. **内容薄片圆角修正**：border-l/t 移除，改 `shadow-[0_0_0_1px_rgb(0_0_0/.04),0_2px_12px_rgb(0_0_0/.05)]`（描边随弧度 + 轻浮起）。
3. **边界（白块语言）**：工作区钮/快捷钮白卡 + 发丝边；树行白块填充 + 行间 2px 间隙（hover `accent/60`、选中主题 pill）；树图标 `text-primary/70`（参考稿暖色图标）；顶栏激活 tab `ring-border/50`、搜索胶囊 `border-border/60`、图标钮 hover `bg-secondary`。

## 验证

- check-contrast 8 主题 PASS；tsc / biome / build 三绿；mock-IPC 截图 sunset ×3 无页面错误。

## 备注

- primary/accent/按钮范式/dark 均未动；本轮校准 chrome 中性度与边界语言。
