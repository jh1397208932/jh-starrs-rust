- 用户要求：知识库选择写入全局记忆。

## 完成内容

1. 新增工作区级记忆键 `kb.current.<workspaceId>`，记录该工作区当前选择的知识库；不同工作区互不覆盖。
2. `useWorkspaceStore`：
   - 启动/切换工作区时，从 `app_bootstrap` 的记忆快照读取该工作区当前知识库；
   - 选择顺序：显式指定 → 记忆值 → 当前值 → 第一个库；
   - 知识库切换成功前先写全局记忆，写失败则保持原库；
   - 记忆值指向已删除/不存在的库时回退第一个库并回写；
   - 写入通过 Promise 队列串行化，避免快速切换时旧请求覆盖新选择。
3. Rust 记忆用例增加 `kb.current.ws-1` 键读写断言。
4. 真实 Tauri 窗口补测并归档截图：预置记忆启动选中第二个库 → 真实鼠标切换第一个库 → 全局库写入 → ⌘Q 重启恢复第一个库。
