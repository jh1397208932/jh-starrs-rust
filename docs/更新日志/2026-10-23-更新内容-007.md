# 更新日志 · 2026-10-23 · 主题色回归：高明度主题浅调 chrome（007）

- 关联归档：`docs/设计/2026-10-23-主题色回归-001/`（方案 + sunset/azure 截图）

## 背景

用户反馈第六轮「全是灰色、没有颜色风格」——中性灰 chrome 走过头，主题色个性丢失。需要在不牺牲明亮轻盈感的前提下把主题色请回来。

## 变更（仅 tokens.css 浅色块 + 侧栏快捷钮图标）

1. **主题浅调 chrome 回归**（8 主题 light，比旧暖米色更亮更淡）：
   - sidebar：sunset `#FBF4EB` / azure `#F1F8FE` / midnight `#F2F2FD` / amber `#FBF7E6` / forest `#F0F8F2` / rose `#FDF2F5` / violet `#F5F2FE` / graphite `#F3F4F6`；
   - secondary/muted（hover 底）、sidebar-active（选中 pill）、border、input 同步主题化，全部过对比门禁（border ≥1.30、sb-muted ≥4.5、act-fg ≥4.5、mut/sec ≥4.5）。
2. **快捷钮图标 primary 化**：Sidebar 收藏/小记/新建图标 `text-primary`，标签保持 muted。
3. 内容区维持纯白——「白纸 + 主题色画框」；accent / accent-fg / primary（第六轮值）不动。

## 验证

- 独立 ratio 脚本预校 + `check-contrast.mjs --check` 8 主题 PASS；
- tsc / biome / build 三绿；
- mock-IPC 截图 sunset ×3 + azure ×3 无页面错误。

## 备注

- 主色、按钮范式、dark 模式均未动；本轮是 chrome 层的「色彩个性回填」。
- 若某主题想要更强/更弱倾向，调该主题 sidebar/secondary/active 三个值即可，门禁会自动把关。
