# 更新日志 · 2026-10-21 · 正文字色中性化（003）

- 关联：需求 `docs/需求文档/2026-10-21-需求文档-正文字色中性化.md`；任务 `docs/开发任务清单/2026-10-21-任务-002/`
- 用户反馈：主题字体颜色偏向主题色（应为偏黑），与背景对比度不够。

## 问题诊断

8 主题浅色的正文字色（foreground/card/popover/sidebar/secondary-foreground）均为主题色相深色变体（sunset 暖棕 #2C241E、azure 深蓝 #14283C、forest 深绿 #1C2E24…），正文与底色同色相互相加强——文字"泛主题色"而非黑，层级感知下降。违反 tinted neutral 原则（Impeccable：中性色 chroma 0.005~0.01 足够，白底文字用深灰 明度 12~18% 禁纯黑）。

## 完成内容（仅改 tokens.css light 块；dark 与品牌强调色不动）

1. **foreground / card-foreground / popover-foreground 中性近黑**（chroma ≤8、明度 ~13%）：如 sunset #2C241E→#221F1B、azure #14283C→#1E2226、forest #1C2E24→#1D2320（保留 ≤1% 暖/冷倾向区分主题温度）；graphite 原本中性未动。
2. **sidebar-foreground / secondary-foreground 中性深灰**：对比分别 ≥9.4 / ≥8.3。
3. **色相分工确立并写入 UI-SPEC §5A**：正文/结构文字 = tinted neutral；muted-fg = 轻倾向辅助灰；强调/激活 = 主题色。

## 验证结果

- 脚本复验 8 主题：fg 对比 14.8~15.9（chroma 6~8）、card-fg ≥16.0、sidebar-fg ≥9.4、secondary-fg ≥8.3，全部达标。
- biome check 61 文件零问题；headless Chrome 截图 `docs/设计/2026-10-21-正文色中性化-001/图片/sunset-light-正文近黑.png`——标题/正文为干净近黑，不再泛棕。
