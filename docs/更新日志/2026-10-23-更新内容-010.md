# 更新日志 · 2026-10-23 · 扁平收敛：侧栏成面、行透明（010）

- 关联归档：`docs/设计/2026-10-23-第十轮扁平收敛-001/`

## 背景

用户指出第九轮「万物垫白块」效果奇怪（白卡 ×12 堆在近白底上，骨架屏既视感）。

## 终态

1. 侧栏由"近白"加深为可感知浅灰面（sunset `#F4F2ED` / azure `#EFF4F9` / midnight `#F0F0F8` / amber `#F4F1E7` / forest `#EFF4F1` / rose `#F6F0F2` / violet `#F1EFF9` / graphite `#F0F1F2`），secondary（hover 底）同步微调；
2. 撤销全部白块：工作区钮 / 快捷钮 / 树行恢复透明行 + hover 浅灰底；选中 = 主题 pill；
3. 白块仅保留给浮控件：顶栏激活 tab（ring 发丝边）、搜索胶囊（border）；内容薄片、毛玻璃、树图标 primary/70 保留。

## 验证

- check-contrast 8 主题 PASS；tsc / biome / build 三绿；mock-IPC 截图 sunset ×3 无页面错误。

## 方法论沉淀

- **面的层次**：chrome（深一档的灰面）→ 行（透明）→ 浮控件（白块）——块只给浮起来的东西；
- 反馈两级：hover 灰、选中主题色；色彩只出现在选中态与点缀。
