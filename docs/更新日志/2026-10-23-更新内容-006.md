# 更新日志 · 2026-10-23 · 浅调范式收尾：白字残留清理 + dark 适配（006）

- 关联归档：`docs/设计/2026-10-23-明亮轻盈风-001/`（本轮补 dark 模式截图：`*-dark-*.png`）

## 背景

第五轮遗留的「白字填充」点位在第六轮提亮 primary 后对比不足（3:1 边缘，普通字号不达 AA）；且 hover 加深在 dark 模式几乎不可见。

## 变更

1. **白字残留清零**（浅色主题）：
   - 编辑器链接「应用」按钮 ×2（BubbleMenu / ContextMenu）→ 浅调描边样式；
   - `Badge` solid 变体：`bg-primary + 白字` → `bg-primary/15 + accent-fg`（深浅模式通用）；
   - `AppToast` 成功态圆点：同款浅调化（destructive 仍实底白字）。
2. **hover 加深双模式自适应**：主按钮 / CTA / 链接应用钮的 hover 由 `bg-primary/15` 改 `bg-accent-foreground/15`——light 下加深、dark 下提亮，一举解决 dark 不可见。
3. 保留 `bg-primary` 纯图形用法（开关选中、拖拽指示线、圆点、分隔）——3:1 图形标准达标。
