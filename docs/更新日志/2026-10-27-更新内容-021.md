# 更新日志 · 2026-10-27 · 存储页附件保留时间下拉样式修复（021）

- 用户反馈：设置 → 存储 → 附件区的「永久保留」下拉显示为 macOS 系统默认凸起样式，与相邻输入框不符。
- 原因：它是全代码库唯一的原生 `<select>`，WebKit 未去系统外观时会自带凸起与步进箭头。
- 修复：`AttachmentManager.tsx` 中为该 select 增加 `appearance-none`、固定宽度与右侧自绘 `ChevronDown`（pointer-events-none），禁用态 60% 透明；选项与读写逻辑（`ttlSeconds`）不变。
- 测试配套：
  - `50-settings` 在进入存储页后新增 `settings-storage` 截图（此前该页无截图）；
  - 独立运行（未先跑 `40-board`）时跳过“附件插入画板”段，避免 `ctx.shared.boardTitle` 为 undefined 导致误报失败。
- 验证：typecheck 0、biome 0、build 0；真机 `tmp/e2e/20261027T085056`（00 + 50-settings）2/2 通过，`settings-storage.png` 中下拉与输入框风格一致、箭头为自绘。
