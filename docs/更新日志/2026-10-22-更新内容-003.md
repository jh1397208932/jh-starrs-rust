## 完成内容

1. **工作区库 v3**
   - 新增 `doc_block_hash(hash, json)` 与 `doc_block_tree(id, node_id, hash, order)`；
   - v1→v2→v3 顺序迁移，旧数据保留；`node.content` 保存完整 Tiptap JSON 缓存。
2. **Rust 块存储**
   - xxh3-128 内容哈希（32 位 hex），重复块复用 hash、实例独立 UUIDv7；
   - LIS 锚点 + base62 Fractional Index 最小重排；32 字符上限；失败整篇等距重排；
   - 删除块后检查 hash 引用，最后引用消失才进入 `rm`；
   - `doc_load` / `doc_save` 返回 `add/rm/order/tree/wordCount/updatedAt`；
   - 保存全程工作区互斥 + 单事务。
3. **前端自动保存**
   - 编辑后 1s 防抖；单飞互斥；锁冲突延长本次 1s 且不取消新编辑防抖；
   - 拿到锁后才 `editor.getJSON()`；保存中再编辑会在结束后再排一次；
   - 切换标签/文档/工作区/知识库前 flush，失败阻止切换并提示；
   - meta 行显示字数与“正在保存/已保存/保存失败·重试”。
4. **编辑器**
   - MIT 扩展：TextStyle/Color、Highlight、TextAlign、上下标、任务列表、表格（可调列宽）、图片（可缩放，≤2MB data URL）、代码高亮、Emoji、折叠块、TOC、拖拽手柄、Placeholder、CharacterCount、FileHandler；
   - 选区气泡菜单（B/I/U/S/Code/颜色/高亮/链接/上下标）；
   - 右键浮层（块类型/颜色/高亮/对齐/插入/表格上下文/链接/表情）；
   - Slash 菜单过滤 + ↑↓/Enter/Esc；
   - Toolbar 大纲接入真实 TOC；
   - 表格/任务/折叠/图片/高亮/代码高亮样式补齐。
5. **许可证**
   - 53 个 `@tiptap/*`（含传递依赖）全部 MIT；新增 `xxhash-rust 0.8.19` 为 Boost 1.0；
   - 门禁显式允许 BSL-1.0（Boost 宽松许可，区别于 BUSL），并记录依据。
