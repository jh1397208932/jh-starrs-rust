# 更新日志 · 2026-10-27 · 思维导图体验修复（020）

对应需求：`docs/需求文档/2026-10-27-需求文档-思维导图体验修复.md`；任务：`docs/开发任务清单/2026-10-27-任务-017/`。

## 用户可见变化

- **不再整页闪烁**：画布改用 React Flow 受控节点 + 只渲染可视区域，拖拽期间不再每帧重建节点；同时修复了开发态首次加载新依赖时 Vite 整页 reload 冲掉标签页的问题。
- **标签/标记/贴纸/备注/链接都在节点内**：节点下方新增元信息行；悬停节点浮出卡片显示备注全文、标签、标记中文名与链接，关闭检查器后仍可查看。
- **链接可一键用系统默认浏览器打开**：节点内的「打开链接」与悬停卡链接都走系统 opener（仅 http/https/mailto）。
- **默认配色更鲜艳**：新导图默认 `vivid` 主题，分支使用 6 组高饱和色；旧数据里的 `auto` 打开时也按鲜艳分支渲染并归一为 `vivid`（首次编辑后落盘）；边框/填充色板扩到 32 色（含旧色兼容）。
- **下划线不再变空**：只去掉上/左/右边框，保留浅底与 3px 底线。
- **内容多时自动扩宽/扩高**：测量把标记、贴纸、标签、备注、链接计入宽高，并按真实折行计算元信息行数；根主题以原点为中心，变宽时不会把中心挤出屏幕。
- **检查器改为按需浮动卡**：宽 300px，浮在画布右侧，可随时收起；点选节点不再自动弹面板，改用工具栏「主题详情」按钮打开。
- **大纲改为左侧浮动卡**：层级缩进、分支色点、主题计数，不占画布宽度。
- **动效与流畅度**：节点入场淡入缩放、悬停浮起、选中描边过渡、浮层滑入；适配 `prefers-reduced-motion`。
- **新导图居中**：等 React Flow 量出节点尺寸后再适配视口，首次缩放上限 100%，根主题落在可视中心。
- **工具栏与搜索框真正居中**：改用 `translate` 属性居中，入场动画不再在结束帧覆盖水平位移；检查器打开时工具栏自动左移，避免按钮被浮层盖住。
- **平移不再重播入场动画**：节点入场动画只给首次出现的节点，`onlyRenderVisibleElements` 重挂节点时不会闪烁。
- **星期标记可读**：节点徽标由「一」改为「周一」…「周日」，不再像一条破折号。
- **英文界面补齐**：新增 `主题详情`、`缤纷（默认）` 两条英文文案，导图 UI 不再回退中文。
- **大纲新建即可输入**：在大纲里新建子主题后直接进入行内编辑并聚焦（此前编辑态留在画布，需再双击一次）。

## 修掉的根因

1. `vite.config.ts` 未预构建 Tauri 插件包：会话中首次加载 `@tauri-apps/plugin-opener` 触发依赖重优化整页 reload（`vite.log` 有 `optimized dependencies changed. reloading`）。
2. 视口初始化在节点测量完成前执行：`fitView` 得不到包围盒，视口停在 `(0,0,1)`，根主题落在画布左上角。
3. `measureTopic` 把元信息固定按 18px/行估算：chip 折行后节点高度不足，标题被顶出节点并被画布裁掉。
4. 点选即打开检查器：300px 浮层遮住右侧节点，真机拖拽起点落在面板上。
5. 切换导图未清空上一张图的 `initial`：新画布用旧图的视口初始化且只初始化一次。
6. 大纲色点引用的分支色变量只定义在画布上：大纲是画布的兄弟节点，取不到变量而全部显示灰色；分支色板与主题属性已上移到 `.mindmap-workspace`。
