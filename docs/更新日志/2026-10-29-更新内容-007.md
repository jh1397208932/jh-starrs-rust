## 思维导图

- **连接线不再随节点数消失**：父子线改为按布局坐标自绘 SVG（挂在 React Flow 的视口门户内，随平移缩放一起变换）。此前走 edge 通道，端点节点一旦在视口外就没有测量结果，`getEdgePosition` 返回 null 导致整条线被静默丢弃；时间线/鱼骨/向上组织还引用了节点上不存在的 handle。现在端点只由布局坐标决定，节点上的 `Handle` 与两个 edge 组件一并删除。
- **关系线仍可点选**：关系线也在同一层 SVG 里绘制，笔画本身接收指针事件，并补了 `role`/`tabIndex`/Enter-Space 的键盘可达路径。
- **大纲层级再深也能操作**：行缩进按 8 层封顶（超出显示 `+N`），文本省略、hover 动作按钮固定在行右侧；在大纲里点行会直接打开右侧主题检查器。
- **编辑时其余节点不再发虚**：编辑态不再把被编辑节点换成不透明白卡，只加一圈描边；显式导航的缩放从 1.05 改为 100%，避免整屏文字按非整数设备像素重采样。
- **分支配色更艳丽**：六个分支色同色相提高饱和度（红 `#e0433c`、橙 `#c25c04`、青 `#07947a`、蓝 `#2277e0`、紫 `#9b47e8`、粉 `#dd3e7b`），描边强度 62%→88%，填充 16%→22%，根节点填充 30%。新增门禁 `npm run check:mindmap-colors`，明暗两档都要求描边对比 ≥3.0、文字对比 ≥4.5、饱和度 ≥45%。

## 性能与稳定性

- 保存链不再背靠背连打：一次保存结束若还有新内容，退回 800ms 防抖再存，而不是立刻再发一次全树 IPC；`flush()` 等待上限 8s，切标签/切库不会被打字期的保存链永久挂住。
- 测量缓存在 5 万条时按插入顺序淘汰 1/4（原来整表清空会把下一帧变成全量重测）。
- 文件树 `toggleFolder` 收进 `useCallback`，恢复行级 memo（每次自动保存不再整树重渲染）。
- 极限规模实测（Node 基准，非浏览器）：1000 主题布局中位 1.0ms / 5000 主题 3.4ms，整树 `JSON.stringify` 1.1ms——布局本身不是瓶颈，剩余成本在 DOM 重建与界面渲染。
- 检索索引实测（同一套 FTS5 trigram 结构 + 触发器，临时库）：25 KB 正文每次保存整篇重建平均 **1.5 ms**（24 KB 级文档 0.1 ms）——"每次保存都重建全文索引"不是热点，没有为它引入搜索延迟的必要。
- 异步任务改为有界队列：文档元数据单工作线程 + 64 容量队列（满则丢弃派生写入），附件维护单消费者 + 请求合并，备份在数据库快照落盘后立即释放工作区会话锁。全仓 spawn 清单已写入任务文档（每处标注是否有界）。

## 磁盘

- `[profile.dev] debug = "line-tables-only"`：默认全量 debug info 会把 `target/debug` 撑到几十 GB。
- e2e 不再每轮全量构建：只有源码比 debug 二进制新才重编（`E2E_SKIP_BUILD=1` 可强制跳过）。
- 三处测试包装脚本的 stdout/stderr 改为覆盖写，并加 `ulimit -f` 200MiB 硬上限。
- AI 审计与待审区不再只插不删：30 天保留期 + 审计 2000 条/待审 500 条上限，未处理的待审项不受条数上限影响。

## 数据可靠性

- 文档保存遇到数据库错误时，先换一条新的工作区连接再重试一次：长时间运行的连接在外部写入替换 WAL/SHM 之后会一直返回 `disk I/O error`，换连接即可恢复；重开保留工作区 id、根目录与库路径。全量 e2e 长跑中 98/99 两例的 `disk I/O error` 由此覆盖。
- 前端 dirty 状态兜底不变：两次都失败时仍保留未保存内容，由用户手动重试或关闭时拦截。
