# 2026-10-22 更新内容 006：文档图片块与附件块

## 一、编辑器块

1. 新增 `attachmentImage` 图片块（atom + React NodeView）：
   - 通过附件模块读取原始字节生成 Blob URL 预览，不在文档 JSON 写 base64/src；
   - 左/中/右对齐，选中 2px 主色环；
   - 左右拖拽缩放 120px–正文宽度，`width` 持久化；
   - 选中浮条含对齐与「下载原图」；块手柄可拖动排序；
   - 加载/失败/超过 20 MiB 显示占位与下载兜底。
2. 新增 `attachmentBlock` 附件块（atom + React NodeView）：
   - 一个块承载 1..N 个附件；`items` 存 attachmentId/name/size/mime + 组内 uid；
   - 卡片网格（210px）与长条列表（全宽）两种形态；
   - 组级左/中/右对齐；选中浮条切换对齐与形态；
   - 逐项下载、移除，移除最后一项删除整块；
   - 名称/大小直接用节点元数据回显，不读取对象内容。
3. 新增自绘文件类型图标 `FileTypeIcon`：56×68 / 36×44 折角页面、类型色、扩展名标签；覆盖图片/PDF/文档/表格/演示/压缩/音频/视频/代码/Markdown/JSON/文本/通用，颜色全部走语义令牌。
4. 文字 BubbleMenu 在 NodeSelection（图片/附件块）时隐藏，避免与块浮条叠加。

## 二、对象模块接入

1. 新增 raw IPC：
   - `attachment_read_bytes`：图片附件读取原始字节（仅 image MIME、≤20 MiB），以 ArrayBuffer 返回；
   - `attachment_upload_bytes`：剪贴板/拖放 File 的原始字节上传；文件名/逻辑目录用 hex headers，避免 Unicode header 问题。
2. 前端新增 `invokeRawCommand`、`uploadAttachmentBytes`、`readAttachmentBytes`。
3. Slash「图片」「附件」、右键「插入图片/附件」走 `pickAttachmentFiles` 路径上传；FileHandler 接收所有文件，粘贴/拖放走 raw bytes 上传。
4. 文档 JSON 仅保存 attachmentId 与展示元数据；图片预览 Blob URL 在卸载/ID 变化时 revoke；上传批次在文档切换后不插入旧编辑器。
5. 旧 data URL `image` 节点继续由官方 Image + ResizableNodeView 渲染，不做强制迁移。

## 三、后端派生数据

- `to_markdown` 支持 `attachmentImage`（`![alt](attachment://id)`）与 `attachmentBlock`（逐项 `- [name](attachment://id)`）。
- `document_props` 的 `imageCount` 计入旧 image + attachmentImage；新增 `attachmentCount`（附件块 items 总数）。

## 五、已知限制

- 真实 Tauri WKWebView 的 raw IPC、Blob URL、原生文件对话框未执行，需重启 dev 人工复测。
- 图片预览上限 20 MiB；超大图片只显示错误态并允许下载。
- 新图片块仅用于新上传；旧 data URL 图片不迁移。
- 设置页暂未暴露附件重命名/移动；编辑器图片/附件块不进入表格单元格内部。
- 字节上传上限 64 MiB；更大文件必须走文件选择器的路径上传。
