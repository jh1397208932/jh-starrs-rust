## 完成内容

1. **Tiptap 结论**：`@tiptap/core`、`@tiptap/react`、`@tiptap/pm`、`@tiptap/starter-kit` 及已安装的 24 个扩展包全部为 **MIT**；未安装 `@tiptap-pro`/Cloud/AI 等付费模块。
2. **全量许可证审查**：
   - 前端 740+ 个已安装包、Rust 300+ crate 无 GPL/AGPL/SSPL/BUSL/非商业/UNLICENSED/专有依赖；
   - `khroma`、`fuzzy` 包元数据缺失，但包内 LICENSE 文件为 MIT；
   - 9 项 MPL-2.0 弱 copyleft（lightningcss、cssparser、selectors、dtoa-short、option-ext）：开源，未修改文件，无“开源本项目”义务；
   - `r-efi` 为 MIT/Apache/LGPL 三选一，按 MIT 使用。
3. **字体审查**：
   - 生产构建产物仅包含 `Assistant`（OFL-1.1）；
   - Excalidraw 随包字体中，Liberation Sans 1.05 嵌入元数据为 Ascender 旧许可、Excalifont 无独立许可声明，列入禁止发布；
   - 新增 Vite `fontLicenseGuard`：构建阶段剔除白名单外字体资产。
4. **门禁**：新增 `scripts/check-licenses.mjs` 与 `npm run check:licenses`；`npm run build` 在 vite build 后自动执行，许可证失败即构建失败。

## 验证结果

- `node scripts/check-licenses.mjs`：exit 0；输出弱 copyleft 警告 9 项，无禁止项。
- `npm run build`：通过；`dist` 字体文件仅 4 个 Assistant woff2。
- 修复首版门禁对 `MIT/Apache-2.0`、`Unlicense/MIT` 斜杠 OR 写法的误报（统一归一化为 ` OR `）。
