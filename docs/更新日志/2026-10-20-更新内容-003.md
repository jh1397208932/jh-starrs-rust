# 更新日志 · 2026-10-20 · 弹窗行为统一化 与 动画场景规范化（003）

## 完成内容

1. **弹窗关闭行为契约收编**：`ui/dialog.tsx` 的 `DialogContent` 新增 `dismissible`（默认 true = 右上角 X / Esc / 点击遮罩均可关闭）；设为 false 时统一在组件内阻止三种途径——调用方禁用必须显式声明。各弹窗散落的 `preventDefault` 三连全部清除。
2. **弹窗头部组件化**：新增 `DialogHeader`（标题 + 可选描述 + 右侧动作槽，统一 pr-8 避让关闭按钮）；创建工作空间向导、KB 管理、工作空间管理三个弹窗已迁移。
3. **修复向导不可关闭**：`CreateWorkspaceWizard` 移除 `showClose={false}` 与三连 `preventDefault`；新增 `onOpenChange`，关闭（X/Esc/遮罩/创建成功）时统一重置 name/cloudPicked/avatar/touched 四个状态。
4. **确认弹窗恢复关闭按钮**：`ConfirmDialog` 移除 `showClose={false}`（X 行为 = 取消）。
5. **动画场景规范化**：新建 `src/lib/motion.ts` 作为 JS 动效预设唯一来源（SPRING_PANEL 260/26、SPRING_TOAST 400/30、SPRING_TICKER 60/100、TRANSITION_VIEW 140ms、TRANSITION_COLLAPSE 220ms、TRANSITION_REVEAL 400ms、EASE_STANDARD）；App / Sidebar / BlurFade / NumberTicker 的内联字面量全部替换为预设引用。UI-SPEC.md §5 新增「场景 → 预设映射表」（10 场景）与「新组件接入三步指引」。
