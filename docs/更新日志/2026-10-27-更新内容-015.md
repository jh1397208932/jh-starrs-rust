# 更新日志 · 2026-10-27 · 思维导图 v3 与 AI 协作 MCP（015）

## 思维导图 v3（XMind 补齐第二轮）

- **自由主题**：画布空白处新建、可拖任意摆放（保存坐标）；拖到主题上自动挂为其子主题；树主题拖到空白处记录手动位置。同级拖拽自动排序（吸附最近兄弟）。
- **关系线绕行**：与无关节点包围盒相交时自动绕行（上下取近），标签块按内容自适应宽度；关系线可用颜色与标签编辑。
- **大纲视图**：页头开关，右侧抽屉按层级列出全部主题；单行双击编辑、行内新增子主题/删除、折叠分支；与画布共享同一棵树与撤销历史。
- **贴纸库**：12 个内置贴纸（勾/灵感/警告/火焰/目标/图钉/心/赞/爆发/问号/金额/时钟），检查器点选，节点角标展示。
- **画布背景**：点阵 / 网格 / 纯色三档；**自动编号**（1 / 1.2 …）与**全部展开/折叠**入结构与主题菜单。
- **视觉**：分支线按节点渐变（源端 100% → 目标端 55%）+ 首挂淡入；标签/备注/链接徽标改为图标；节点手动坐标与自由主题样式（虚线框）。
- 数据模型：`topic.pos`、`topic.stickers`、`content.freeTopics`、`sheet.background/showNumbers`；Rust 校验覆盖坐标范围、贴纸白名单、自由主题上限（100）与总量计入；v1/v2 内容可直接打开。
- 布局基准：5000 主题 balanced 4.0ms（未回归）。
